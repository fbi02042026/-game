## 在公司要做的三件事（约 15 分钟）

### 1. 确认公司电脑的引擎版本（1 分钟）

团结里 `Help > About Tuanjie`，或者看：

```
ProjectSettings/ProjectVersion.txt
```

家里这台是 `2022.3.62t12` / `m_TuanjieEditorVersion: 1.10.0`。
**两边必须一致**（你之前说是一致的，再确认一次）。

### 2. 跑脚本，看 Y 盘工程是否健康（3 分钟）

把 `Tools/CollectMissingGuids.py` 拷到 Y 盘工程根目录，跑：

```
python CollectMissingGuids.py
```

看输出的「悬空 guid」数量：

| Y 盘悬空数 | 含义 | 怎么办 |
|---:|---|---|
| **远小于 67**（比如 0~10） | Y 盘是健康的，源头有图 | 继续第 3 步，取回来 |
| **接近 67** | Y 盘也是坏的，源头就没这批图 | 跳过第 3 步，只能手动配图 |

### 3. 从 Y 盘取回缺失资源（10 分钟）

把 `Tools/缺失资源guid清单.json` 和 `Tools/FetchFromSourceProject.py`
拷到 Y 盘工程根目录，跑：

```
python FetchFromSourceProject.py --src "Y:\PixelAdventureTown"
```

会生成 `_导出资源/` 目录，**按原相对路径放好资源 + 同名 .meta**，
里面有 `导入说明.txt`。

⚠️ **拷回本机时，`.png` 和 `.png.meta` 必须成对覆盖**——只拷 png 等于让团结
重新导入、生成新 guid，引用依旧对不上，白拷。

拷回来后在本机验证：

```
python Tools/DiagnosePhantomSprites.py
python Tools/CheckGuidRefs.py
```

确认悬空数下降。

## 如果 Y 盘也缺这批图

那就只剩一条路：**在团结里手动拖**。选职业页只有 **13 张不同的图**
（27 是引用次数，满星/空星是同一张重复用），十几分钟能拖完。
拖完保存，跑：

```
python Tools/DumpSpriteMapping.py --file PlayerJobSelect
```

把你的人工选择固化成 `Tools/sprite-rebind.json`，以后再被清空，
一条 `python Tools/ApplySpriteRebind.py --write` 就能全部恢复。
