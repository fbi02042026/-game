# 技能配置 / 战斗特效 — 放置与命名说明
# 路径均相对工程 Assets/

================================================================================
一、目录结构
================================================================================

Resources/Config/Skills/
  Ally/                           玩家 + 佣兵共用技能数值
  Monster/                        敌人主动技

Resources/VFX/Shared/             共用普攻套（我方/敌方分文件夹）
  Ally/    MeleeSlash / Bow / Orb / Heal
  Enemy/   MeleeSlash / Bow / Orb / Heal

Resources/VFX/Skills/
  Ally/                           玩家技能特效（文件名 = 技能 id）
  Monster/                        敌人技能特效
  Merc/                           佣兵技能特效（SK001~SK020）
  _Deps/                          技能特效依赖（材质/贴图/模型/音效，勿手改 guid）

※ 技能 prefab 命名 = Config 技能 id（如 ally_heal、mon_slam_multi、SK001）
※ 共用普攻套仍用 vfx_* 前缀，见下方 Shared

※ 暴击不用特效套，用飘字区分

================================================================================
二、共用套文件名
================================================================================

  Ally/
    MeleeSlash/vfx_melee_hit.prefab
    Bow/vfx_bow_fly.prefab + vfx_bow_hit.prefab
    Orb/vfx_orb_fly.prefab + vfx_orb_hit.prefab
    Heal/vfx_heal.prefab

  Enemy/   ※ 敌方弓箭文件名带 enemy，勿与 Ally 同名再搞混
    MeleeSlash/vfx_melee_hit.prefab
    Bow/vfx_enemy_bow_fly.prefab + vfx_enemy_bow_hit.prefab
    Orb/vfx_orb_fly.prefab + vfx_orb_hit.prefab

小怪远程普攻/技能：Enemy Bow（vfx_enemy_bow_fly / vfx_enemy_bow_hit）
精英/Boss 主动技见下方技能 id

================================================================================
三、技能 id（文件名 = prefab名 = .asset名）
================================================================================

【Ally 我方】
  ally_heal        加血
  ally_atk_up      加攻击
  ally_atk_speed   加攻速
  ally_crit_up     加暴击
  ally_thunder     雷击（玩家默认头像技）
  ally_shield      护盾

【Monster 敌人】
  mon_slam_multi   重击多次 — 近战精英、Boss近战
  mon_magic_burst  魔法攻击 — 远程精英、Boss远程

【Merc 佣兵 SK001~SK020】
  主动技 + 被动触发特效，文件名与 merc_skills 表 id 一致（SK001…SK020）
  来源对照：Resources/VFX/Skills/etfx_skill_vfx_map.csv

Boss 可配精英技或小怪普攻套；小怪不配主动技。

默认佣兵技能：盾兵→护盾，弓手→雷击，狂战→加攻速，奶妈→加血

================================================================================
四、注意
================================================================================

- 弓箭/法球必须有 _fly，不能只有命中图
- Enemy/Bow 不要放 vfx_melee_hit，应放 vfx_bow_fly + vfx_bow_hit
- 盾兵普攻用 MeleeSlash，不要单独职业文件夹
