## 2. P0 — 战斗显示与站位（进行中）

### 2.1 已定位问题

1. **`AutoGameInitializer` 用 `cur.y > 0` 判废出生点**  
   场景 Ground≈Y0.38、Spawn≈Y0.4 会被强制改成 `(-7, -3.5)`，角色落到地皮下。
2. **`monsterSpawnPoints` 未参与刷怪**  
   刷怪用 `hero.x + 4` + `GROUND_Y`，场景里摆的 `MonsterSpawn_*` 无效。
3. **Spawn/End 挂在 `Ground(scale.x=30)` 下且曾带 RectTransform**  
   坐标体系脏，运行时虽会归一化，但易与用户编辑预期不一致。
4. **Ground 贴图 alpha=0** 时看不见地面（碰撞可能仍在）。

### 2.2 修复项（代码）

- [x] 去掉 `y > 0` 判废，仅原点视为未摆放；默认 Y 从 Ground 采样
- [x] 收集全部 `MonsterSpawn_*`，刷怪轮询使用
- [x] Hero 出生优先读 `SpawnPoint`；相机 `minX/maxX` 跟 Spawn/End
- [x] Ground alpha=0 时恢复可见

### 2.3 场景侧建议（编辑器）

把锚点挂到 **WorldRoot 直属**，不要挂在带大缩放的 Ground 下：

```
WorldRoot
  ├── Ground          （碰撞 + 贴图，scale 按美术需要）
  ├── SpawnPoint      （普通 Transform，脚底对齐地面）
  ├── EndPoint
  ├── MonsterSpawn_0 … N
  └── Maproot / 背景
```

Spawn / MonsterSpawn 的 **世界坐标 Y** 应等于脚底站立线；代码会把 `UnitBase.GROUND_Y` 设为 `SpawnPoint.position.y`。

### 2.4 P0 验收

- Play Battle：英雄出现在 SpawnPoint，脚底贴 Ground
- 怪物出现在 MonsterSpawn 附近（Y 与点一致）
- 相机跟随 X，不把角色甩出屏幕
- Console 出现 `保留用户设定`，不再出现 `位置异常，已重置` 到 -3.5
