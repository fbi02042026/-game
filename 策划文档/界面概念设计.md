# 游戏界面概念设计
共8个核心界面，全部适配1080×1920竖屏手机操作，单手可玩。

---

## 1. 主界面（城镇界面）
```
┌─────────────────────────────┐
│ 💰 12580      💎 20      ⚙️ │ 顶部状态栏：金币/钻石/设置
├─────────────────────────────┤
│                             │
│    🏰 小镇全景像素图        │  中间是像素城镇背景
│  🏠铁匠铺  🍺酒馆  ⛲祭坛   │  建筑点击进入对应界面
│  🌾农场    🗿英雄雕像       │
│                             │
│                             │
├─────────────────────────────┤
│  🎒背包  🗺️冒险  📋任务     │ 底部三个大按钮，冒险按钮最大最突出
└─────────────────────────────┘
```
功能说明：
- 顶部显示资源，点设置可以调音量/看广告得钻石
- 中间点击不同建筑进入对应升级界面
- 底部大按钮「开始冒险」占中间位置，是核心操作入口
- 上线先弹离线收益领取弹窗，看广告可以翻倍

```
┌─────────────────────────────┐
│ ← 返回      第一章 第3关    │
├─────────────────────────────┤
│                             │
│              🏰BOSS         │ 最上面是BOSS关图标
│             /   \           │
│     🛡️精英   ✨附魔         │ 分支树状结构，已打过的灰色，可选的高亮
│       \     /               │
│        ⚔️普通               │ 当前可选的关卡点击选中
│         |                   │
│        🏪商人               │
│         |                   │
│       [你在这里]            │ 最下面是当前位置
│                             │
├─────────────────────────────┤
```

```
│ 🌳🌲 🏰      🍄🐰 →  🟢🟢  │ 中间横版战斗场景，像素背景

│ └─┘└─┘└─┘└─┘└─┘└─┘         │
│ ┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐         │  6×5格子背包常驻显示，战斗中随时可以点装备换/穿/分解
│ │🥕││💎││🥛││👢││🔨││📦│         │ 占多格的装备占对应格子，已装备的打勾

│ ┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐         │ 换装备立即生效，不用切界面

│ └─┘└─┘└─┘└─┘└─┘└─┘         │
```

功能说明：
- **全程自动战斗，背包常驻显示**：不用打开背包界面，战斗中随时可以点背包里的装备更换，换完立即生效
- **顶部进度条**：直观显示英雄当前推进进度、离终点还有多远
- **队伍栏+主动技能**：
  - 主玩家英雄最多带3个主动技能，技能来自装备词条/羁绊
  - 每个佣兵只有1个主动技能，点技能图标或者英雄头像就释放
  - 技能有冷却时间，蓝条/CD条在技能图标下面显示
- 血条/等级直接在头像下方显示，不需要额外状态栏
- 清完怪走到终点自动触发通关结算，不需要玩家操作

## 4. 通关结算/三选一装备界面
```
┌─────────────────────────────┐
│        🎉 关卡通关！        │
├─────────────────────────────┤

│  ┌────┐  ┌────┐  ┌────┐    │

│  │蓝剑│  │铁甲│  │皮靴│    │ 显示图标、名字、品质颜色、属性
│  │+15攻│  │+50血│ │+10速│   │
│  │⭐⭐  │  │⭐   │  │    │    │ 星级显示
│  └────┘  └────┘  └────┘    │
│                             │
├─────────────────────────────┤
│ [选这件]  [选这件]  [选这件] │ 每张卡片下方有选择按钮
```

- BOSS关会额外多一张卡片，必出紫/橙

## 广告点位统一设计
所有广告都是玩家主动点，不强制弹出：
- 所有「翻倍」按钮：离线收益/通关金币翻倍，看广告得
- 「免费」按钮：免费刷新商人商品/免费复活一次/免费拿一件装备
- 奖励旁边小电视图标：点了看广告得双倍奖励
