## 3. 接口契约（防并行接口冲突，各任务照此签名）

```
enum DayPhase  { Day, Dusk, Night }
enum WeatherType { Clear, Rain, Snow }

BattleAtmosphere : MonoBehaviour   // 非 DDOL，随 Battle 场景销毁
  static Instance
  DayPhase Phase / WeatherType Weather / float LightRadiusWorld（视野半径唯一真源，世界单位）
  event OnChanged(DayPhase, WeatherType)
  ApplyForStage(DayPhase, WeatherType)   // 由 LoadStage 调用一次

DayNightOverlay : MonoBehaviour
  Bind(BattleAtmosphere)   // 订阅 OnChanged，做 1.5–3s 插值
  SetRadius(float)         // 由 LightRadiusWorld 驱动，遮罩挖洞与判定同半径

NightVisionController : MonoBehaviour
  Bind(BattleAtmosphere)   // 每帧 LateUpdate 算距离，晚于 CameraFollow 与 ForceEnableRenderers

WeatherVfxController : MonoBehaviour
  Bind(BattleAtmosphere)   // 订阅 OnChanged，管雨雪粒子启停与回收

BattleManager（新 partial）
  ApplyWeatherBuff() / ClearWeatherBuff()   // 独立 AttrBonusData 引用字段，按关挂摘
```

数据表解析：`ChapterThemeMapTable.GetAmbience(int gameChapter)` / `GetWeather(int gameChapter)`，缺值回退 Day / Clear。

## 4. 任务清单

### T1 — 数据表加两列（依赖：无）
- 文件：`Assets/Data/Source/Tables/chapter_theme_map.csv`（CRLF）、`Config/ChapterThemeMapTable.cs`、`Assets/Resources/Data/Tables/chapter_theme_map.bytes`（Cook）
- 做法：表头追加 `ambience,weather`；8 行按 §2 映射填；`Row` 加两字段，`Translate` 解析；加 `GetAmbience`/`GetWeather`（仿 `GetMapName`:85），缺值回退；跑 `Tools/sync_table_bytes.py` 重烤 bytes。**CSV/bytes 必须同步，CRLF 不破坏**。
- 验收：8 章读值正确；bytes 与 csv 一致；缺表不阻塞开战。
- 风险：改表注释里的章节名是旧主题（亡灵/丛林等），以 `folderName`（森林/墓园/雨林/草原/海岸/深窟/炼狱/冰川）为准。

### T2 — BattleAtmosphere 控制器（依赖：T1）
- 文件：新建 `Assets/Scripts/Systems/BattleAtmosphere.cs`；挂点 `BattleManager.Waves.cs:166`（原 `SwitchBattleBackground(CurrentChapter)` 处）
- 做法：按 §3 契约实现；`LoadStage` 里解析一次 `ChapterThemeMapTable.GetAmbience/GetWeather(CurrentChapter)`；引导局（`Mode.Id == Tutorial`）强制 Day+Clear；退战随场景销毁、清事件订阅。
- 验收：`LoadStage` 后 Phase/Weather 正确；昼夜与天气可独立叠加（如 8 章黄昏+雪）；引导局不受影响。
- 风险：非 DDOL，勿挂 GameRoot；`ICombatBoundSingleton` 体系可选。

### T3 — 径向遮罩 Shader + DayNightOverlay（依赖：无，但半径要对齐 T4）
- 文件：新建 Shader（放 `Assets/Shaders/`）+ `Assets/Scripts/Systems/DayNightOverlay.cs`；参考 `BattleAmbienceBanner.AddDim():123`、`Assets/Shaders/BattleFootShadow.shader` 写法
- 做法：全屏 UI Image，中心透明四周压暗的径向渐变；中心每帧跟随 `Camera.main.WorldToScreenPoint(玩家位置)`；半径按 `orthographicSize` 补偿（击杀 zoom / ViewportFit 会改 ortho）；alpha/颜色按相位插值；**半径对外暴露 `SetRadius`，由 T2 的 `LightRadiusWorld` 唯一驱动**；排序在 HUD 之下、`UiSort.BattleAmbience`，`raycastTarget=false`。**不开第二相机**（历史黑屏）。
- 验收：夜晚玩家周围明显亮、无闪屏、血条/技能不被压暗；炼狱暗红色；正交尺寸变化时光圈不跑偏。
- **派 DeepSeek V4.1 Flash**（渲染数学/Shader）；C# 侧 `DayNightOverlay.cs` 可派 GLM/Step。

### T4 — 视野显隐控制器（依赖：T2 半径、T3 半径对齐）
- 文件：新建 `Assets/Scripts/Systems/NightVisionController.cs`
- 做法：按 §3 契约；每帧 `LateUpdate` 算敌人到光心世界距离 > `LightRadiusWorld` 则隐身（身体 SpriteRenderer / 头顶词条 / 名字），**血条节点保留常显**；进圈短淡入（0.15–0.3s）不硬闪；Boss/精英同样处理；白天/雨雪章全显并在退出夜战时还原；**必须晚于 `AutoGameInitializer.ForceEnableRenderers():582`（会强制 enabled+alpha）执行，每帧写回**。
- 验收：圈外怪看得见血条看不见身；被暗处怪打得到；进圈淡入；白天全显；切关/退战无残留隐身。
- 风险：血条是独立节点，别跟着身体一起隐；圈外 AI/索敌**不动**（主人明确要"照常行动只是看不见"）。

### T5 — 天气 buff 挂摘（依赖：T2）
- 文件：`BattleManager` 新建 partial；仿 `BattleManager.BossBlessing.cs` 的 `_bossStageTempBuff` 手法
- 做法：独立 `AttrBonusData` 引用字段；雪→`AttrType.MoveSpeed -5%`、雨→`AttrType.AttackSpeed -5%`、晴→无；进关挂、换关**按引用精确摘除**（主角+佣兵 RecalcAttr）；**绝不 `tempBuffs.Clear()`**（石像赐福/强化卡是整局 buff）。
- 验收：雪天走位变慢、雨天攻速变慢可感；换关不残留、不误删整局 buff；结算清空。
- 风险：`GetCombatMoveSpeed()` 是玩家/佣兵移速唯一出口（`UnitBase.Combat.cs`），吃 `attr.MoveSpeed`；攻速走 `SkillCastService.GetTeamAttackSpeedMul()` 之外还可直接改 attr，按 BossBlessing 同款走 attr 最稳。

### T6 — 雨雪粒子控制器（依赖：T2）
- 文件：新建 `Assets/Scripts/Systems/WeatherVfxController.cs`
- 做法：按 §3 契约；订阅 OnChanged，雨/雪各循环发射，排序在单位与 HUD 之间（`Default` 层、`SORT_VFX=50` 附近），`raycastTarget=false`；复用 `BattleVFXSystem.PlayPreparedVfx():931` + `PoolManager`；退战回收；关"天气特效"开关无粒子无报错。
- 验收：不挡血条/技能/飘字；切关无残留；开关切换无报错。

### T7 — 资源落地 + Toast + 收尾（依赖：T2/T6）
- 文件：`Assets/Art/Effects/Epic Toon FX/Prefabs/Environment/Weather/{Rain,Snow}/*.prefab` → `Assets/Resources/VFX/Weather/`（.meta 一起）；首次天气 Toast；提交前 `EnsureMeta.py`
