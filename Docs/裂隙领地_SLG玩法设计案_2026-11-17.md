# 城镇入口 · 轻量 SLG 玩法设计案 v6.4（2026-11-17）

> **v6.1 增量**：机器人城友好度系统（双路线锁定 / 奖励递增递减 / 达标给战功 / 敌对侵略 / 仇恨离线衰减 / 城镇永久消失）。
> **v6.2 增量**：① 友好城顶满转盟友城（慢产战功、有存在时限），榨干城刷新补位、地图城镇总数恒定；② 友好城/侵略**每日各 2 次上限**、行军慢靠广告加速；③ 新增**旅店**建筑（参考附图右下角）+ 战功快速治疗；④ 战功抽装备、**替换装备回收换金币**。
> **v6.3 定稿数值**：装备回收金币**不设上限**（单件最多一两百、冲击可忽略）；每日 2 次 = **每城每天 2 次**；盟友城时限 **24 小时**；旅店回血**按百分比**（升级旅店回得更多），**战功治疗 = 消耗战功按比例一次回满**。
> **v6.4 改名**：玩法名"裂隙领地"→ **"城镇入口"**（主人嫌原名土、拍板直白命名）。仅改标题/界面顶栏/命名待确认项，**文档文件名保持旧名不动**（避免动引用）。

> 状态：**设计案，未动代码、未提交**。只给规则/数值/界面/接口/验收标准，不含完整代码。
> 🔴 **独立性**：本玩法单独设计、单独成系统，不接入此前任何玩法代码或设计（派遣远征／试炼场那份不作参考）。
> 定位（主人定性）：**主玩法 = 获取 + 提升佣兵；SLG = 长期留存（时间海绵）**。玩法简单、耗时长、每天有事做。
> 🔴 **爽快基调**：玩家想出门就出门，不看天气、不算风险账。血条是唯一的"缰绳"，而且只在城内恢复；广告是"想多赚一票"的正向加速，不是解惩罚。

## 1. 一句话 + 决策表

**一句话**：一张城镇图，玩家坐镇守城、三佣兵小队出门——打野怪拿少量粮草石材、占矿挖大量矿（升级建筑）、打城镇选掠夺（抢战功换装备升星石）或通商（安全拿少量石材）；回来路上要耗时、看广告加速，血空了在城里慢慢回；守护石合一加全员属性、还决定全图矿的富饶度，越升矿越肥也越难；后期开野外精英据点，传奇小队才敢碰。

| 决策点 | 定案 |
|---|---|
| 形态 | 一张城镇图 + 一张大地图。玩家守城不出城；3 佣兵小队外出 |
| 玩家角色 | **只守城**：solo 或带 ≤2 佣兵；野外全交给佣兵 |
| 队伍 | **出发必须 3 个佣兵组队**（占矿/掠夺/通商/打野/据点统一） |
| 资源 | **金币**（出征军费）· **粮草**（产+掠，出征耗）· **矿**（野外采，升建筑）· **战功**（掠夺 + 友好度达标的通商 + 据点，换装备/升星石）· **守护石材料**（掠夺多/通商少/野怪少，升守护石）· 钻石/广告（加速） |
| 反哺 A · 工坊 | 战功随机制作装备（最高稀有、大概率普通、分职业）+ 卖通用升星石 |
| 反哺 B · 守护石 | 石材升级 → 给点 → 手动加**全员**属性；等级 = 全图矿富饶基准 |
| 升星梯度 | 主线 ★1→★3（碎片+徽记）；SLG ★3→★5（通用升星石）；每星 +15% 不变 |
| 互斥 | 主线出战队列 ⇄ SLG（生产/驻守/外出），同一佣兵只能占一边；战损不回主线 |
| 战斗 | 纯数值弹窗，无战斗动画；但行军往返耗时 |
| 美术 | 主人提供城镇 + 大地图 |

## 2. 核心循环（爽快飞轮）

```
① 想出门就出门（3 佣兵小队）
   打野 / 占矿 / 掠夺 / 通商 / 后期据点
   ↓ 血条掉、行军耗时（广告可加速）
② 满载回城
   带回 矿 / 粮草 / 战功 / 石材
   ↓
③ 全部拿去变强
   矿升建筑 · 战功买装备/升星石 · 石材升守护石
   ↓
④ 守护石升级
   全员属性↑ + 全图矿富饶度↑（矿更难、但产得更多）
   ↓
   ↺ 变强 → 去抢更高级的矿/城，飞轮永远朝上转
```

**为什么不会畏缩**：出门零门槛，唯一成本是血条和行军时间，两者都能靠广告加速；世界变难的同时收益也变高，方向永远朝上。

## 3. 守护石系统（反哺 B · 全员属性）

> 定名 **守护石**：裂隙的对立存在、镇压裂隙护住城镇之物（世界观绑定）。v6 改动：**两组并一组、加全员属性**，等级决定全图矿富饶度。

### 3.1 世界观

裂隙侵蚀世界，守护石是镇压裂隙的守护之物。对外掠夺 → 回城加固守护石 → 全员更强、矿更肥。属性加成是守护石力量的体现，矿变难是裂隙对力量增长的反扑。

### 3.2 规则

- **合并为一组**（原玩家石/佣兵石作废），升级给守护点，**手动加全员属性**。
- 每次升级给 **N 点守护点**（建议每级 +3 点），玩家分配到基础属性。

| 可加属性（全员） | 每点效果（示例，需实测） |
|---|---|
| 攻击 / 生命 / 防御 | 每点 +1% |
| 金币收益 | 每点 +1% |

- ~~**可洗点**（消耗少量金币或每日免费 1 次），避免加错废号。~~ **已删（11-17 主人拍板）**：守护石**不可洗点**，加点确认后不可重置，只能靠升级拿新守护点。
- **等级 = 全图矿富饶基准 B**：守护石 Lv=N，野外刷出的矿等级在 N±1 浮动（见 §7.2）。守护石越高 → 矿越肥也越难。
- 加点后**账号级永久生效**，回主线直接变强。
- UI：[守护石] → 升级得点 → [加点] 面板（属性列表 + 剩余点 + 确认）。

> 已定（11-17）：不洗点、只能升。待定：每级给几点、每点加多少、属性清单（见 §11）。

## 4. 资源体系

| 资源 | 来源 | 花在哪 | 边界 |
|---|---|---|---|
| **金币** | 主线 + **装备回收变卖**（v6.2 新增） | 出征军费 | ⚠️ 原"SLG 不产金币"红线破例：仅装备回收一条口子，**单件最多一两百、不设上限**（主人拍板） |
| **粮草** | 农田 + 野怪少量 + 掠夺/通商 | 出征消耗 | 内部自给，上限 8h |
| **矿** | **野外矿点采集（唯一）** | **升级建筑** | 有等级，等级越高单位时间产越多 |
| **战功** | 掠夺城镇 + **友好度达标的通商城镇** + **盟友城慢产** + 后期野外据点 | 工坊（装备+升星石）+ **旅店快速治疗** | 通商前期不给、友好度达标后才给 |
| **守护石材料** | 掠夺多 / 通商少 / 野怪少 | 升守护石 | — |
| **钻石 / 广告** | 主线 / 看广告 | 行军/回血/冷却加速、出征次数 | 只买效率，不产硬通货 |

🔴 **两种硬通货分开**：**战功换养成资源（装备/升星石），石材换守护石属性**，两条线不混用。通商前期只给少量石材、**友好度达标后才给战功**（是"养熟了才给"的长线回报，不是白嫖）——前期拿战功还是靠掠夺。

## 5. 城镇界面（玩家守城）

### 5.1 一张城镇图

```
┌───────────────────────────────────────┐
│ 城镇入口  粮草1,240 战功380 石材24 矿96 ⓘ  │
│                                           │
│   [农田 Lv2]      [工坊 Lv1] ← 工坊=商店   │
│    +12/分        随机制作装备              │ ← 建筑放佣兵，头顶冒 +X
│                                           │
│       ┌─────────────────┐                 │
│       │   议事厅 Lv3     │                 │ ← 玩家守城点：solo / 带≤2佣兵
│       └─────────────────┘                 │
│                                           │
│  [城墙 Lv2] 玩家+1驻守  [城门]🏹 → 大地图   │ ← 城门进大地图选目标
│   城防860  （反打看城防+驻守）             │
│                                           │
│  [守护石 Lv4] 全员攻/血/防 [加点] ─ 裂隙对立 │ ← 合一守护石，手动加点
└───────────────────────────────────────┘
```

- **建筑**：农田（产粮）、工坊（=商店，做装备+卖升星石）、议事厅、守护石、城墙、城门、**旅店**（位置参考主人提供的城堡图**右下角**屋舍）。
- 🔴 **旅店**（v6.2 新增，v6.3 定数值；**11-17 主人拍板定值**）：残血 / 无血佣兵**进驻旅店，每 1 分钟回 1% 血条**（满血约 100 分钟）；**升级旅店 → 回血更快**（曲线待定）。另一条路：**消耗 10 战功 → 一次把 1 名佣兵回满**（战功快速治疗）。回血仍只在城内（旅店）发生，广告只加速。
  - 定值（11-17）：自然回血 = 1 分钟 1%；战功治疗 = 10 战功回满 1 人。升级旅店加快回血速率（具体曲线待定）。
- **玩家守城**：玩家本人只在城内，可选 solo 守 / 带 ≤2 佣兵驻守；城防 + 驻守决定被打时的损失。**人不出城**。
- **城门 → 大地图**：选目标，派 3 佣兵小队出门。
- 建筑放佣兵头顶冒 `+X/分` 实时跳，放置感核心；空着则灰显产出 0。

### 5.2 佣兵状态互斥

一个佣兵同一时间只能处于一种状态：**生产中 / 守城驻守 / 外出小队 / 回城休息**。
🔴 **与主线互斥**：在主线出战队列的佣兵，不能出发或干活；反之在 SLG 占用的也不进主线出战队列。主线待命/收藏的不算占用，可调来 SLG。
- 外出小队固定 **3 人**；守城最多 2 人。界面给"占用中"标记 + 一键从主线队列撤下转 SLG，别让玩家手工翻名单。

### 5.3 城镇等级（11-17 拍板，被动派生）

- **城镇等级不单独升**：城内**其他所有建筑都达到某等级时，城镇等级被动 +1**（即取所有建筑的最低等级为城镇等级，木桶效应）。具体"达到几级 +1"待定（见 §11）。
- 城镇等级是**野外据点的解锁门槛**：城镇等级 ≥3 才开放野外精英据点（见 §6.1）。别处不用城镇等级。

## 6. 大地图：点位与交互

### 6.1 点位类型

| 点位 | 内容 | 产出 | 风险 | 出现阶段 |
|---|---|---|---|---|
| **野怪据点** | 普通野怪 | 少量粮草 + 少量石材 | 低，掉少量血 | 全期 |
| **矿点** | 占矿会话制，野怪定时骚扰 | **大量矿** | 中，掉血；被打死回城 | 全期 |
| **城镇** | 有名字+友好度，首次选掠夺/通商锁死 | 见 §6.3，奖励随友好度递增/递减 | 掠夺招侵略 / 通商安全 | 全期 |
| **野外据点** | 精英本 | **大量矿 + 大量战功** | 极高，**传奇佣兵才有几率打过** | **城镇等级 3 解锁**（11-17 拍板，取代"仅后期"） |

### 6.2 城镇交互流程（主人拍板）

```
点城镇 → 弹「掠夺 / 通商」二选一
       → 选定后弹「预计获得物」弹窗（出发 / 取消）
       → 点出发 → 校验 3 名空闲佣兵 → 派 3 人小队走行军流程
```
- 不足 3 名空闲佣兵时，"出发"置灰并提示"需要 3 名空闲佣兵"。
- 预计获得物弹窗显示：粮草 / 战功 / 石材 / 矿（按所选类型）、行军耗时、预计血耗、胜率分档。
- 🔴 **路线锁定**：一个城镇**第一次选了什么就永远是什么**，不能中途改换路线；敌对后只能一路侵略到城市被消灭。

### 6.3 机器人城友好度系统（v6.1 新增 · 主人拍板）

> 每个机器人城都有**名字**和一个**友好度**。第一次接触时二选一锁定路线，两条路都是"不归路"。走到终局后城市**转化或消失，并刷新补位，地图城镇总数恒定**。

🔴 **城镇名字与分等级（11-17 拍板）**：
- **名字**：用**随机玩家名字**命名，先备 **10 个随机池**，刷新补位时从池里随机取；不足时再扩池。
- **分等级**：机器人城**不都一样，要分等级，像竞技场一样**分档（守军战力/资源量按等级递增，参考 `ArenaRules` 的确定性分档思路，SLG 内独立实现）。城等级如何随阶段映射待定（见 §11）。

🔴 **每日次数上限（v6.2 定稿）**：**通商每天最多 2 次 / 城、侵略（掠夺）每天最多 2 次 / 城**（主人拍板：**每城每天 2 次**，非全地图共 2 次）。友好是慢慢消耗的过程、不要太快——这样玩家才有动力去侵略。来回行军路途耗时，玩家嫌慢就会看广告加速（行军加速/一键召回），这正是广告变现点。

**通商线（慢慢养，安全）**
- 每通商一次 → 友好度 **+30**（11-17 拍板）→ **奖励前期差不多、慢慢涨一点**（每天最多 2 次）。友好度**每天自然 −10**（11-17 拍板）。
- **4 次通商即可把友好度顶满**（每次 +30，满值 120；11-17 拍板，取代原 6~8 次）。
- 🔴 **友好度达标后，通商也开始给战功**（v6.1 覆盖 v6"通商不给战功"）——战功前期靠掠夺，养熟后通商也能产。
- 友好度**顶满**（第 4 次通商当场，11-17 拍板）：这一次即给**一次性大奖**（大量粮草 + 石材 + 战功）→ **转为"盟友城"**：存续 24 小时内**可去 3 次**获取守护石等材料（11-17 拍板），每次给的逐次减少，**约 4 次后盟友城消失** → **消失后刷新一座新城镇补位**。

**掠夺线（快进快出，高收益但树敌）**
- 每掠夺一次 → **给 30 战功**（11-17 拍板，见 §8 工坊消耗口径）→ 友好度 ↓ → **第一次抢最多，之后一次比一次少**（机器人资源有限、不增长，越抢越少；每天最多 2 次）。
- **3~4 次掠夺 → 敌对**。
- 敌对 → **机器人开启侵略玩家城市**：你侵略越多、它反扑越频繁，直到把这座城的资源榨干、城市消失。
- **仇恨值**：每侵略一次 +10，每小时自然 -1（🔴 **离线也算**，按 `lastSaveTime` 结算差值）；仇恨越高 → 侵略越频繁。
- 城市被榨干消失后 → **刷新一座新城镇补位**（新名字）。

🔴 **城镇总数恒定（v6.2）**：任何城镇走到终局（盟友城到期 / 被榨干）→ 消失 → **冷却后刷新一座带新名字的城镇补位**，保证地图上城镇数量始终等于该阶段配比（前 6 / 中 10 / 后 15 中的城镇份额），**不会最后全变成友好城镇**。

| | 掠夺城镇 | 通商城镇 |
|---|---|---|
| 安全 | 掉血、可能阵亡回城 | 不掉血，安全 |
| 粮草 | 第一次多、逐次递减 | 少 → 随友好度递增 |
| 守护石材料 | 多、逐次递减 | 少量起步 → 顶满大量 |
| 战功 | 有 | **前期无、友好度达标后有** |
| 每日上限 | 2 次 | 2 次 |
| 单次次数 | 3~4 次到敌对 | 6~8 次到顶满 |
| 终局 | 侵略至资源榨干、城市消失→刷新补位 | 友好度顶满给大奖→转盟友城慢产战功、到期消失→刷新补位 |
| 成本 | 粮草 100 + 金币 50 | 粮草 80 + 金币 40（只低 20%，别让通商显得白嫖） |

**设计意图**：把"掠夺还是通商"从单次选择升级成**一条长线经营**——通商是慢热的安全回报（养熟了连战功都给），掠夺是快进的爆发回报但会招来持续侵略。路线锁死让每次选择有分量。复仇悬赏叠加在掠夺上（被机器人抢过 → 打回有额外赏金）。

### 6.4 占矿会话制

- 占矿不是打完就一直挖：矿点有**储量**，采满即枯竭消失；采集期间**野怪定时骚扰**，佣兵掉血。
- 被骚扰打死 → 回城，矿点保留剩余储量，下次可再来采。
- 矿点等级越高 → 单位时间产矿越多，骚扰怪也越强。

### 6.5 行军耗时 + 战斗结算

- **单程 20 分钟**（11-17 主人拍板，往返共 40 分钟）：占矿/通商/掠夺/打野/据点**都要往返耗时**：派队伍 → 路上 → 办事 → 返回 → 回城。太长一天打不完、太短没广告意义，故定 20 分钟。
- 看广告可**加速单程**或**一键召回**；行军时间本身是时间海绵。
- 到达后战斗仍是**纯数值弹窗**（无战斗动画）：
  ```
  战力比 R = 我方战力 / 守军战力
  R ≥ 1.5 大胜100% │ 1.0~1.5 小胜70% │ 0.8~1.0 惨胜40% │ R<0.8 失败0、重疲劳
  ```
- 出征战力 = Σ(3 佣兵战力快照) × 守护石加成；复用 `MercRosterDefs.ApplyCombatStats` + `PowerCalc`。
- **战损 = 佣兵疲劳 + 血条**（休息恢复），绝不回写主线佣兵。
- 玩家守城被打（**机器人侵略**）：由敌对城镇的仇恨值驱动，仇恨越高越频繁；异步模拟，城防 + 驻守决定损失，回城弹战报。难度像竞技场分高低（参考 `ArenaRules`/`ArenaEnemySpawner` 的战力分档与确定性浮动思路，SLG 内独立实现，不改竞技场）。
- 🔴 **被掠夺损失按攻守战力差定比例（11-17 拍板）**：机器人来抢时，损失 = 玩家资源 × 比例，比例由**攻方战力相对守方（玩家）战力**决定。已给基准档：**攻方战力高于玩家 10~50% → 掠走 10% 资源**。其余档位（高 50~100% → 20%、高 100%+ → 30%、持平或更低 → 5%）为主架构建议值，**待主人拍板**（见 §11）。
- 🔴 **离线结算**：仇恨值衰减按 `lastSaveTime` 算离线差值（1 小时 -1）；离线期间机器人侵略也按仇恨档位结算，回来弹累计战报。

## 7. 点位分配 + 刷新 + 冷却

### 7.1 每轮点位（一次性消失）

打完矿 / 打完野怪 → **该点消失，刷新后有几率再出现**；机器人城走到终局（盟友城到期 / 资源榨干）→ **消失，冷却后刷新一座新名字的城补位**（总数恒定，见 §6.3）。整图清空 → 进入冷却 → 冷却结束刷新新一轮。每轮**每种类型保底**（矿和城镇都要有）。
- 🔴 **区分刷新规则**：矿点 / 野怪据点 = 一次性消失 + 冷却后**有几率重刷**；**机器人城 = 走完友好度线（盟友城到期 / 被榨干）后消失，但冷却后刷新一座带新名字的城补位，城镇总数恒定**（v6.2 覆盖 v6.1"城镇永久不刷"）。

| 类型 | 前期 6 | 中期 10 | 后期 15 |
|---|---:|---:|---:|
| 矿点 | 2 | 3 | 4 |
| 野怪据点（普通） | 1 | 1 | 1 |
| 掠夺城 | 1 | 3 | 6 |
| 通商城 | 2 | 2 | 2 |
| 野外据点（精英） | 0 | 1 | 2 |

**逻辑**：前期点少（佣兵少、满屏灰点体验差）、多为安全的矿和通商；后期拉到 15 个、掠夺城占近半 + 精英据点，佣兵多了正好抢战功。**前期没有野外据点**（主人拍板）。

### 7.2 矿等级与守护石挂钩

- 基准 **B = 守护石等级**；每个矿点刷出 **B-1 / B / B+1**，比例 **20% / 45% / 35%**（富矿略多，正向惊喜）。
- 守护石升级 → B 上移 → 全图矿等级整体上移 → **更难但产得更多**。
- 单位时间产矿 = **10 点/分钟**（11-17 主人拍板定值）；UI 高亮"富矿"。

## 12. 施工红线

- **独立系统**：不接此前任何玩法代码/设计；新文件为主。
- **玩家不出城**：只在城镇守城（solo 或 ≤2 佣兵）；野外全是佣兵。
- **出发固定 3 人组队**：占矿/掠夺/通商/打野/据点统一。
- **升星分段**：主线 ★1-3、SLG ★3-5；★1-3 与每星 +15% 一字不动；太简单调关卡难度。
- **升星石消耗定死**：普通 5/10、稀有 10/15、传奇 15/20。
- **两条反哺线分开**：战功→装备/升星石，石材→守护石属性；通商前期只给石材、**友好度达标后才给战功**。
- **友好度路线锁死**：城镇首次选掠夺/通商即锁定，不可改；走到终局（盟友城到期 / 榨干）城市消失、**冷却后刷新新城补位、城镇总数恒定**。
- **仇恨离线衰减**：按 `lastSaveTime` 结算，1h -1；离线侵略需设损失上限，避免离线过狠。
- **单向隔离**：SLG 不产钻石；战功/石材/矿不换主线货币。⚠️ **金币破例**：仅"装备回收变卖"一条口子产金币，**单件最多一两百、不设上限**（主人拍板），其余仍不产。
- **守护石单点只读**：唯一碰主线处（除升星扩位），只读、全员、单点。
- **血条只在城内恢复**：广告只做城内加速，不在野外救命。
- **互斥**：主线出战队列 ⇄ SLG 不可同时占；战损只写疲劳/血条，绝不回写主线佣兵。
- **战斗无过程**：纯数值弹窗；行军耗时另算。
- **反打不改竞技场**：难度思路参考，SLG 内独立实现。

- **不动美术排版**：城镇/大地图界面由主人提供素材，接线前先确认。
- **编译验证**：本机无引擎，落地后须主人跑编辑器确认编译。

## 15. 一句话给开发

做一套**独立** SLG：玩家只守城不出城，城门派 **3 佣兵小队**出门；打野怪拿少量粮草石材、占矿挖大量矿（升级建筑、等级跟守护石挂钩）、打城镇点一下弹**掠夺/通商**二选一再弹获得物弹窗（出发/取消）；**每座机器人城有名字和友好度、首次选哪条路就锁死到底、每城每天通商/侵略各最多 2 次（友好慢慢耗，逼玩家去侵略、嫌路慢就看广告）**——通商 6~8 次养到顶满、奖励递增且达标后给战功、顶满给一大笔粮石战**并转盟友城慢产战功、24 小时后消失**；掠夺第一次最多、逐次递减、3~4 次转敌对、机器人开启持续侵略（仇恨每次 +10、每小时 -1 且离线也算、越高侵略越频繁）直到榨干消失；**城镇走完任一条线消失后刷新新城补位、地图城镇总数恒定、不会全变友好城**；矿/野怪打完几率重刷；**新增旅店（图右下角）：残血进驻按百分比回血、升级旅店回得更多、战功按比例一次回满**；**工坊战功抽装备、替换下的旧装备卖成金币（⚠️ 破"SLG 不产金币"红线，但单件最多一两百、不设上限）**；出门回来都耗时、广告加速；血空回城、血只在城内（旅店）回；守护石合一加全员属性、等级决定全图矿富饶度；后期加传奇门槛的野外精英据点；主线/SLG 佣兵互斥、战损不回主线；主线 `MaxOutStar` 3→5、每星 +15% 不动、★1-3 不动；美术由主人提供。写完请主人跑编辑器验编译。
