- 标题「分享领奖励」+ 右上角 X / 点 Dim 关闭
- 分享文案预览：「我正在玩《像素冒险：裂隙之刃》，割草爆装超解压，快来一起冒险吧！」

- 大按钮「立即分享」→ 唤起系统分享面板（ShareService 链路原样复用，发奖时机不变）
- 当日已领 → 按钮置灰「今日已领」，提示条变「今日已领过，明天再来」
