### `BattleResultScreen` 实现要点

- **守卫**：`Application.isPlaying && GameSceneGate.IsBattle` 否则直接 onDone 不播；`Resources.Load<GameObject>("Prefabs/Battle/战斗结果")` 取 null → LogError + onDone（fail closed，铁律 14，不缺真值不卡流程）。
- **自适应**：Instantiate 后立即 `UICanvasSetup.ApplyPopup(canvas, GameConfig.UiSort.BattleResult)` —— 一次修预制体三处硬伤：① worldCamera 空 → 绑 `ResolveUiCamera()`；② 根节点 localScale=(0,0,0) → `EnsureRootStretch` 归一铺满；③ CanvasScaler 写死高对齐 720×1280 → 按 `DesignAspectLetterbox.ResolveUiMatch()` 换宽对齐（瘦长屏 1080×2400 逻辑宽不被压到 576 < Panel 620）；④ overrideSorting 985。
- **节点定位**：`transform.Find("Root")` → `.Find("Panel")` → `panel.Find("胜利"/"失败")` **直属子节点**（特效子树里还有一个叫「胜利」的粒子节点，深度查找会撞名）；缺失 → LogError + Destroy + onDone。
- **设图（按路径，需求不是兜底）**：`Resources.Load<Sprite>("Art/UI/battle/战斗结果/胜利"|"失败")` 赋给对应节点 Image；取 null → LogError 不静默（铁律 14），界面照播。
- **点击跳过**：`rootT.Find("Dim")` 与胜负节点上的 Button 都接 `Skip()`（RemoveAllListeners 后 AddListener，同一出口）；`_skipped` 旗标只打断「未结束」的等待段，已结束后点击无效。
- **时间轴**（全程 unscaled，战斗结束可能处于定格/慢动作）：淡入 0.28s + `Panel.localScale` 0.5→1（EaseOutBack 过冲，读预制体基准值倍乘、不写死 1）→ 停留 1.2s → 淡出 0.3s（跳过走 0.12s 缩短版，先从弹出中途归位再淡避免跳变）→ `Destroy` → onDone。
- **合规**：只动 `localScale` / `CanvasGroup.alpha`（CanvasGroup 代码 AddComponent，不改预制体）；不写任何 `sizeDelta` / `anchoredPosition.x` / `Image.type`（铁律 32）；零 guid 依赖（预制体 meta 与图 meta 都是团结 56 字符标识，铁律 29/30 不扫不修）。
