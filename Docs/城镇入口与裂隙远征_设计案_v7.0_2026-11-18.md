## 1. 城镇入口（精简版 · 一条直线）

**一句话**：一张城镇图，建筑产资源；派 3 佣兵出门打点，打完即拿回城；资源拿去升建筑、升守护石、买装备，变强了去打更肥的点。

**核心循环**：`建筑产资源 → 派 3 佣兵打点（野/矿/城）→ 打完即拿 → 回城 → 升建筑/守护石/买装备 → 再出门`

### 1.1 保留
- **建筑**：农田（产粮）、工坊（商店）、守护石、城墙+玩家守城位、城门（进大地图）。
- **资源**：粮草、矿、战功、石材、金币（仅装备回收一条口子）。
- **出征**：固定 3 名空闲佣兵；野怪/矿/城三类点；战斗纯数值弹窗；行军往返耗时（单程 20 分钟），广告加速单程 / 一键召回。
- **守护石**：升级给点、手动加全员攻/血/防，账号级永久生效（唯一碰主线的只读单点）。**砍掉矿富饶度联动**。
- **工坊**：战功抽装备（复用现有随机生成 + 替换弹窗）、卖通用养成材料。
- **点位刷新**：打完即消失，整图清空进冷却（8 小时，广告 -40 分钟/次、每日 3 次）；冷却后刷新新一轮，每轮矿和城保底。
- **互斥**：主线出战队列 ⇄ 城镇占用，同一佣兵只能占一边；战损只写疲劳/血条，不回写主线。

### 1.2 砍掉（v6.4 整套）
- 友好度值 + 双路线锁死 + 每日 2 次/城 + 盟友城慢产与到期 + 仇恨值 + 离线衰减 + 侵略频率 + 被掠损失分档 + 城市消失补位 + 城镇总数恒定。
- 城镇等级木桶派生（野外据点门槛改挂守护石等级 ≥3）。
- 占矿会话制（储量、骚扰怪）→ 打完即拿。
- 矿等级联动守护石富饶度 → 矿固定产出。
- **连带消失的文档矛盾**：v6.4 §11 的"4 次 / 6~8 次顶满"冲突、"每天 −10 与 4 次顶满"数学冲突，随友好度系统整体删除而不复存在。

### 1.3 数值（沿用已拍板，未拍板标"建议"）
| 项 | 值 |
|---|---|
| 行军 | 单程 20 分钟、往返 40 分钟 |
| 地图冷却 | 8 小时；广告 -40 分钟/次、每日 3 次 |
| 战力比 R | ≥1.5 大胜 / 1.0~1.5 小胜 / 0.8~1.0 惨胜 / <0.8 失败 |
| 守护石 | 每级 +3 点、每点 +1%（建议，待主人拍板） |
| 工坊价 | 抽装备 20 战功 / 通用材料 50 / 石材补给 60（建议） |
| 点位配比 | 前 6 / 中 10 / 后 15（矿、野怪、城按档分） |

## 2. 裂隙远征（无缝大地图 · 随机撒点出征）

**定位**：承接 SLG 砍掉后的留存位。核心 = **地图上点位随机、每次刷新布局不同**（变化多）+ **少量反哺养成**（长期目标）。**先不上赛季**（无段位/排行榜/每日挑战），赛季留二期扩展位。

### 2.1 无缝大地图（本轮主人诉求，v7.1 重做）
- **形态**：竖屏一张**无缝滚动大地图**，**固定最大范围**（建议：前期 3 屏 / 中期 4 屏 / 后期 5 屏，待主人拍板）。`ScrollRect` 上下左右自由拖动，**无分层、无连线、无"只能选相邻节点"限制**——地图上任意可见点都能点选出征。玩家城固定在地图一角/中心作为"家"。
- **随机撒点**：每次地图刷新（首次进入 / 冷却结束），按当前阶段点位配比在整张图范围内随机撒点：
  - **矿点**：打完即拿，固定产出（单位时间产矿 10 点/分，沿用已拍板）。
  - **野怪据点**：少量粮草 + 少量石材，低风险。
  - **机器人玩家城**：随机玩家名（10 个名字池）、按阶段分档（守军战力/资源量递增，参考 `ArenaRules` 确定性分档思路、SLG 内独立实现）；点开弹"掠夺/通商"，一次结算后消失、冷却补位。⚠️ 机器人为异步模拟，非真人 PVP（合规红线沿用）。
  - **野外精英据点**：守护石 ≥3 解锁，大量矿 + 大量战功，传奇佣兵才有几率过。
  - **位置 / 类型 / 城名 / 等级均随机** → 每次刷新布局不同，这就是"变化多"的来源。
- **出征流程**：点任意可见点 → 弹"目标详情 + 预计获得物"（出发/取消）→ 校验 3 名空闲佣兵 → 行军往返（单程 20 分钟、广告加速 / 一键召回）→ 到达后纯数值弹窗结算 → 点位消失 → 冷却后刷新补位。
- **轻量边界**（明确不做什么）：
  - 固定 N 屏范围（**非无限地图**），到边界停住；**不做**分块加载、地形实时生成。
  - 一张底图 + 图标节点 + `ScrollRect`；点位图标点击走弹窗，不做场景内建模/3D。
  - 行军是计时 + 广告，不做实时行军动画；战斗无过程（纯数值弹窗）。
  - 🔴 **独立 UI 页面**，绝不改战斗场景 `map` / `unitRoot` 的 position/scale（项目恒位红线）。
- **美术**：底图 + 点位图标由主人提供（项目红线：不动美术排版，接线前先确认）；未到位前用占位。

### 2.2 出征三选一（轻量化肉鸽元素，可选增强）
- **触发**：每次出征**出发前**弹一次三选一（词条 / 技能 / 临时佣兵），本次出征期间生效、**回城后清空**。这样每次出门的 build 都不同，且不与城镇存档纠缠。
- **复用**：`DraftPool.PickOne()` 抽卡、`LevelUpDraftUI.ShowCategorized()` 三选一 UI、`RunLoadout.TryAddSkill/TryUpgradeSkill/TryAddMerc` 构筑账本、`SkillDraftMeta` 星级倍率、`SlotMachineSystem` 保底/免费抽。
- **隔离**：走 `RunLoadout.BeginMemoryMode/EndMemoryMode`，回城 `EndMemoryMode` 清空，不污染城镇存档。
- ⚠ **注意**：`RunDraftDirector.Tick()` 自然升级抽卡已停用（L213-215）、佣兵升星/升级卡已注释下架（L347-353 / L72-78）。远征须**新接"出发前三选一"入口**，不要复活这两条旧链路。

### 2.3 战利品与少量反哺
- **局内产出**：装备（复用 `RiftEquipGenerator.Generate` + `EquipReplaceConfirmUI.CoShow`）、通用养成材料"裂隙晶石"（命名待定）。
- **反哺**：裂隙晶石可换工坊通用养成材料 / 装备强化。
- 🔴 **不碰主线升星上限**（`MercStarDefs.MaxOutStar` 保持 3）、不改主线数值；一期不做 ★4/★5 扩位，避免主线耦合。
- **控量**：按点位给、设单点上限与单局总量上限（具体值待定），防通胀。远征装备走背包/替换弹窗，不自动覆盖主线已穿戴。

### 2.4 广告位（先建集中常量）
- 新增广告位（建议）：`expedition_march_speed`（出征行军加速）、`expedition_double_loot`（双倍战利品）、`expedition_recall`（一键召回）。
- 🔴 **先建常量表**：当前 `RewardedAdBridge.cs` 未定义任何 placement，现有 9 个 placement 中 6 处是裸字符串、3 处散落常量。新增前必须先集中定义，否则埋点/审核易漏。全走 `RewardedAdBridge` 单一出口，跨天重对、失败不发奖。
