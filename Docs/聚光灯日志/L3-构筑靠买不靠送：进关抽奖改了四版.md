# 日志 #3 · 构筑靠买不靠送：进关抽奖改了四版

> 发布窗口：**10/6–10/9**　标签：#聚光灯gamejam开发者日志
> 与上一篇间隔 ≥2 天；至少 1 张开发过程截图或短视频。

---

#### 正文

这游戏的核心乐趣是"这一局我凑出什么流派"。构筑从哪来，我前后做了四版，**前三版都是我自己做完之后又亲手推翻的**。

**第一版**：打完一关，免费弹三选一。做完跑了两局我就觉得不对——它发生在**打完之后**，玩家已经用旧构筑把怪打完了，奖励对刚才那场战斗没有任何影响。抽卡变成领奖，构筑不再是决策，是打卡。

于是我把它整个挪到**进关那一刻**：刚进关，剧情播完，先抽，抽完再开打。这样构筑是**先给的**，玩家带着新东西去打这一关。这一挪，前面写好的结算流程全要重排。

**第二版：自动扣钱 + 老虎机。** 进关自动扣费，老虎机转上两三秒，停下给结果。这个版本我只跑了一次就否了——钱在玩家没点头的时候就被花了，而且老虎机转的那几秒玩家只能干看着。既没有选择权，也没有事可做。我自己做的老虎机动画，做完就砍。

**第三版：先问再抽。** 弹面板：本关价格、[抽奖]、[跳过]。点了才扣钱，30 秒不理就当作跳过直接开战，绝不自动消费。老虎机改成只决定**类型**（佣兵 / 技能 / 装备），第二层仍然让玩家自己三选一——我要保证最后那一下是玩家选的。

**第四版，也就是现在这版：把"买"和"送"彻底拆开。**

- **四个按钮是买**：随机 / 佣兵 / 装备 / 技能。点了立刻出 1 张结果、直接生效、弹个提示，一秒都不用等。玩家买的是**结果**，不是演出。定向类（佣兵 / 装备 / 技能）价格是随机的两倍——买的是确定性，不是折扣。
- **老虎机是送**：只在"再来一次"小概率触发时才出场，随机一类，演出 1.2 秒，然后该类三选一。它是奖励，所以仪式感留着。

中间还绕进去一次：我一开始把抽奖花的钱和战斗奖励的钱当成一回事，越算越乱——战斗打完给的那份金币（也就是回城镇买东西、点天赋、解锁佣兵用的那份）要供好几个系统，抽奖一旦跟它共用，整套经济都得重算。最后做成**两套货币**：抽奖币只在战斗里产出、只进抽奖，那份金币完全不受影响。顺带地，之前那个"局内金币和城镇金币互为镜像、扣款要手动同步"的坑也一并消失了。

有一条规则我咬死没做：**不做替换机制**。槽位满了就只出升级卡，玩家永远不会因为抽到新东西而损失旧东西。要做"替换哪个"就得再套一层二级选择加一个确认弹窗，我觉得那是给玩家添堵，不划算——构筑的乐趣是叠加，不是割肉。

现在还没解决的：同一关里连抽不涨价，开局送 8 个启动币、第 1 关只卖 1 个，理论上第一关就能连抽 8 次直接滚起来；而后期价格涨到 8 封顶、产出却固定在 3/5/8，越往后能抽的次数反而变少。这个张力我知道，但得等真跑完几章、看玩家是不是真这么干，再决定要不要加刹车。
