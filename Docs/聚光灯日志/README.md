## 发布操作清单

每篇发布前逐项打勾：

- [ ] 帖子带 **#聚光灯gamejam开发者日志** 标签
- [ ] 至少 1 张**开发过程**截图或短视频（录屏算，成品宣传图不算）
- [ ] 自然收尾就行，**不用硬凑「本周进展 / 问题与风险 / 下期计划」三段式**（主人不要；2026 届官方也没强制）
- [ ] 与上一篇**间隔 ≥2 天**
- [ ] 发在自己游戏论坛；还没建页面就发聚光灯论坛，之后迁回
- [ ] 内容里有具体数字、具体文件、具体决策理由——**避免出现"优化体验""提升手感"这类空话**
- [ ] 不出现 `【待填】` 占位符

两份都缺 = 视为放弃所有奖项评选。底稿都在 [`素材清单-第三方与AI.md`](./素材清单-第三方与AI.md)：

> ✅ 已确认为「挑出来改名复制」，属实使用。比例已填实：**图标约 30% / 佣兵约 40% / 特效约 30%**
> （口径＝该素材包里被挑用的比例，非占游戏总美术比例）。AI 美术占比 >50%，**不参评最佳美术**。
