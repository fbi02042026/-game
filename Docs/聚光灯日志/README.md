## 发布操作清单

每篇发布前逐项打勾：

- [ ] 帖子带 **#聚光灯gamejam开发者日志** 标签
- [ ] 至少 1 张**开发过程**截图或短视频（录屏算，成品宣传图不算）
- [ ] 图随便配，立绘 / 实机截图 / 片头都行，**但别配一张还没做出来的东西**
- [ ] 自然收尾就行，**不用硬凑「本周进展 / 问题与风险 / 下期计划」三段式**（主人不要；2026 届官方也没强制）
- [ ] 与上一篇**间隔 ≥2 天**
- [ ] 发在自己游戏论坛；还没建页面就发聚光灯论坛，之后迁回
- [ ] 内容里有具体数字、具体文件、具体决策理由——**避免出现"优化体验""提升手感"这类空话**
- [ ] 不出现 `【待填】` 占位符
- [ ] **不强调 AI**。日志主角是自己的想法、测试和推翻自己的过程
