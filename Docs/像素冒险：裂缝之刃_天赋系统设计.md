# 《像素冒险：裂缝之刃》天赋系统设计（V3）

## 一、设计目标

- **左侧属性足够长**：40 个线性节点，给玩家稳定的长期成长感。
- **右侧有选择**：部分节点提供二选一或三选一，让玩家根据 build 做决策。
- **新手友好**：第一层右侧就放「武器专精」，让玩家根据第一章掉到的最好武器快速成型。
- **材料不进背包**：强化材料、天赋石、附魔石直接进入顶部资源条，不占用背包格子；因此右侧天赋只加「掉落数量」「资源上限」「背包格子」。
- **双货币分离**：左侧只消耗金币，右侧只消耗天赋石。

- 左侧 40 个节点全部按顺序点亮。
- 右侧 10 个节点，R_N 需要 L_(4N) 已开启（R1 需 L4，R10 需 L40）。
- 有选择的节点点击后弹出 A/B/C 选项，选择后不可更改（当前版本）。

## 三、核心规则

1. **线性解锁**：左侧必须 L1 → L2 → … → L40 顺序点亮；右侧 R1 → R2 → … → R10 顺序。
2. **左右联动**：R_N 需要 L_(4N) 已开启。
3. **材料消耗**：
   - 左侧只消耗金币。
   - 右侧只消耗天赋石，前期 5 个，后期 R10 需要 140 个。
4. **选择节点**：部分右侧节点提供 2-3 个分支，玩家选择后该节点锁定为所选效果。
5. **不可重置**：当前版本不可重置，后续版本可用「重置药水」作为 IAA/活动奖励。

## 六、升级节奏

- 普通玩家每天刷 3-5 局：
  - 2 周左右点满左侧属性。
  - 3-4 周左右点满右侧辅助。
- 金币主要出口来自「左侧天赋」，避免通货膨胀。
- 天赋石作为稀缺资源，右侧后期高消耗给玩家持续追求目标。

## 七、第一章/首日节奏参考

基于「反复刷但每次都能前进一点，失败只是运气不好」的目标设计：

### 第一章通关预期

- **单局时长**：5-7 分钟（5 个普通房间 + 1 个 Boss 房）。
- **首次通关所需局数**：4-7 局，约 30-50 分钟。
- **第一天总游戏时长**：1.5-2.5 小时，约 15-25 局。

### 为什么前几局会失败

失败原因主要是**随机性**，而不是玩家太弱：

- 怪物波次和精英怪出现位置随机。
- 装备掉落品质随机，差的时候没拿到好武器。
- 药水/强化材料掉落随机，导致续航不稳。
- 玩家操作失误（走位、技能释放时机）。

每局结束后，玩家带回金币和天赋石，即使失败也能感觉到「刚才差一点就过了，再点两下天赋应该能行」。

### 第一天天赋成长预期

| 时间/局数 | 左侧节点 | 右侧节点 | 玩家感受 |
|---|---|---|---|
| 第 1-2 局 | L1 力量 I | 无 | 基础属性略提升 |
| 第 3-4 局 | L1-L4 | R1 战斗入门 | 容错率/伤害提升 |
| 第 5-7 局（首次通关） | L1-L8 | R1-R2 | 明显变强，开始觉得能过 |
| 第 8-15 局 | L1-L12 | R1-R3（武器专精） | 武器定型，build 出现 |
| 第 15-25 局 | L1-L18 | R1-R5 | 进入第二章准备期 |

### 第一章单局产出参考

- 金币：150-350（失败约 100-200，通关约 250-400）。
- 天赋石：1-3 个（失败 1 个，通关 2-3 个）。
- 强化材料：若干，直接进入资源条。

### 设计要点

- **左侧 L1-L8 成本很低**（共 820 金币），保证第一天能点不少，成长感强。
- **R1 选「坚韧」+15 生命**，让玩家觉得「刚才那波我没死是因为血多了」。
- **R3 武器专精放在第一章通关后解锁**，玩家正好有一把好武器可以对应选择。
- **失败惩罚轻**：死亡只丢本局金币，装备和材料都带回，玩家愿意再来一局。

## 八、可选扩展方向

后续版本可以加入：

- **赛季天赋**：每个赛季新增一组辅助天赋，不影响老天赋。
- **天赋重置药水**：作为 IAA 广告奖励或活动奖励，让玩家可以尝试不同 build。
- **武器大师路线**：当某类武器专精点满后，解锁更高级的「武器大师」节点。

当前版本保持「左侧长线属性 + 右侧有选择的辅助/专精」结构，既简单又有养成深度。
