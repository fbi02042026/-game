# 战斗昼夜过渡与天气系统设计

**产品：** 像素冒险:裂缝之刃  
**文档类型：** 玩法 + 表现 + 落地规格（软著后局内氛围增强）  
**状态：** 设计稿，未实现  
**对接现有系统：** `ParallaxBackground`、`BattleBackgroundRegistry`、`BattleManager`、`StageRoller`、`GameBgm`、关卡类型 `StageType`

---

## 1. 目标与边界

### 1.1 要解决什么

战斗场景目前是「静态章节背景 + 视差」。希望在局内增加：

1. **黑天 ↔ 白夜过渡**（昼夜渐变，不是硬切）  
2. **下雨 / 下雪** 天气粒子与氛围  
3. 与关卡类型、章节主题挂钩的 **轻玩法差异**（可读、可感知，不做复杂气象模拟）

### 1.2 不做的事（本版）

| 不做 | 原因 |
|------|------|
| 实时现实时间同步 | 竖屏 Roguelike 以「关卡氛围」为主，不绑手机时钟 |
| 城镇昼夜同步 | 先只做战斗；城镇另案 |
| 完整物理积水/积雪碰撞 | 成本高，像素横版收益低 |
| 玩家主动「换天气」道具（一期） | 先做关卡驱动；二期再加消耗品 |
| 改软著说明书口径 | 本功能属软著后内容，见 `Docs/软著后开发备忘.md` |

### 1.3 体验原则

- **先氛围，后数值**：玩家先感到「天变了 / 在下雨」，再感到「打得不一样」。  
- **过渡必须可见**：昼夜切换至少 1.5～3 秒渐变，禁止瞬间跳色。  
- **不挡信息**：雨雪粒子不得遮挡血条、头像、技能按钮与飘字。  
- **性能可控**：粒子上限 + 低端机降级（只调色不粒子）。

## 2. 概念模型

一局战斗同时存在两套状态，互相独立又可组合：

```
DayPhase（昼夜相）     Weather（天气）
  Day / Dusk / Night     Clear / Rain / Snow
  Dawn（可选）
```

| 字段 | 含义 | 示例组合 |
|------|------|----------|
| `DayPhase` | 当前光照阶段 | 白天晴、黄昏雨、黑夜雪 |
| `Weather` | 当前降水 | 白天雨 = 灰蓝滤镜 + 雨粒子 |
| `Transition` | 是否正在渐变 | 进入 Boss 前：黄昏 → 黑夜（2.5s） |

**组合规则：**

- 任意 `DayPhase` × 任意 `Weather` 合法。  
- **冰雪章节**默认偏向雪；**丛林/海岛**偏向雨；**洞窟/魔界**可强制黑夜。  
- Boss 关建议：**进战前或清完最后一波前**做一次「白→黑」或「黄昏→黑」仪式感过渡。

## 3. 昼夜（黑天白夜）玩法

### 3.1 阶段定义

| 阶段 | 画面 | 建议用途 |
|------|------|----------|
| **白日 Day** | 正常章节色、对比正常 | 普通关默认 |
| **黄昏 Dusk** | 暖橙/洋红压暗，长影感（用滤镜模拟） | 精英关、进 Boss 前过渡 |
| **黑夜 Night** | 冷蓝/紫压暗，高光略抬单位轮廓 | Boss 战、诅咒关氛围、深夜事件 |
| **黎明 Dawn**（可选二期） | 从黑缓亮到白 | Boss 击败后结算前「天亮了」 |

### 3.2 何时切换

| 触发 | 行为 | 时长 |
|------|------|------|
| 进入关卡 | 按关卡表直接落到目标相位（可带 0.8s 淡入） | 0.8～1.5s |
| 普通 → 精英（同章连续） | 可选：白 → 黄昏 | 2s |
| 进 Boss / Boss 血量首次破半 | **仪式过渡**：黄昏 → 黑夜（禁止跳切） | 2.5～3.5s |
| Boss 击杀 | 可选：黑夜 → 黎明 → 回城前淡出 | 2s |
| 恢复关 | 固定白日晴朗（安心感） | — |

**引导战：** 固定白日 + 晴，避免干扰教程可读性。

### 3.3 轻数值（一期建议，可配置关闭）

原则：**±5%～10% 量级**，文案可感知，不改变构筑核心。

| 相位 | 对玩家 | 对怪物 | 备注 |
|------|--------|--------|------|
| 白日 | 无修正 | 无修正 | 基准 |
| 黄昏 | 暴击率 +3% | 移速 +3% | 「趁乱输出」 |
| 黑夜 | 视野感压迫（纯表现）；受治疗 +5% **或** 暴击伤害 +5%（二选一配置） | 远程小怪索敌略钝 / 近战攻速 +3% | Boss 关以表现为主，数值可关 |

> 一期推荐：**仅 Boss 仪式过渡 + 滤镜，数值全关**；跑通表现后再开表驱动修正。

### 3.4 与 BGM / 音频

- 昼夜本身不强制换 BGM（避免和关卡 BGM 抢戏）。  
- Boss 进黑夜时可对当前 BGM **低通/压小声 0.5s** 再恢复，配合 `bgm_boss`（决战来临）。  
- 剧情气泡期间继续走 `bgm_story`（静夜战线），昼夜滤镜保持，不打断过渡。

## 4. 天气（雨 / 雪）玩法

### 4.1 天气种类

| Weather | 表现 | 音效 | 章节偏好 |
|---------|------|------|----------|
| **Clear** | 无粒子 | 环境底噪可有可无 | 默认 |
| **Rain** | 斜向雨丝粒子 + 地面偶发水花（可选） | 循环雨声，音量随强度 | 丛林、海、森林、田野 |
| **Snow** | 缓落雪花 + 轻微横向漂移 | 风雪循环（轻） | 冰雪章；部分洞窟顶层 |

强度分档：`Light / Normal / Heavy`（只影响粒子密度与音量，不新开类型）。

### 4.2 何时出现

**方式 A（推荐一期）：关卡表驱动**

进关时由 `StageWeatherTable`（章节 + 关卡类型 + 随机种子）决定：

| 关卡类型 | 雨权重 | 雪权重 | 晴 |
|----------|--------|--------|----|
| Normal | 章节表 | 章节表 | 余量 |
| Elite | 略提高恶劣天气 | 同左 | — |
| Rest | **强制 Clear** | 0 | 100% |
| Boss | 章节主题天气或 Clear→进战后再起风雨 | 可脚本指定 | — |

**方式 B（二期）：局内动态**

- 某波刷怪后 20% 概率起雨/雪（需 Toast：「风雨将至」）。  
- 与昼夜过渡可叠：先变黑，再起雪。

### 4.3 轻数值（可选，表驱动）

| 天气 | 建议修正 | 文案提示 |
|------|----------|----------|
| 雨 | 火焰类伤害 -8%；电击/水系 +5%；地面移速 -3%（双方） | 「雨天：火焰减弱」 |
| 雪 | 移速 -5%（双方）；冰系 +8%；燃烧时长 -20% | 「雪天：行动迟缓」 |
| 晴 | 无 | — |

一期同样建议：**只做表现 + Toast 预告**，数值默认关。

### 4.4 与玩法系统的钩子（后续可接）

| 系统 | 钩子 |
|------|------|
| 天赋 | 「雨中行军」「冰原适应」：在对应天气下移速惩罚减免 |
| 装备词条 | 「防潮」「融雪」：小幅抗性 |
| 成就 | 「暴雨中通关精英」「雪夜击杀 Boss」 |
| 冒险日志 | 图鉴条目「裂缝气象」解锁文案 |

## 6. 表现规格

### 6.1 昼夜滤镜（推荐实现）

在战斗 UI / 世界相机上挂 **全屏 Color Grade Overlay**（UI Image 或 URP Volume，二选一；当前工程以 URP + 2D 为主，优先：

1. **方案甲（最快）：** 战斗场景加半透明全屏 `Image`（或 Sprite），按相位插值颜色与 alpha。  
2. **方案乙：** 统一调 `ParallaxBackground` 三层 `Image.color` + 单位 `SpriteRenderer` 乘色（注意血条/HUD 不乘）。

**相位色参考（可调）：**

| 相位 | 乘色近似 | Overlay alpha |
|------|----------|---------------|
| Day | (1,1,1) | 0 |
| Dusk | (1.05, 0.75, 0.55) | 0.18～0.28 |
| Night | (0.55, 0.62, 0.95) | 0.35～0.48 |

单位轮廓：黑夜时给英雄/佣兵/Boss 轻微自发光或描边，避免融进背景。

### 6.2 雨雪粒子

| | 雨 | 雪 |
|--|----|----|
| 发射区 | 屏顶外扩 | 屏顶外扩 |
| 速度 | 快、斜向（跟 facing 无关，略向镜头一侧） | 慢、带摆动 |
| 层级 | 在单位之上、HUD 之下（sorting 介于 Unit 与 UI） | 同左 |
| 上限 | Light 40 / Normal 80 / Heavy 120 | Light 30 / Normal 60 / Heavy 90 |
| 低端机 | Heavy→Normal；再降则只 Overlay 不加粒子 | 同左 |

资源建议目录：

```
Resources/VFX/Weather/
  rain_drop.prefab
  rain_splash.prefab   （可选）
  snow_flake.prefab
Audio/SFX/
  sfx_rain_loop.ogg
  sfx_snow_wind_loop.ogg
```

### 6.3 过渡动画时间线（Boss 示例）

```
T+0.0s  精英清场 / 传送门前
T+0.2s  Toast：「天色骤变…」
T+0.3s  开始 Dusk→Night 插值（2.8s）
T+1.0s  可选起 Weather（雨或雪，Light→Normal）
T+2.8s  相位锁定 Night；BGM 已是 bgm_boss
T+3.0s  Boss 入场 / 波次开始
```

玩家操作：过渡期间 **UnitsCanAct 可保持**（避免拖节奏）；若演出需要，可短冻 0.5s。

### 6.4 HUD 提示

- 进关左上或任务条旁小图标：☀ / 🌤 / 🌙 + 🌧 / ❄  
- 首次遭遇该天气：Toast 一行说明（可关「不再提示」）。  
- **不**做复杂气象面板。

## 7. 技术落地（对接现有代码）

### 7.1 建议新增类型

```csharp
public enum DayPhase { Day, Dusk, Night, Dawn }
public enum WeatherType { Clear, Rain, Snow }
public enum WeatherIntensity { Light, Normal, Heavy }
```

### 7.2 建议组件 / 类

| 类 | 职责 |
|----|------|
| `BattleAtmosphere` | 单例或挂在 Battle 场景；持有当前 DayPhase / Weather；对外 `SetPhase` / `SetWeather` / `TransitionTo` |
| `DayNightOverlay` | 滤镜插值 |
| `WeatherVfxController` | 雨雪粒子与循环音效 |
| `StageAtmosphereTable` | 静态表：章节 × StageType → 权重或固定配置 |
| `BattleManager.LoadStage` | 进关调用 `BattleAtmosphere.ApplyForStage(stage)` |
| Boss 流程 | 在刷 Boss 前协程里 `TransitionTo(Night, 2.8f)` |

### 7.3 与视差背景

- **不要**为昼夜复制三套背景图（包体爆炸）。  
- 一律用乘色 / Overlay；章节图仍走 `BattleBackgroundRegistry`。  
- 若某章美术有「夜景专用远景」，可作为二期可选替换 `backLayer` 一张图。

### 7.4 存档

- **不需要**写入永久存档（每关重 roll 或按表）。  
- 若做中断续关：再把 `DayPhase/Weather` 写进 `BattleState`（当前软著口径不强调续关）。

### 7.5 设置项

战斗设置增加：

- 「天气特效」开/关（关则无粒子，可保留轻度滤镜）  
- 跟随全局「声音」：雨雪循环算环境音，受同一开关影响

## 9. 分期实施

### P0 — 可玩预览（约 3～5 人日）

1. `DayNightOverlay` 三相位 + 平滑过渡 API  
2. 雨、雪各一粒子预制体 + 循环音  
3. `BattleManager` 进关按章节表套用；Boss 进战前强制 Night 过渡  
4. Toast + 小图标  
5. 引导战强制 Day+Clear  

### P1 — 表驱动与关卡差异

1. `StageAtmosphereTable`（CSV/ScriptableObject）  
2. 轮盘 UI 可选显示天气小标（非必须）  
3. 低端机降级  

### P2 — 轻数值与养成钩子

1. 天气/昼夜修正开关与数值表  
2. 天赋/词条/成就接入  
3. Boss 击杀黎明过渡

1. 可选夜景远景图

## 10. 验收清单

**表现**

- [ ] 白↔黑过渡肉眼可见，无闪屏、无 HUD 被乘色  
- [ ] 雨/雪粒子不遮挡血条与技能头像  
- [ ] Boss 进战有完整昼夜过渡时间线  
- [ ] 恢复关始终晴朗白日  
- [ ] 引导战无雨雪、无黑夜  

**系统**

- [ ] 切换章节背景后大气仍正确  
- [ ] Loading / 静音时雨雪循环音跟随 `GameAudio`  
- [ ] 关闭「天气特效」后无粒子且无报错  

**性能**

- [ ] 中端机 60 档不掉到因粒子卡顿（Heavy 档可测）  
- [ ] 对象池回收，切关无泄露  

**玩法（若开启数值）**

- [ ] Toast 与实际修正一致  
- [ ] 伤害统计/日志可核对（调试用）

## 11. 风险与对策

| 风险 | 对策 |
|------|------|
| 滤镜误伤 UI | Overlay 挂在世界/背景层，或 UI 用独立 Canvas 且不受 Volume 影响 |
| 粒子挡住点击 | Weather 层 `raycastTarget=false`；排序低于 HUD |
| 与剧情黑场叠两层黑 | 大气与 `TownIntroVeil`/对话黑场互斥或降低 alpha |
| 包体与电量 | 粒子图集小；低端关粒子 |
| 玩家觉得「又暗又看不清」 | 黑夜给单位描边；设置可关天气 |
