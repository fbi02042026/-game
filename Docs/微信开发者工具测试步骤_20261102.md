# 微信开发者工具测试步骤（2026-11-02）

> 用途：主人在家自测微信小游戏构建。逐步照做即可。
> 依据：工程实际配置（`Assets/Settings/Build Profiles/New WeChat Profile.asset`、`Builds/wechat/` 产物、`Packages/manifest.json`）+《微信小游戏上线检验报告_20261102.md》的 V1-V10 清单。
> 标注约定：**「需确认」** = 静态查不到、以实际界面为准，不要当成手册写错。

## 第 1 步 · Unity 侧构建前检查（关键，约 5 分钟）

1. **启用 Town/Battle 场景**（本工程当前最大坑，必须先做）：
   - 菜单 **File → Build Settings**（团结中文版可能叫「文件 → 构建设置」，需确认译名）。
   - 场景列表里确认三行都在且**全部勾选**：
     - `Assets/Scenes/Boot.unity` ✅
     - `Assets/Scenes/Town.unity` ← 当前是**未勾选**状态，勾上
     - `Assets/Scenes/Battle.unity` ← 当前是**未勾选**状态，勾上
   - 依据：`ProjectSettings/EditorBuildSettings.asset:8-16` 现状 Town/Battle `enabled: 0`。不勾 → 转换产物里没有这两个场景 → 进主城必失败。
2. **切换构建目标**：同一窗口左下平台列表选 **WeChat MiniGame**（微信小游戏）→ 点 **Switch Platform**（切换平台）。首次切换要重导资源，等它跑完。
3. **Build Profile**：若界面有 Profile 选择，选 **New WeChat Profile**（`Assets/Settings/Build Profiles/` 下那个）。其中已是：竖屏、MemorySize 256、代码优化开、`iOSHighPerformance` 开——**都别动**。
4. **不要动的设置**（测试包铁律）：`ProjectSettings` 的 `bundleVersion` / `AndroidBundleVersionCode` 一字不改；`compressDataPackage` 这次**先不勾**（CDN 未配，勾了本地预览反而多一层解压变量，留到 T4）。

## 第 2 步 · Unity 侧出包（约 10-30 分钟，视机器）

1. Build Settings 窗口点 **Build / Build And Run**（或转换面板的「导出/转换」按钮，**需确认**按钮名）。
2. **输出目录选 `Y:/PixelAdventureTown/Builds/wechat/`**（P0 实测产物就在这个目录；Profile 里写的 `Y:/PixelAdventureTown/minigame` 是旧默认值，以面板上的导出路径字段为准，**需确认**面板当前值）。
3. 等转换完成。完成后核对产物结构（对照 P0 实测）：
   - `Builds/wechat/minigame/` ← 代码包侧（开发者工具导入的就是它）
   - `Builds/wechat/webgl/` ← 数据侧（本地预览用，不用管）
   - `minigame/game.json` 里应有 `UnityPlugin 1.3.14` + `wasmcode` 分包 + `parallelPreloadSubpackages`

| 失败症状 | 最可能原因 | 先查哪里 |
|---|---|---|
| 转换报错/红字 | 代码编译错误或 SDK 版本问题 | Unity Console 第一条红字；SDK 锁版 `Packages/manifest.json:3` |
| 产物里没有 Town/Battle | 第 1 步场景没勾 | `EditorBuildSettings.asset` 两场景 enabled |
| 主包远超 4MB | UnityPlugin 没启用 | 产物 `game.json` 的 `plugins` 段（P0 实测主包 0.99MB 属正常） |

## 第 3 步 · 导入微信开发者工具（约 5 分钟）

1. 打开微信开发者工具 → 左侧选 **小程序/小游戏** → **导入项目**（不是新建）。
2. 目录选 **`Y:/PixelAdventureTown/Builds/wechat/minigame/`**（注意是 minigame 子目录，不是 wechat 根目录）。
3. AppID 栏应自动读出 `wx37eb4c2fee0fecf8`；若空白就手填。项目名称随意。
4. 导入后先开一个设置：**右上角「详情」→「本地设置」→ 勾「不校验合法域名…」**（产物 `project.config.json` 里 `urlCheck: false` 通常已带此效，勾上双保险）。
   - 就地提示：不勾的话会看到一条 `gitee.com 不在 request 合法域名列表` 的报错——**这是已知现象不是 bug**（AdKillSwitch 远程广告开关拉 gitee 必失败，代码已按「失败保持现状」设计，见 `Assets/Scripts/Platform/AdKillSwitch.cs:51-62`）。

| 失败症状 | 最可能原因 | 先查哪里 |
|---|---|---|
| 导入报「AppID 不合法/无权限」 | 用了测试号或登错微信 | 换 `wx37eb4c2fee0fecf8` + 有该小游戏权限的微信号 |
| 启动白屏 + 插件报错 | UnityPlugin 未声明或插件未审核通过 | `minigame/game.json` plugins 段；工具「详情→基本信息」插件列表 |
| 编译报 framework.js 相关错 | 开发者工具版本太旧 | 升级到最新 Stable 重导 |

## 第 4 步 · 模拟器逐项验证（V1-V10，核心环节，约 40 分钟）

> 每项 = 操作 → 通过标准 → 失败先查哪里。🔴=不过就停下来排查，🟡=记录后继续，🟢=顺手看。
> 全程开着底部 **Console** 面板。

**V1 🔴 场景进包（第一个测）**
- 操作：启动 → 登录页点「开始冒险」进主城 → 冒险页选一关进战斗。
- 通过：登录→主城→战斗三场景都进得去，Console 无 `Scene ... couldn't be loaded`。
- 失败查：`EditorBuildSettings.asset` 场景勾选状态（回第 1 步）；`GameSceneManager.cs:61-121` 加载链路。

**V2 🔴 Console 零红字**
- 操作：V1 全程盯 Console。
- 通过：零红字。黄字 Warning 里 `[AdKillSwitch] 拉取失败` 属已知预期（域名白名单未配），不算问题。
- 失败查：第一条红字截图留证；疑似裁剪问题看是否提到某类型序列化；音频 Missing 见 V6。

**V3 🔴 存档读写与恢复**
- 操作：打一场战斗领到奖励 → 工具栏「模拟操作」→「切后台」→ 再「关闭」模拟器 → 重新编译启动。
- 通过：金币/钻石/关卡进度都在。
- 失败查：Console 有无 IO 异常；`SaveSystem.cs:90-140`（损坏恢复）、`CloudSaveBridge.cs:31-34`（沙箱写盘）。就地提示：**云存档是本地镜像**（`UseWeChatCloud` 是占位），换设备丢档是已接受口径，别误判成 bug。

**V4 🔴 切后台/回前台**
- 操作：战斗中途「模拟操作→切后台」→ 5 秒后「切回前台」。
- 通过：战斗继续、不卡死、体力计时正确。
- 失败查：`GameSceneManager.cs:26-34`（onHide/onShow 映射）；若全场定格查剧情 timeScale 残留。

**V5 🟡 视频跳过守卫**
- 操作：清档（工具「清除数据→全部」或用游戏内清档重置）→ 从头进。
- 通过：开场/登录视频**直接跳过**到登录页，无黑屏等待。
- 失败查：`UNITY_WECHATMINIGAME` 宏未生效 → 构建目标没切对（回第 1.2 步）；`OpeningIntroOverlay.cs` / `LoginIntroSplash.cs`。

**V6 🟡 音频播放**
- 操作：主城听 BGM → 战斗听打击音 + 胜利/失败 Sting。
- 通过：出声正常无爆音；重点听战斗胜利/失败（11-02 换发 guid 的 8 个音频）。
- 失败查：哪条音 Missing 记哪条 → 按口径修 guid 或预制体重拖（禁止兜底）；若全部无声查系统音量/工具静音钮。

**V7 🟡 触摸与 UI 适配**
- 操作：工具左上角机型下拉换 iPhone X（刘海）+ 一个 20:9 瘦长屏，各走一遍主城/战斗。
- 通过：按钮都可点、顶栏不躲进刘海、右上内容不被微信胶囊遮挡、底栏不超屏。
- 失败查：`SafeAreaFitter.cs:45`（胶囊坐标拿不到时按常量预留，个别机型偏差真机再核）；`UICanvasSetup` 统一出口。

**V8 🟡 广告占位行为（空窗期口径，预期就是"看不了广告"）**
- 操作：点主界面右列「看视频领钻」、顶栏金币/体力加号。
- 通过：弹「暂未开放」或钻石档确认框（50/100 钻），**无报错不卡死**；这是 `PlatformClosed=true` + `ADS_ENABLED=false` 的设计表现（`RewardedAdBridge.cs:34`、`GameConfig.Progression.cs:103`），**不是 bug**。
- 失败查：哪个入口直接无响应/报错 → 该入口没接总闸，记下来。

**V9 🟢 转发（无奖励，合规版）**
- 操作：点模拟器右上角胶囊「…」→ 看「转发」项；顺手确认胜利结算界面**没有**分享按钮（分享得钻已于 11-02 下线）。
- 通过：转发卡片标题「割草爆装，招募佣兵，技能流派自由搭，一局 5 分钟」+ 封面图；全程不发任何奖励。
- 失败查：Console 有无 `[WeChatShare]` 红字 → `WeChatShare.jslib` 是否随包、封面图 meta 的 isReadable 是否开。

**V10 🟢 性能与首屏基线**
- 操作：Performance 面板看战斗帧率；秒表记「启动到登录页可点」时长。
- 通过：战斗不卡（30fps 口径）；时长记个数留档即可——**本地预览加载 103MB data 慢是已知现象**（`compressDataPackage` 未勾 + CDN 未配，T4 项），别误判成 bug。

## 第 5 步 · 真机预览（约 15 分钟）

1. 开发者工具工具栏点 **「预览」** → 手机微信扫码。
2. 真机复跑这 5 项（模拟器与真机差异最大的）：**V3 存档恢复**（杀微信进程重进）、**V4 切后台**、**V6 音频**、**V7 胶囊/刘海避让**、**V9 实际转发一次看卡片**。
3. 其余项模拟器过了即可，真机不必重复。

| 失败症状 | 最可能原因 | 先查哪里 |
|---|---|---|
| 扫码后长时间卡加载 | data 103MB 走局域网传输慢 | 等；正式对 <8s 目标等 T4 CDN 后测 |
| 真机无声 | iOS 静音开关 / WebAudio 解锁需首次触摸 | 关静音、先点一下屏幕 |
| 真机胶囊遮挡 UI | 常量预留与实际机型偏差 | `SafeAreaFitter.cs:45`，截图回报 |

## 第 6 步 · 测完收尾

1. 把 V1-V10 结果（过/不过 + 红字截图）记到 `Logs/` 或直接在冲刺清单 T1 打勾。
2. **Unity 里把 Build Settings 切回原平台**（避免污染安卓配置，P0 清单回归红线）。
3. Town/Battle 的勾选**保留**（正式出包也需要）；如因此产生 `EditorBuildSettings.asset` 改动，提交时带上即可。
4. 全部通过后，下一棒是冲刺清单 T2（资源搬家）→ T3（ASTC）→ T4（压缩+CDN）。
