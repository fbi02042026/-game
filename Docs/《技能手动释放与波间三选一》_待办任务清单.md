## 2. 目标

1. 技能默认自动（现状零变化），HUD 给一个「自动 / 手动」开关。
2. 手动模式下 4 个技能头像可点：冷却中置灰、就绪高亮；点了才放，不点不过期。
3. 手动与自动走**同一个释放函数**，`player_skills.csv` 与 `GameConfig` 一个字不动。
4. 每跨一个大波（场清）给一次技能三选一；开局给一次。
5. 流派系统不动；难度第一版不上调。

## 3. 任务清单

### T1 自动 / 手动开关

**T1.1 状态位（新增）**
- 建议挂在 `Assets/Scripts/Config/MercSkillMigrate.cs` 同款位置附近，或新建 `Assets/Scripts/Config/PlayerSkillCastMode.cs`。
- `PlayerPrefs` 键 `settings.player_skill_manual`，`0 = 自动（默认）` / `1 = 手动`。
- 单一出口：`IsPlayerSkillManual()` / `SetPlayerSkillManual(bool)`。**禁止**其他文件直接读这个 PlayerPrefs 键。
- 清档复位要接进 `Assets/Scripts/Core/NewGameReset.cs → ApplyAll()`（进程级状态统一复位口）。

**T1.2 自动链加闸（一行级改动）**
- `PlayerSkillPassive.cs:230` `TickAutoCast()` 开头加：手动模式直接 `return`。
- 只加这一处。**不要**在 `FindReadySkillSlot` 里加开关判断 —— 那里是「判定哪个槽能放」，不是「谁扣扳机」，混在一起手动模式会连自己都放不出来。

**T1.3 手动入口（新增方法）**
- `BattleManager` 新增 `TryUsePlayerSkillAt(int slot)`，入口补四道闸（`TryUsePlayerSkillSlot` 自身不查这些）：
  - `!UnitsCanAct` → `return false`
  - `IsTutorialRun` → `return false`（引导局锁死自动）
  - `BattleLootMode.Active` → `return false`
  - `CareerSkillExecutor.IsCharging` → `return false`
- 通过后调 `SkillCast.TryUsePlayerSkillSlot(slot)`。
- **禁止**复制 `SkillCastService` 里任何校验逻辑，也不要新写释放分支。

**T1.4 UI**
- 技能栏加「自动 / 手动」切换（位置见 §4 待确认 1）。
- 手动模式下 4 个头像变可点；冷却读秒中置灰不可点；就绪时高亮。
- 切换后立刻生效，不重开关卡、不重进战斗。
- 复用 `Assets/Scripts/UI/BattleUI.Skills.cs` 现有头像与冷却显示，不新做一套。

**验收**
- 自动模式行为与本版逐帧一致（回归零变化）。
- 切手动后技能不再自己放；点头像能放并正常进 CD / 扣蓝。
- 引导局、领奖模式（`BattleLootMode`）、冲锋中、`UnitsCanAct=false` 时点头像无效。

## 5. 难度判据（第一版不上调，看这三个数再决定）

| 指标 | 危险线 | 说明 |
|---|---|---|
| 单波清怪时长 | < 8 秒 | 低于此值说明一轮推平，观感变闷 |
| 通关率 | > 95% | 高于此值说明强度超了 |
| 三选一跳过率 | > 30% | 玩家开始不选，说明技能已过剩 |

**真要提，提「压力」不提「血量」**：加同屏怪密度、提前出精英，**不动**怪的血量和攻击 —— 血量提高只是打得更久，观感更差。
