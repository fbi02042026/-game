## 二、架构校验点（落地前必对）

1. **只动攻击两列**：HP / 攻速 / 移速 / 射程 / 金币 / 经验一律不动。最终攻击 = `baseAtk × chapter_stat_scale × stage_stat_scale`，改 base 即全口径 +20%，不会误伤血量。
2. **不动倍率表**：`chapter_stat_scale.csv` / `stage_stat_scale.csv` 一律不改（否则血量也跟着涨，违背「只提攻击」）。
3. **不动全局常量**：`GameConfig.MONSTER_*` 全局难度常量不动（那是全章生效，会波及第 3~8 章）。
4. **Boss 行是否包含**：默认方案含 4 个 Boss 行（forest_111/112、undead_211/212，28/30 → 33.6/36.0）。若主人只想要小怪、不要 Boss，落地时剔除这 4 行即可。
5. **数据链路**：`monster_stats.csv` 由 `GameDataCooker.CookMonsterStats` 烘焙为 `Config/monster_stats`，运行时读 cooked 资源而非原始 CSV —— 改完必重导，否则游戏内数值不生效。
