# 《英雄没有闪》玩法拆解与借鉴分析

> 分析对象：墨麒麟工作室《英雄没有闪》（竖屏横版卷轴 · 放置 ARPG 刷宝，非同名 FPS）。
> 对照项目：《像素冒险：裂隙之刃》。
> 结论口径：只挑**能落地**的，按「A 可直接做 / B 需策划确认 / C 只记录不推荐」分级。

---

## 一、它到底是什么

一句话：**放置挂机（减负）+ 暗黑刷宝（深度）的双核**。
竖屏横版卷轴、卡通中世纪暗黑风、自动战斗割草，玩家几乎不需要操作；
策略密度全部压在「技能符文 × 暗能套装 × 侍从光环」的**构筑**上。

核心循环：

```
推图（自动战斗，一波波小怪 → Boss）
   ↓ 掉装备
穿装备 / 分解多余装备 → 奥术结晶 → 升「祝福」→ 后续掉率与品质变好
   ↓ 消耗混沌石（每颗 = 一次强力技能；用完必须回营地）
等级 / 头衔（头衔卡等级上限）→ 解锁更高装等
   ↓
每日副本补充资源：挖矿 / 首领讨伐 / 威能秘境 / 奶牛牧场
```

## 二、系统拆解（值得抄的部分）

| 系统 | 它的做法 | 为什么有效 |
|---|---|---|
| **技能 5 分类** | 被动 / 基础（输出）/ 核心（输出）/ 掌控（辅助）/ 终极（增益） | 玩家一眼看懂「我在凑什么」；构筑有骨架，不是乱堆数值 |
| **符文改形态** | 同一技能配不同符文变体（原力锤 1 / 2、狂战 1…） | 同一个技能玩出几种手感，深度不靠加新技能，靠已有技能的组合 |
| **混沌石** | 每用 1 颗放 1 次强力技能，用完就得撤回营地修整 | 给「无限自动战斗」装了一个**节流阀**，也是关卡节奏与撤离动机 |
| **侍从光环** | 侍从不是只打人，出战即给全队光环（护盾 / 免伤 / 增伤 / 暴击），按流派分 T0–T2 | 佣兵从「多一个打手」变成**流派的一部分**，养成有方向 |
| **流派成型** | 雷旋风 / 痛割流血 / 冰锤控制 / 反伤陀螺；61 级解锁双流派切换 | 长线目标 + 身份感，玩家会说「我是玩流血的」 |
| **实时分档掉落** | 怪越强掉的品质越高，装备现打现分 | 爽感即时，不用回城鉴定 |
| **分解 → 祝福** | 多余装备不废，分解成结晶升祝福，提高后续掉落质量 | 垃圾有出口，形成「打 → 分 → 更强 → 打更好」的正循环 |
| **每日副本分桶** | 挖矿（混沌结晶）/ 首领讨伐（灵魂石）/ 威能秘境（套装宝石）/ 奶牛牧场（混沌石） | 每天上线有事干，且每件事对应一种明确资源 |
| **掉落演出** | 「kuku 掉光柱」 | 竖屏小屏上也一眼看见收获，爽感主要来自演出而非数值 |

## 三、对照本项目：哪些能直接拿

### A 级 · 低风险、可直接做

**A1. 佣兵「光环」——把佣兵从打手变成流派零件**
现状：22 个佣兵（H001–H022）只有「主动技能 + 被动」，`MercenaryManager` 只管出战与技能。
建议：出战即给全队一条光环（如维克 = 减伤、凯恩 = 终伤、米娅 = 暴击、索菲 = 回血效率），
并按现有 `SynergyTag` 绑定流派（已有势能系统：2/5/9 点 → 1/2/3 级 → 伤害 ×1.08/1.18/1.32）。
**复用成本最低**：势能表已经能算出流派等级，光环只是把它从「只加伤害」扩展到「加队伍属性」。

**A2. 掉落演出强化**
现状：装备掉落有分解/穿戴流程，但缺少「打到好东西」的瞬间反馈。
建议：稀有度 ≥ 某档时给光柱 / 音效 / 短暂定格。竖屏小屏尤其吃这一套，投入小、体感提升大。

**A3. 分解产物的长期出口（祝福等级）**
现状：已有 `decomposeMatText`（分解材料）。
建议：材料升「祝福等级」→ 提高后续掉落品质。让分解这件苦差事有明确回报，和 A2 配套。

### B 级 · 需要你拍板（会动到节奏）

**B1. 混沌石 → 战斗资源阀门**
它的混沌石是「有限次大招，用完必须回城」。本项目已有撤离/续关（`RunLoadout` 撤离即作废）。
可以引入「裂隙能量」：每关 N 次强力技能，用完只能撤离。
**风险**：会明显改变现在的「一局能打多久」，直接决定单局时长与体力曲线，**必须你先定单局时长目标**。

**B2. 技能符文（改形态，不改数值）**
现状：局内技能只有「星级」一维（`RunLoadout.StarOf`）。
建议：给技能加 1 个符文位，符文改的是**形态**（单体/范围、附带流血/减速、触发条件），星级继续管数值。
与它「原力锤 1 / 2」同理，深度来自组合不是堆数。
**风险**：技能描述与图标都要配套，美术工作量要看你手上素材。

**B3. 每日 / 每周特殊关分桶**
现状：章节推进 + 分叉 + 已有金币关（`IsGoldDungeon`）。
建议：把「金币关 / 首领讨伐 / 材料秘境」做成明确的每日限次入口，每种对应一种资源。
**风险**：要做一套每日次数与重置逻辑，且会稀释主线存在感。

### C 级 · 记录但不建议照抄

- **离线挂机收益**：它的卖点是「摸鱼也能涨」。本项目卖点是**手动横版推进 + 局内构筑**，
  给离线收益会让在线战斗贬值，两头不讨好。
- **头衔卡等级上限**：典型的留存墙，短期拉时长、长期劝退，和「构筑爽游」的调性冲突。
- **侍从抽卡池 / 觉醒石 / 双卡氪金**：商业化结构，和本项目当前形态无关。
- **PVP 竞技场**：匹配、平衡、反作弊成本极高，收益不确定。

## 四、最该学的一句设计原则

> **减负不减策略。**

操作全交给自动战斗，但把决策压在构筑上：技能分类清晰、符文改形态、侍从光环成型流派、
每局抽到什么就临时决定往哪条路走。

本项目其实**已经在走同一条路**——技能自动释放（`PlayerSkillPassive` / `MercSkillCaster`）、
玩家决策点在「抽卡构筑 + 拖拽调释放优先级 + 佣兵搭配」，波次也是每关现摇原型（`StageModeTable` + `WaveArchetypeTable`）。
所以方向是对的，差的不是框架，是**让玩家看得见自己的选择**：

1. 光环/流派要**显式展示**（现在势能只有伤害倍率，玩家感知不到）；
2. 波次差异要**播报出来**（本次已做：预告条显示「第 N 波 · 箭雨：远程压制 — 近战顶住，远程先点」）；
3. 掉落要有**演出**和**出口**（A2 + A3）。
