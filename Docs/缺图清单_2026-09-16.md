## 这是什么

预制体/场景里某个 Image / SpriteRenderer 的 `m_Sprite`（或 `m_Material`）记录的
guid，在工程里**已经找不到对应的图片/材质**。这些 guid 在本地 `Assets`、`Packages`、
`Library/PackageCache` 的所有 `.meta` 里都不存在（扫描了 15409 个 guid），属于历史遗留
（图片被删或被替换过）。

**重要：「磁盘上找不到 guid」不等于「Unity 里现在显示缺图」。** 你在 Inspector 里看到图
正常，可能原因是：
1. Unity 当前 `Library/` 缓存还保留着这些旧 guid 的映射；
2. 代码在运行时会重新给这些 Image 赋 sprite，Inspector 里的引用只是占位；
3. 对应节点本来就隐藏或未启用。

所以本清单是**潜在风险清单**（一旦 `Library` 重建或缓存丢失，这些位置可能变白块），
不是「当前已经坏掉」的清单。按节点路径检查过后如果确认运行无影响，可以先搁置。

## 怎么修（三种办法，按推荐顺序）

1. **确认无用 → 清掉组件**：在 Unity 里按上表的对象路径找到节点，
   若该 Image 根本不该有图（或整段 UI 已废弃），直接清空/删除该组件。
2. **确认该有图 → 重新拖图**：在 Inspector 里把正确的 Sprite 拖进 Source Image 字段，
   保存预制体即可（guid 会由 Unity 写对）。
3. **先不管**：界面实测正常就先放着，等真发现某处图不对再回来查表。

> 注意：动预制体前先关掉团结引擎，或确认当前没有别人在编辑同一个 prefab。
