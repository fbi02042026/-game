## 一、需求清单（主人 2026-10-29 拍板原话整理）

1. **实时抽奖**：只有战斗里的抽奖币抽奖，抽奖按钮常显，抽奖时**不冻结**战斗，抽了立即生效。
2. **技能**：获得弹窗降级为**横幅**（不再弹 SkillObtainPopupUI 模态窗）。
3. **装备**：该部位**没有装备 → 自动穿上 + Toast**；需要替换 → 照旧弹窗。
   （⚠ 推翻 2026-10-14「抽中装备一律弹替换确认」的拍板，RunDraftDirector.cs:400）
4. **抽奖 CD**：每次点完抽奖加 **5~10 秒** CD，防连点（默认取 8 秒，常量可调，待主人定值）。
5. **不再出现抽奖界面动画**：进关抽奖大面板的展开动画没有了（进关面板去留见待确认①）。
6. **没有回合间了**：波清后不再弹抽奖窗，改为 **5 秒倒计时** → 下一波出现。
7. **适用范围**：正式主线关 + 金币本改实时抽；**无限裂隙保持原设定**（进关面板/每波弹抽照旧）。
8. 击杀直发抽奖币（10/25/50）**不动**——实时抽下币随时能花，无死钱窗口。

## 二、改动点明细

### A. 实时抽入口（新增）

**文件：`Assets/Scripts/Managers/BattleManager.Settlement.cs`（或新建 partial）**

- 新增公开入口 `TryLiveDraw(DraftCategory? cat)`（cat=null=随机，有值=定向），内部流程：
  1. 守卫（全部拦截 + 原因 Toast/Log，不静默）：
     - `IsTutorialRun` → 引导局禁用（三拍节奏走旧面板，不被抢拍）；
     - `IsEndlessRift` → 裂隙禁用（保持原设定，走旧面板）；
     - `BattleEntryDraftPanel.IsLotteryOpen / _draftActive` → 面板展开中禁（裂隙进关/波间面板打开时）；
     - `_runClosed / _rewardSequenceStarted / _stageCleared` → 局已收尾/通关链已启动禁（防与宝箱/剧情叠场）；
     - CD 中 → 禁；
     - `SlotMachineSystem.AvailableCategories()` 空 → LogError（铁律 12）。
  2. 算价：`DrawPrice()` / `DrawFocusPrice()`（唯一出口，不另写算式）；免费额度 `FreeDrawsLeft()` 只惠及随机抽。
  3. 余额检查 `CanAffordDraw`（复用），不足 → 按钮侧已置灰，这里兜底 Toast。
  4. 「再来一次」：随机抽先掷 `RollReroll()`（照旧），命中 → `GrantBonusFreeDraw` + 横幅，不起 CD 不扣币。
  5. `CoInstantPick(target, cost)` 直抽（协程，复用全部保底/计数/生效链路）。
  6. 生效后起 CD：`_liveDrawCdUntil = Time.unscaledTime + LIVE_DRAW_CD_SEC`。
- 新增常量 `LIVE_DRAW_CD_SEC = 8f`（主人定 5~10）。
- ⚠ `CoInstantPick` 里的「等获得弹窗关闭」循环（:1060-1067）：技能降级横幅后该分支立即回调，不阻塞；
  装备替换弹窗保留模态等待（玩家决策期间战斗继续跑，已拍板接受）。

**文件：`Assets/Scripts/UI/BattleEntryDraftPanel.cs` / `.Flow.cs` / `.Refresh.cs`**

  - `SetLiveMode(true)`：`Build()` 后把 DraftRoot 从收起位（PosY -400）抬到**常显位**（坐标实测定，
    面板保持 600 收起高、zhuangshi 内容不动、map 停 250 不抬——没有展开动画）；
  - 四个抽奖按钮 onClick 直调 `BattleManager.TryLiveDraw(cat)`（不走 Begin/Show/倒计时/继续链路）；
  - 每次抽完（生效回调）重刷 `Refresh`（价格/余额/置灰）+ 启动 CD 显示（按钮置灰 + 剩余秒数）；
  - `_draftActive`（裂隙旧面板展开）时隐藏常显按钮（防两排并存）。
