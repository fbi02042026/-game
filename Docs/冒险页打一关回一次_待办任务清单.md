# 冒险页「打一关回一次」改造任务清单

> 2026-10-22 主人拍板并当次落地。本文档记录新流程口径、改动清单与验收点，供跨机回溯。

## 口径（主人拍板）

1. **打一关回一次**：主线普通关（非章末 Boss）通关 → 不弹战斗内结算 → 直接回冒险页；
   构筑 / 局内金币池**不结束本局**，下次进本从「最后通关的小关 +1」续打。
2. **奖励弹窗**：回到冒险页自动弹「获得奖励」，内容 = 本关实际掉落（与战斗结算同账，不新造数值）。
3. **体力**：主线 10 → **5 /次**；无限裂隙 20 → **10 /次**。
4. **宝箱节点**：冒险页地图上每章 10 小关宝箱（木/银5/金10），已通关=开启、当前进度=关闭、未打=未解锁；
   窗口 4 个、首尾 α0.7，位置缩放以预制体 `RightContent/关卡` 为准。

## 新流程链路

进本（5 体力）→ 打当前小关 → 传送门 → 关末金币落盘 → 首通记 `AdventureRewardNotice`
→ 直接回冒险页（局保留，`runGold` 带池子）→ 宝箱变开启 + 自动弹「获得奖励」
→ 再点开始冒险 → 续局从下一关进（池子还原，启动金不重发）→ … → 第 10 关（Boss）→ 原结算 → 回城（局结束）。

## 边界行为（实现口径，主人可否决）

- **换章 / 进无限裂隙 / 进金币本**：parked 局作废（`RunLoadout.Clear`），裂隙与金币本独立进本。
- **重复打已通关的小关**：不再弹奖励弹窗（弹窗只挂首通），宝箱保持开启。
- **中途死亡 / 撤离**：走原死亡/撤离结算，局照旧作废。
- **第 10 关 Boss**：原双钮结算不变（下一章直进 / 返回）。
- **进程被杀**：parked 局在 PlayerPrefs 里仍 active，下次启动进本会续（含跳关）；弹窗队列丢失（展示层，不入档）。

## 验收点（待主人进游戏）

1. 打完 1-1 回冒险页：1-1 宝箱开启、底部弹「获得奖励」；再进本从 1-2 开始、金币池延续。
2. 同章连打体力每次扣 5；裂隙进一次扣 10。
3. 中途换章再进：旧局作废、新章从 1-1 开始。
4. 打满 10 关：原章末结算正常，回城后整章宝箱全开。
