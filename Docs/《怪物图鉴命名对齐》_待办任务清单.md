## 4. 待主人确认的命名口径（「风格一致 / 不违规」按这套执行，有出入请直接改）

1. **长度 ≤ 7 个汉字**（项目既有偏好：命名 ≤7 汉字、结果先于隐喻）。
2. **名字意象必须和该格图片对得上**——不许「看着像水却说生活在沙漠」；表里 B 类是重点。
3. **不与现有 96 个名字重复**，同章内不出现近似名（如「冰晶虫 / 冰晶狼 / 冰棱蝙蝠」要拉开）。
4. **调性**：有趣、年轻、口语活梗，别端着别书面腔（参考项目台词调性 10-16 拍板）。
5. **合规**：不含现实宗教 / 政治 / 血腥 / 恐怖敏感词，不含品牌 / 真人 / 版权角色名；不发违规承诺。项目已有的「死灵法师 / 骸骨领主」等暗黑向名字属既有内容，不主动升级尺度。
6. **一处名字两处落**：图鉴 `Name` 与 `monster_stats.csv` 的 `name` 必须一致，改表后同步 `.bytes`。
