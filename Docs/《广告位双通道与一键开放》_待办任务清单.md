## 二、双通道机制（一句话版）

每个点位只问一句 `AdGateway.Ready`：true 走广告（免费），false 原样走钻石（= 改动前线上行为）。
**广告失败不发奖也不扣钻**；玩家再点一次即可按当时状态重新选路。

## 三、以后接安卓广告 SDK 时改哪里（一键开放）

1. 接好 SDK 后，只改 `AdGateway.PlatformCanPlay` 的正式包分支（`#else` 里）：
   `return false;` → `return 新桥的就绪判断;`（如 `TapAdBridge.IsReady` 或「已初始化 && 广告位 id 非空」）。
   **改这一行 = 全项目广告通道开放，业务点位零改动。**
2. 临时关广告（不用出包）：`AdGateway.Enabled = false`；全项目急停：`RewardedAdBridge.PlatformClosed = true`。
3. 主界面 / 编辑器注意：编辑器与开发包 `Ready` 恒 true（走 `RewardedAdBridge` 本地模拟），**正式包不受影响**。

## 四、新点位接入方法（以后照抄）

1. placement 常量登记在 `AdGateway`（现有 `PlacementMercRefresh` / `PlacementBagCell`），禁止业务里散字符串；
2. 业务里 `if (AdGateway.Ready) { AdGateway.TryWatch(AdGateway.PlacementXxx, ok => {...发奖...}); return; }`，后面原样保留钻石通道；
3. 发奖成功后调 `Analytics.AdSlotClick(placement, true)`；回调内**必须重对**当日计数/跨天（照 `CommitAdRefresh` 口径），绝不超发；
4. 消耗型特权（刷新、抽取类）广告发奖**必须照占既有日计数**，否则可无限白嫖；一次性解锁类（格子）不用计数。
