## 1. 一句话玩法与核心循环

竖屏横版自动跑酷：玩家一直往右跑（世界向左卷），**唯一操作是「跳」**，跑 / 攻击 / 拾取全自动；吃金币得经验并升级，佣兵从天上加入队列替玩家挡伤害，怪从右侧成波进来；看一共跑了**多少米**，结算把本局金币带出去。

核心循环：无限赛道生成 → 单指跳（躲怪 / 进门 / 换人）→ 自动攻击与拾取 → 里程 + 金币 + 经验 → 3 滴血归零 → 结算发奖 → 一键再来。

### 2.2 操作与队列（B 方案）

| 项 | 定稿 |
|---|---|
| 操作 | 单指点屏幕任意处 = 跳；其余全自动；空中不攻击、不碰撞 |
| 跳跃 | 高 180 px / 滞空 0.8 s / 落地硬直 0.2 s / 输入缓冲 0.15 s |
| 生命 | **玩家 3 滴血**，顶部 3 颗爱心（`UI/Art/Icons/表情包/爱心.png`），死一次变一个空心 |
| 队列 | `[佣兵1, 佣兵2, 玩家]`，**玩家永远在最后**；最多 2 佣兵，再吃按 FIFO 顶替最早的 |
| 顶替槽位 | 新佣兵落到**被顶替的槽位（前 1）** |
| 入场/退场 | 新佣兵从天上 0.35 s 落到指定槽位（落地期间不参与碰撞）；被替换的**往后跳出队列消失 0.4 s**；受击是**往前弹飞**（两种表现分开）；补位平滑 0.25 s 不瞬移 |
| 受击 | 有佣兵 → 最前佣兵弹飞消失、**不扣血**；没佣兵 → 玩家扣 1 颗；掉沟 → **直接扣玩家 1 颗，不由佣兵挡** |
| 保护 | 受击 / 掉沟后 0.35 s 无敌并弹到下一平台；佣兵消失后留 0.3 s 无保护 |
| 攻击 | 前排佣兵**能攻击也能挡刀**，全队按各自射程与攻击 CD 自动出手（近战 96 / 远程 288 = 3 倍）；玩家在队尾，只让射程内的单位出手 |
| 跟随 | 跳跃是**全队指令**，领队先起跳，后面按 `0.10 s × 序号` 延迟复现轨迹；x 用固定槽位 + 阻尼弹簧，不做位置追赶 |
| 跳 = 换人 | 新佣兵天降 0.35 s 内，**跳 = 顶替，不跳 = 放弃**；该窗口内生成器不刷怪波（三种「跳」语义时间互斥） |

### 2.3 怪、波次与地形

| 项 | 定稿 |
|---|---|
| 怪来源 | 怪**只从右进**；**敌人不会攻击**，伤害只来自碰撞；只借第一章图与名字，**不读** `monster_stats` / `monster_attack_style` |
| 怪种 | 普通 3 种：`forest_101` 走路菇 / `forest_105` 硬壳甲虫 / `forest_103` 树精守卫；精英建议 `forest_104` 暮影森主（**不许用蘑菇当精英**），单独成波 |
| 波只数 | 一波 **1~5 只**等间距，不跨段、不跨沟；最多 5 只是硬上限 |
| 波间隔 | 按**秒**计（1.0~2.0 s），不按 px；配 0.15 s 输入缓冲 |

| 传送门 | 跳 = 进传送门 → 黑屏 0.25 s → 背景在 `1.jpg` / `2.jpg` 间切换；不跳 = 留原图；**黑屏是安全窗口**（不刷危险、不判碰撞）；门前金币弧线预告；每 200~300 m 一个。基础版**只换背景**，前景与生成参数不动 |

### 2.4 成长、金币与结算

| 项 | 定稿 |
|---|---|
| 双计数器 | `runExp`（吃 1 枚 +1，升级用，单局清零）与 `runGold`（同一枚 +1，带出用）**分开**；**无加成倍率、无擦身额外金币** |
| 升级 | `Lv = 1 + ⌊runExp/100⌋`，`ATK = 40 × Lv`；敌人 `HP(m) = 40 × (1 + ⌊m/100⌋)` |
| 升级表现 | 领队头顶弹「队伍升级！！」，跟随队伍 1.8 s（上浮淡出），字号 **24**（fusion-pixel 12 的倍数） |
| 宝箱 | 每 100 m 一个，按里程锚点 `HashSet` 去重；道具池：回心 / 加攻 / 招人 / 吸金 / 护心（一次性即时效果，不进装备技能槽） |
| 带出 | **A 方案**：`ResourceWallet.Add(Gold, runGold, false, false)` 进主金币池，**不封顶**，跑多远拿多少；结算或中途退出都走同一条 + `Save()`；每天 3 次是天然总量闸 |
| HUD | 顶部 3 爱心 + 里程；底部经验条 + 金币条（复用 `TopBar.prefab` 的 `GoldPanel` **视觉**，`PlusButton` 隐藏） |
| 🔴 HUD 红线 | **不挂 `ResourceStrip`**、不接主界面 `RefreshGold`（它会把 `GoldText` 刷成账户余额）；由跑酷自己写 `runGold` |
| 结算 | 米数 / 本局金币 / 最高连击 / 一键再来 |

## 6. 验收总纲

- 单指点任意处起跳，其余输入全部无效；空中不攻击不碰撞。
- 三蘑菇组（或等价波）不跳必产生 1 次碰撞结算，容差 ±0.05 s。
- 传送门黑屏期间不生成危险、不判碰撞；天降窗口内不刷怪波。
- 连跑 2000 m 不掉帧、内存不涨；3 颗爱心归零即结算。
- 金币带出金额 = HUD 显示 `runGold`；中途退出与正常结算一致。
- 旧玩法零回归：不改旧表、旧字段、旧入口；战斗 / 竹篓功能不受影响。
- 弹窗走摄像机模式 + 全屏 raycast 底图；确认弹窗用 `StaminaConfirmPopup.Show`。
- 本机只做静态核对，**写完 C# 必须主人在编辑器跑一次**（本机无引擎，编译错误查不出）。
