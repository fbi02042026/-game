## 3. Loading 剧情提示（随机）

源码：`Assets/Scripts/UI/LoadingTips.cs`  
进入城镇 / 进入战斗各随机一条（避免连续重复）。

### 3.1 进城镇（12 条）

1. 小美说过：等她回来，就给你办转正仪式……  
2. 咨询台小姐看你的眼神，总像在隐瞒什么。  
3. 公会大厅灯火通明，像是什么都没发生过。  
4. 见习徽章还在胸口发烫。今天也要活着回来。  
5. 裂缝入口的风，比昨天更冷一点。  
6. 有人说正式小队都去调查最大的那道裂缝了。  
7. 打份工而已——你当初是这么想的。  
8. 阿尔托那家伙出发前还在念骑士荣耀。  
9. 格雷走前只丢下一句：别信表面的委托单。  
10. 回到公会，先去看看有没有她的消息。  
11. 任务板又刷出了一批「普通调查」。真的普通吗？  
12. 公会会长笑得很慈祥。你忽然不太想看。  

### 3.2 进战斗（12 条）

1. 裂缝越深，怪物越不像「记录里的样子」。  
2. 森林层：新人练手的地方……据说。  
3. 地上的剑痕还很新。有人比你早到一步。  
4. 亡灵在逃，不是在猎你——它们怕更深的地方。  
5. 补给箱上的编号……小美？  
6. 「引导至最深处」——这哪是调查任务。  
7. 若失败则封锁入口，不再派遣救援。  
8. 有些任务，从一开始就不是给活着的人准备的。  
9. 祭品不祭品，我说了算。  
10. 我们不是公会的礼物。我们是来砸场子的。  
11. 裂缝意志在等一个足够强的灵魂。别成为下一个。  
12. 公会不要的人，我们自己救。

## 5. 新手引导（教学战斗）

### 5.1 操作提示

| 时机 | 文案 |
|------|------|
| 开场 | 靠近怪物会自动攻击。 |
| 清第一波后 | 不错！再清一小波，熟悉下节奏。 |
| 掉落装备 | 地上有装备，捡起来看看。 |
| 装备后 | 属性更好就装备，旧的会变成强化材料。 |
| 诱饵波 | 小心！有些装备是怪物设下的诱饵。 |
| 发现老盾 | 前方有人被怪物围住了，走近看看。 |
| 怪转火 | 怪物冲过来了，靠近它们会自动攻击。 |
| 老盾入队 | 老盾加入了队伍。 |
| 治疗引导（硬） | 老盾快没血了。点你的头像放技能，给他回血。 |
| 组队后 | 组队后佣兵会自动战斗，和你一起推进。 |
| 再清一波 | 状态不错，再清一波我们就撤。 |
| 撤离前 | 你的队友状态也不好，现在撤出来比较稳。点击右上角设置，选择撤离。 |
| 撤离（硬） | 点右上角设置，选择「撤离」回城。 |
