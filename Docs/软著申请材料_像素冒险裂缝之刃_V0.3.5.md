## 1. 软件概述

《像素冒险:裂缝之刃》是一款竖屏 2D 像素风 Roguelike 冒险游戏客户端。玩家在城镇（冒险者大厅）进行养成与准备，选择章节进入横版自动战斗；通关后通过石墩关卡图与随机轮盘决定下一关类型，形成 **「启动 → 城镇 → 冒险开战 → 战斗结算 → 选关 → 再战斗 / 回城」** 的可玩闭环。

本登记版本 **V0.3.5** 保证上述主闭环可完整演示，并包含：佣兵招募、恢复关、遗产战前三选一、成就里程、本地存档与顶栏资源激励模拟；**V0.3.5** 另含登录/音频/引导/战斗 UI 体验收口。**不在本版本功能范围** 的项见第 6 章，**请勿写入说明书正文**，避免与实机不符。

### 1.1 运行环境

| 项 | 内容 |
|----|------|
| 硬件 | 支持 Android 的智能手机 / 平板；开发调试可用 PC 模拟器 |
| 操作系统 | Android 8.0 及以上（目标平台）；开发环境 Windows 10/11 |

| 分辨率 | 720×1280 竖屏基准 |

## 2. 主要功能

### 2.1 启动与存档

1. **Boot 场景**：初始化持久对象（存档、配置、场景管理），显示登录界面（本版隐藏公告、设置等未开放入口；登录页播放城镇 BGM）。  
2. 用户勾选协议后点击「开始游戏」进入城镇主界面；片头/Loading 期间按全局「声音」设置静音 BGM 与音效，切场景后恢复。  
3. **本地 JSON 存档**：金币、体力、材料、天赋、佣兵、遗产池、章节进度等持久化；支持备份文件。  
4. **云存档 / 激励广告**：接口层已预留；本版本为 **本地模拟发放**（顶栏金币+、体力+）。  
5. **离线收益**：离开游戏一段时间后回城，弹出「已到账」说明窗，金币写入存档。

### 2.2 城镇（冒险者大厅）

底部固定导航五入口：**公会 / 角色 / 冒险 / 酒馆 / 冒险日志**。

| 模块 | 功能说明 |
|------|----------|
| **公会** | 大厅主界面；顶栏显示金币与体力；邮件领取；咨询台对话提示；成就里程入口 |
| **角色** | 查看基础属性、天赋、技能与背包格子；**无独立穿戴栏**；背包点击装备后，城镇页与战斗内均以 **SPUM 实时换装** 展示同一形象 |
| **冒险** | 选择章节与难度（普通 / 困难 / 噩梦），消耗体力开战；**仅主线模式** |
| **酒馆** | **佣兵招募（三选一）**：从佣兵形象池抽取 3 名候选项；形象可相同，但姓名、等级、星级、佩戴技能不同；可反复招募；写入永久名册并展示出战槽 |
| **冒险日志** | 怪物（含 Boss）、佣兵、成就、世界、主线、支线；不设装备图鉴 |

**本版本隐藏入口（界面不可见）：** 商城、公告、排行榜、公告栏、武器库、执照厅、活动副本、扫荡、章节奖励、酒馆信任 / 任务 / 情报等。

### 2.3 战斗与关卡

1. **横版自动战斗**：英雄与佣兵协同；普攻与技能（含远程飞行体命中）。  
2. **波次刷怪**：普通 / 精英 / Boss 按章节与难度系数缩放。  
3. **通关结算**：宝箱三选一装备；走近传送门完成关卡；未选中奖励折合金币并 Toast 提示。  
4. **石墩关卡图 + 轮盘**：通关后进入章节石墩地图；轮盘展示并抽取下一关类型。  
   - **本版本实际类型：普通、精英、恢复、首领**（四类）。  
   - 历史枚举中的商人、诅咒、锻造、附魔若残留于旧数据，**静默按普通战斗关处理**，不弹「未开放」提示。  
5. **恢复关**：弹出生命恢复界面（回复最大生命 50%），发放强化材料，确认后继续。  
6. **死亡与撤离**：本局战斗金币按规则结算；可携带一件遗产回城写入遗产池。  
7. **不支持** 应用中断后的战斗续关（中途退出清战斗存档）。

### 2.4 战前与养成

1. **遗产三选一**：非引导局且遗产池有装备时，开战前选择一件带入本局（选中后从池中消耗）。  
2. **激励刷新**：三选一界面支持激励接口刷新一次（本版本模拟）。  
3. **天赋**：角色页解锁与属性加成。  
4. **佣兵**：酒馆三选一反复招募；同形象可有不同姓名/等级/星级/技能；名册顺序决定出战；出战槽数与酒馆等级相关（0～2）。  
5. **成就里程**：公会侧入口打开里程碑领取。  
6. **装备换装**：装备模板配置 `spumName` 对应 SPUM 部位精灵；穿脱后城镇预览与战斗英雄同步刷新。

### 2.5 平台与性能

1. UI 统一 CanvasScaler 720×1280。  
2. 对象池、战斗特效复用、城镇页预加载（`TownSceneBootstrap`）减少切页卡顿。  
3. 伤害公式与武器表集中配置（`GameConfig` / `DamageFormula`）。

## 3. 操作说明（用户手册）

### 3.1 进入游戏

1. 安装 APK 或编辑器运行 Boot 场景。  
2. 登录界面勾选用户协议 → 点击「开始游戏」（界面无公告/设置入口）。  
3. 加载完成后进入公会大厅。（**附图 01、02**）

> 附图 01：登录界面已有品牌 Logo（申请人自备资源），截取完整登录页即可。

### 3.2 首次引导

按屏幕引导完成对话与教学战斗（软提示遮罩、对话气泡等比缩放）；撤离或结束后回到城镇，底栏五入口可用。战斗设置中「声音」开关同时控制音乐与音效。

### 3.3 开始冒险

1. 点击底栏「**冒险**」。  
2. 选择已解锁章节；难度选普通 / 困难 / 噩梦。  
3. 点击开始，消耗体力进入战斗场景。  
4. 若遗产池有装备，先完成 **三选一** 再进入第 1 关。（**附图 05、06**）

### 3.4 战斗中

- 角色自动移动与攻击；可点击技能按钮。  
- 可暂停；主动撤离走遗产结算。  
- 清怪后出现宝箱，三选一装备；走近传送门进入下一环节。  
- 未拾取奖励折合金币，界面有 Toast。（**附图 07、08**）

### 3.5 选下一关（石墩与轮盘）

1. 出现章节石墩地图。  
2. 观看关卡类型轮盘滚动（普通 / 精英 / 恢复 / 首领）。  
3. 旗子落到石墩后，点击石墩进入对应关卡。  
4. **恢复关**：在弹窗中确认回血与材料后继续。（**附图 09、10**）  
5. 本章首领通关后解锁后续章节并回城。

### 3.6 城镇养成

| 操作 | 说明 |
|------|------|
| 角色 | 查看属性、天赋、技能、背包；点背包格装备，城镇立绘与战斗 SPUM 同步换装（**附图 12**） |
| 酒馆 | 点「佣兵招募」→ **三选一**（姓名/等级/星级/技能不同，形象可同）→ 确认招募；可换一批再招（**附图 11**） |
| 顶栏 + | 点金币或体力旁加号，模拟激励视频领取（**附图 03**） |
| 冒险日志 | 查看图鉴与探索统计（**附图 13**） |
| 成就 | 公会界面打开成就里程（**附图 14**） |
| 离线 | 离线 ≥1 分钟后回城弹出收益说明（**附图 04**） |

## 4. 技术特点（鉴别表述）

1. **组件化 C# 架构**：Boot / Town / Battle 三场景；单例管理战斗、存档、章节、对象池。  
2. **关卡抽取与演出解耦**：`StageRoller` 加权抽取四类关卡；`NextStageRouletteUI` + `BattleStageMapUI` 负责展示。  
3. **存档模型**：JsonUtility 可序列化结构 + 运行时 Dictionary 同步；佣兵、遗产、天赋分模块读写。  
4. **SPUM 换装**：装备 `spumName` 与图标文件名对齐 SPUM 精灵；`HeroCostumeManager` 按槽位刷新；城镇 `TownHeroCostumePreview` 与战斗共用同一换装逻辑。  
5. **佣兵池数据驱动**：形象来自 `CharacterRegistry`；`MercenaryOfferGenerator` 生成同形象异属性的三选一；存档含姓名/等级/星级/技能。  
6. **资源发放收口**：`ResourceWallet` 统一顶栏金币/体力变更，避免战斗与城镇重复加金。
