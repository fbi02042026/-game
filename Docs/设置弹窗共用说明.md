# 设置弹窗（登录 / 城镇 / 战斗共用）

## 入口

| 场景 | 调用 | 底部按钮 |
|------|------|----------|
| 战斗 | `SettingsPopupUI.Ensure().Open(SettingsHost.Battle)` | 声音 + **撤离** + **继续战斗** |
| 城镇 | `Open(SettingsHost.Town)` | 声音 + **关闭** |
| 登录 | `Open(SettingsHost.Login)` | 声音 + **关闭**（入口本版隐藏，已接线） |

兼容旧 API：`BattleSettingsPanel.Ensure().Open(...)`。

## 预制体

- 路径：`Resources/Prefabs/UI/SettingsPopup`
- 生成：`Tools/UI/生成设置弹窗预制体`（已存在会询问覆盖）
- 无预制体时运行时兜底搭建同结构

## 策划对齐

- **软著 V1.0**：单行「声音」总开关（音乐+音效）；战斗撤离/继续；城镇关闭。
- **GDD 18.x**：总音量 / 音乐 / 音效分控 —— 预制体已预留 `MusicRow` / `SfxRow`，默认隐藏。
- **天气设计 7.5**：「天气特效」开关 —— 预留 `WeatherRow`，默认隐藏。

## 扩展方式（以后加项）

1. 在 `SettingsToggleId` 加枚举。
2. `IsToggleEnabledInBuild` 里把对应项改 `true`。
3. 在 `ToggleList` 下挂行（或解开预留行），命名含 `Music` / `Sfx` / `Weather` 即可自动识别。
4. 在 `ReadToggleState` / 点击回调里接存档（`GameAudio` 或 `PlayerPrefs`）。
5. **不要**再为登录/城镇/战斗各写一套设置面板。
