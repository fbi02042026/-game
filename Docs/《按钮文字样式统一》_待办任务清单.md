## 目标

把所有按钮上的文字，统一成升阶按钮 `yongbing升阶.prefab` / `shengjieButton/Label` 上主人手摆的「形式」：

| 项 | 值 | 来源（升阶按钮 Label 当前实值） |
|---|---|---|
| 字色 | `(0.9825194, 1, 0.6179246, 1)` 浅金黄 | Text.m_Color |
| 描边 | Outline：深灰 `(0.11320752,0.11320752,0.11320752, 0.39215687)`、偏移 `(2,-2)`、UseGraphicAlpha=1 | Outline 组件 |
| 字号 | **两档**：大按钮 32 / 小按钮 24（按按钮矩形尺寸分流） | 升阶按钮原值 32 |
| 字重 | **Bold**（m_FontStyle=1，属「这个形式」一部分） | Text.m_FontStyle |
| 对齐 / 字体 / RichText / 溢出 | **不动**（保留原值；字体已是 PixelFont 不碰） | — |

> ⚠️ 已知副作用（主人上一轮已接受）：PixelFont 无中文字形 → 中文按钮文字仍是空白。本任务只统一形式，不解决中文字体。要给中文就单独给字体文件再换。

## 落地方式（主人拍板：批量改预制体）

扫描 `Assets/**/*.prefab`，对**每一个 Button 组件**（`script guid = fe87c0e1cc204ed48ad3b37840f39efc`）做：

1. 取该 Button 所在 GameObject 的 RectTransform `m_SizeDelta` → 算档位：
   - `h = m_SizeDelta.y`，`w = m_SizeDelta.x`
   - `h > 0` → 档位 `h >= 48 ? 32 : 24`（阈值常量 `HEIGHT_TALL=48`）
   - 否则 `w > 0` → `w >= 160 ? 32 : 24`（阈值常量 `WIDTH_WIDE=160`）
   - 否则（宽高都拉伸）→ `32`
2. 沿 transform 父子链收集该 Button GO 的**所有后代 GO**，找出其中带 Text 组件（`script guid = 5f7201a12d95ffc409449d95f23cf332`）的，逐个设置：
   - `m_Color` → 目标字色
   - `m_FontStyle` → 1（Bold）
   - `m_FontSize` → 算出的档位
3. 描边：该 Text 所在的 GO 若**已有** Outline（`e19747de3f5aca642ab2be37e372fb86`）→ 原地改 `m_EffectColor / m_EffectDistance / m_UseGraphicAlpha` 为目标值；若**没有** → 在该 GO 上新增一个 Outline MonoBehaviour 块（新 fileID），并把 fileID 追加进该 GO 的 `m_Component` 列表（插在 `m_Layer:` 之前）。
4. 无子 Text 的按钮（纯图标按钮）→ 跳过。

## 铁律（必守）

- **CRLF 零破坏**：二进制读写，按行保留原行尾；禁止把 `\r\n` 吃成 `\n`。改完断言每个 prefab `\r\n` 数 == `\n` 数（或全 LF 时 0==0，但本项目 prefab 基本全 CRLF）。
- **不碰**：按钮底图/背景、非按钮文字、字体引用（上次已统一）、字号之外的对齐/RichText/溢出设置、其它组件。
- fileID 必须全局唯一：新增 Outline 的 fileID 取各 prefab 内未出现过的大整数，禁止与现有 fileID 碰撞（碰撞会断链）。
- 不动 `.meta`、不动 `.cs`、不重跑任何 prefab 生成器、不删文件。
- 先独立备份再改，留一键回退。
