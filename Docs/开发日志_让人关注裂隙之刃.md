# 〈像素冒险：裂隙之刃〉开发日志：我们把"自动战斗"做成了每个选择都算数的游戏

> 一句话先说清楚：这是一款竖屏 2D 像素风、自动战斗的 Roguelike 冒险。但它不是"挂机爽游"——队伍自己打，你负责做每一个关键决定。

---

## 一、我们到底做了个什么

你是冒险者公会新来的见习冒险者，一次次往"裂缝"里钻。队伍会自动索敌、自动出手，爽感这一块交给系统；而你真正要拍板的是三件事：

- **走哪条路**：每局裂缝是随机分支地图，普通 / 精英 / 首领 / 附魔 / 诅咒 / 商人 / 休息，七种关卡散在树状路径上，选路本身就是策略。
- **捡哪件装备**：每关打完三选一，背包是 24 格占格系统，词条 × 符石 × 佣兵 × 天赋互相纠缠，一局能长成完全不同的流派。
- **贪不贪下一层**：活着带战利品撤离，还是再赌一层？裂缝之前，由你决定。

单局 5–8 分钟，竖屏，地铁上、等饭时开一局刚好。我们想做的，是"不用拼手速，但每一步都要想"的像素冒险。

## 二、三个让人"上头"的点

**① 随机裂缝，没有两局一样。** 分支地图每局重排，特殊关卡每局随机分配且唯一（不会一章里刷出两个附魔关）。诅咒关尤其刺激——三选一全是"强力 buff + 负面 debuff"，加 30% 攻击就要砍 15% 血上限，高风险高收益，当场就得算账。

**② 装备构筑，深度全在搭配。** 白 / 绿 / 蓝 / 紫 / 橙五档品质，每件装备的占格、词条、星级、等级要求都不一样。同品质下星级越高属性越好，传说装备只要"这局拿到过"就永久解锁全局加成——收集传说是长线追求。

**③ 死了不白死。** 英雄倒下后能从本局装备里挑 1 件当"遗产"带回城，永久进遗产池，开局就能穿。局外还有天赋树和城镇建筑（铁匠铺、酒馆、农场……）做长期养成，酒馆招募佣兵三选一、无抽卡无 SSR。

## 三、幕后：这个月我干得最多的事是"推翻自己"

说几个真实发生过的，都是带数字的：

**真机和编辑器根本不是同一个游戏。** 打包上手机一跑，冒出一堆"编辑器里明明是好的"问题。查下来不是 bug：项目里有 30 多处"编辑器专用"分支，编辑器直接读美术源目录、真机只能从 Resources 加载，资源没同步就静默显示旧图甚至白框，还不报错。更离谱的是分辨率——我常用 1080×1920 测，正好等于设计比例，那条"屏幕更瘦"的适配分支**从来没触发过**；真机是 1240×2772 这种瘦屏，一上去排版全歪。刘海避让、片头视频真机不播……全是这种"看着没事、其实没测到"的坑。我的解法很硬：把兜底亲手关掉，缺图就露白框，并写了审计工具把"真机必空"的路径全扫成清单——宁可在开发期天天看白框，也不上线后才看到旧图。

**包体压了三轮，一半计划是空操作。** 从 206.68 MB 起步，第一批粗暴降导入尺寸上限，到 175.55 MB。结果第二批实测发现：改上限只在"源图像素大于新上限"时才真省体积，我要压的背景图本来就是 576×1024、图标 128×128，降上限等于没降。真正起效的是跨过"2 的幂归整边界"的那几张——711×1391、750×1125、800×1443 被引擎归整到 1024×2048，每张实打实吃 4 MB；再删 8 张无引用的死立绘、31 张佣兵立绘从 1024 降到 512，才算第一次压到线下。

**一个修了三次的断链坑。** 临上线扫资源引用，报出 7 处图片丢失。图一张没少，坏的是资源标识文件——里面的 GUID 被写成了 56 字符长串，而预制体里存的是旧的 32 位十六进制，对不上。引擎的处理是静默退化成纯色矩形，不报错、不中断打包，本地缓存里还留着旧索引，所以"能打包、看着像那么回事"根本证明不了没断链。修法是反着来的：不动预制体、不动图，把预制体里存着的那串旧 32 位写回资源的 meta。这类长串是引擎自己反复写回去的，之前已换发过 626 个，现在又长出 300 多个。我加了两条防线：全量"路径→标识"快照比对，专门抓"正常的 32 位蜕变成 56 字符"；以及保存预制体时即时查图、丢失直接打 Error——**不要兜底，要报错**，不然我根本看不见问题。
