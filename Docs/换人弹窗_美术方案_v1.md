### 🔴 头像框统一成「酒馆稀有度框」（2026-11-26 主人拍板，覆盖同日早先的 Sliced 口径）

- **问题**：v1 用 Common 的 **200×96 横条**框压成 84×84 正方，四角菱形金饰变形。中间试过九宫格（切边 22/14 → 12/8），但主人指出「说的不是九宫格参数，是要用**其他界面那版稀有度头像的框**统一」。
- **正确做法**：不做九宫格切边，直接换资源——用 `UI/Art/Tavern/酒馆头像/` 下的 **204×248 竖版**框（传奇金 / 稀有蓝 / 普通银），与招募池、竞技场货架、佣兵获得弹窗同一套。原图竖版等比显示，头像叠中心镂空，从根上没有「横条压方」的变形问题。
- **档位映射**：Legendary→传奇头像框（金）/ Rare→稀有头像框（蓝）/ Common→普通头像框（银）；换图只走 `MercHireSession.LoadTavernCardFrame(rarity)`，不代码改色。
- **真机现状**：换人窗 `MercReplaceConfirmUI.SetIconBg` 当前走 `LoadPortraitFrame`（Common 横条那套），与「其他界面」不一致。
- **落地改动（待主人确认后才动）**：把 `SetIconBg` 的取图出口从 `LoadPortraitFrame` 改走 `LoadTavernCardFrame`；头像 `Icon` 保持 Simple + preserveAspect 叠框中心。**属于动真机代码，本版未动。**

## 三、布局结构（720×1280 竖屏，效果稿按 50% 展示）

```
        [通用窗体标头1]  ← 面板顶边外，「换下谁？」
   ┌──────── 通用窗体1 ────────┐
   │  点要换下的人，新佣兵顶上      │  ← 说明主行
   │  15 秒后自动换下较弱的        │  ← 灰绿小字（倒计时）
   │  ┌────┐ ┌────┐ ┌────┐      │
   │  │新人│ │现有│ │现有│      │  ← 三等宽栏
   │  │金框│ │普通│ │阵亡│      │
   │  └────┘ └────┘ └────┘      │
   │  [换下马库斯][换下洛恩][不要了]│  ← 绿 / 绿 / 红
   │      点暗带也是「不要了」       │
   └────────────────────────┘
```

- 三栏等宽，缺口靠**精简每栏信息**腾出，不再靠整体缩放挤。
- 头像框 84×84 见方（效果稿尺寸），头像内嵌居中、preserveAspect。
- 名字随稀有度上色（真源 `RarityPalette.Get`，与头像框同档同源）。

## 四、排版优化点（逐条可验收）

| # | 现状 | 这一版 | 为什么 |
|---|---|---|---|
| 1 | 三栏连字一起 `localScale 0.72`，720 宽下偏小 | 栏内元素独立字号，不整体缩 | 信息密度靠「少写几行」解决，不靠缩字 |
| 2 | 三颗按钮都写「替换」，要记住点了谁 | 「换下马库斯」「换下洛恩」「不要了」 | 点前即知结果，降低误操作 |
| 3 | 新人与现有两位同框同重 | 新人金框高亮 + 「新获得」角标 | 先看「来了谁」再决定「换掉谁」 |
| 4 | 倒计时占 `Verdict` 主视觉位 | 降为说明行下的灰绿小字 | 不抢选择注意力，但仍是防挂机兜底 |
| 5 | 阵亡者与在场者同亮度 | 阵亡者头像/框降透明度 + 红字「已阵亡」 | 视觉暗示换他更划算，与超时自动选逻辑一致 |

## 五、待程序落地的接口约束（不含代码）

- 三栏数据来源不变：左 = `newEntry`（只读），中/右 = `RunLoadout.Mercs()[0]/[1]`，第三栏仍是运行时克隆 `ColumnOld`。
- 按钮回调不变：中栏→`Answer(0)`、右栏→`Answer(1)`、不要了/暗带→`Answer(-1)`，超时 15s 自动选弱者不变。
- **改动范围仅限填数据与排版**（`Fill` / `FillColumn` / 摆位常量），不动 `Show` / `Ensure` / `Answer` 的流程骨架。
- 字号若写死在 prefab，需按项目约定抽常量、两路径各设一次（fusion-pixel 12 倍数优先）。
- 标题挂面板顶边外 `.Bg()` 只挂首句那套不相关，本窗标题常驻，照通用弹窗口径即可。

## 六、验收清单（编辑器里逐条看）

1. 竖屏 720×1280 下，三栏名字/稀有度/战力一眼可读，不再糊成小字。
2. 按钮文字随实际上阵佣兵动态变化（换下的是谁就写谁），不是写死「马库斯/洛恩」。
3. 新人栏金框 + 「新获得」角标只在左栏出现，中/右栏没有。
4. 倒计时为小字，不遮挡、不抢主视觉。
5. 阵亡那位头像明显压暗，红字「已阵亡」清楚。
6. 头像框三档与 `MercHireSession.LoadPortraitFrame` 同源，未出现白框/错框。
7. 点按钮 / 点暗带 / 超时三条收场都通，波次照常推进，无卡死。
8. 工程里没有新增任何图片文件，`.meta` 无改动。
