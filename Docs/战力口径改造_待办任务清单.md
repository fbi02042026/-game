## 一、为什么要改（背景，别跳过）

**一句话：`RunLoadout.TotalPower()` 完全不读属性，是按「装备件数」计费的。**

```csharp
// Assets/Scripts/Systems/RunLoadout.cs:630-671
power += Mathf.Max(1, _data.heroLevel) * 100;                    // :634  等级
foreach (7 个装备槽)
    power += (int)eq.rarity * 60 + Mathf.Max(1, eq.star) * 90
           + Mathf.Max(0, eq.enhanceLevel) * 45;                 // :667  每件固定钱
```

全篇只有「等级 / 稀有度 / 星级 / 强化等级」四样，**ATK、DEF、HP 一个字都没读**。

**现场事故**：剑盾 Lv1 战力 **400**，其余职业 **250**。
原因是 `PowerEquipSlots`（`:674-678`）列了 7 个槽含 `OffHand`，剑盾多穿一面盾就白拿一份。
又因 `Rarity.Common = 1`（`Assets/Scripts/Config/EquipTemplate.cs:10`，不是 0），
一件 Common★1 装备的底线就是 `60 + 90 = 150`：`100(等级) + 150(武器) = 250`、加上盾 `= 400`，分毫不差。

> 主人原话：「我第一次听说按装备数量算战力，搞笑呢。」

## 二、目标口径

**战力 = 对敌方造成伤害的能力系数。** 攻击占大头，防御**不占**（主人口径）。

```
DPS    = 攻击合计 × (1 + 暴击率) × 每秒攻击次数
Power  = 常数底盘 + k × DPS
```

> 🔴 **本项目没有「等级」这个概念**（主人 2026-10-12 订正）。
> `RunLoadout.HeroLevel` 是遗留字段，`RunSkillBarUI.cs:104` 注释已写明「等级系统已停用」。
> → **新公式里禁止出现等级**，底盘必须是纯常数。
