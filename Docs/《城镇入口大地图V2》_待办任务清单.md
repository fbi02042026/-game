## 2. 验收步骤（建议顺序）

1. **入口/解锁**：通了 1-10 → 冒险页主线模式出现大地图按钮 → 点击打开；未通不显示。
2. **资源条**：左上角三格（战功/石头/粮草）icon + 数值，图标分别是军功章/蓝矿石/粮仓；石头数 = 矿 + 石材；返回按钮不压第三格。
3. **地图**：底图、固定城堡、6 个点位**头像图标**齐全；点「放大/缩小」切换缩放；按住拖动平移，边界钳住不越界。
4. **行军**：点点位 → 弹窗显示守军战力/我方战力/行军耗时/小队/预计收益 + **「近/远距」与「掉落池」** → 派遣 → **3 个头像从城堡飞向目标** → 到位后显示「行军中 X分X秒」+「加速」按钮。
5. **加速**：点「加速」→ 激励视频核验成功 → 立即抵达 → 触发战斗演出；未完成激励则继续行军（不发奖）。
6. **战斗演出**：3v3 头像，血条在头像上逐帧下降（前期约 10 秒）；打赢我方血条高、敌方归零；通商不演战斗。
7. **占领 + 跳字**：血条走完 → 「占领中 3/2/1」→ `+ 战功 X 矿 X 道具名×N …` 跳字 → 资源条数值增加 → 点位变灰冷却 → 角色页「随身仓库」能看到刚掉的道具（与主线同池）。
8. **离线到达**：派遣后关掉界面/重进游戏，到达时应自动播战斗演出（2 秒轮询 + 打开时检查）。
9. **互斥**：把某佣兵放进主线队列 → 闲置数减 1；不足 3 人无法派遣；同一闲兵在途时不能再派去别的点。
10. **清档**：新游戏复位后无残留行军单 / 战斗演出状态。
11. **掉落池差异**：近距点位（城寨/野怪）弹窗掉落池 = 分解材料/天赋石；远距（两个矿）= 附魔石/招募卷/碎片。实际派遣后只掉该池道具；战败（战力比<0.8）不掉任何道具；通商概率减半。
