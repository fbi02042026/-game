## Unity .meta GUID（重要）

**现象：** `.meta` 里 `guid:` 变成 56 字符 base64（含 `/+=`），导致头像/装备图标/VFX/脚本引用丢失。

**根因：** 曾依赖 `cn.tuanjie.codely.bridge`（团结 Codely Bridge）。即使用户未主动打开 Codely，只要包装在工程里 + 后台 Bridge/心跳在跑，就可能改写磁盘上的 `.meta`。**不是**业务 C# 写错。

**已处理（2026-08-25）：**
1. 全量修复 2336 个坏 GUID → 32 位 hex（`Tools/FixAllCorruptedGuids.ps1`）。
2. **已从工程删除 Codely**：`Packages/manifest.json` 去掉 `cn.tuanjie.codely.bridge`；删除 `.com-unity-codely.json` / `.codelyignore` / `.codely-cli`。

**以后避免：**
1. 不要再安装 `cn.tuanjie.codely.bridge` / Codely 相关包。
2. 若再出现图标/头像空 → 先跑 `Tools/VerifyGuids.ps1`，坏则跑 `FixAllCorruptedGuids.ps1`，再 Unity Refresh。
3. 禁止只修单个文件夹、只改 meta 不改引用。
4. 新资源入库前抽查 meta 的 `guid:` 必须是 32 位 hex。

**冒险日志数据：** 设计文档 `Docs/像素冒险：裂隙之刃_冒险日志数据设计_V1.0.md` → 运行时 `AdventureLogCatalog.cs`（96 怪 / 22 佣兵 / 15 成就 / 8 世界 / 9 主线 / 16 支线）。
