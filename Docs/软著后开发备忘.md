## 编译失败会让「所有改动都像没生效」（血泪）

出现过两次：脚本编译错误后，团结沿用**上一次成功编译的程序集**，于是玩家看到的是旧逻辑——
表现为「技能特效没了」「背包格子颜色改不回去」「装备弹窗还是旧的」「对话还是旧台词」，
很容易被误判成一堆互不相关的新 bug。

历史案例：
- `3ee3145`：`TutorialDirector` 重复变量 `wait`
- 2026-08-27：`GlobalToastUI` 调用了不存在的 `UIManager.ShouldSuppressToastForBubblePublic()`；
 同时 `Monster.cs` 调用了 `UnitBase` 里 private 的 `CalcHitPointCenter`（CS0122）

**规矩：** 改完脚本必须回头核对新引用的符号真实存在、可见性够、签名匹配。
用户报「改的东西没生效 / 怎么改不回去」时，**先查编译错误**，别急着改业务逻辑。

## Unity .meta GUID（结论已修正 · 2026-08-26）

**先前判断是错的。** 之前认为「base64 guid = 被加密搞坏」，并写脚本强改成 hex，这是造成白框的真正原因。

**事实：** 团结编辑器给**它自己导入的新资源**分配 56 字符 base64 形态 guid。这是引擎行为，不是损坏，Hub 里也没有对应开关。

证据（`Assets/Art/Video/opening_intro.mp4.meta` guid 变化史）：

| 时间 | guid | 谁写的 |
|---|---|---|
| `b9a0569` 首次入库 | `DnMa5in5By/...=` | 编辑器导入 |
| `f02fcf5` | `Wn8X5nz7Ai3...=` | 编辑器再导入 |
| `495cc87` | `45f82b57...` hex | **修复脚本强改（错误）** |
| 之后（未提交） | `Bi8e5Hz4US9...=` | 编辑器又写回 |

该文件从未自然出现 hex guid。所有被报「坏 guid」的文件都是**新导入资源**，老资源全是 hex。

**为什么越修越坏：** `FixAllCorruptedGuids` 把 base64 换成**随机新 hex** 并改所有引用；编辑器下次导入把 meta 写回 base64，**却不会改回引用** → 引用悬空 → 预制体白框 / Missing Script。反复在编辑器外改 meta 还会触发全量重导入 + 重编译，放大 `Unity.ILPP.Trigger.exe Unknown Hard Error`。

**已处置：**
1. 删除 `Assets/Editor/GuidIntegrityGuard.cs`（启动全量扫 meta + 弹窗，纯噪音）。
2. `Tools/FixAllCorruptedGuids.ps1` 加参数闸门，默认拒绝执行。
3. `Tools/VerifyGuids.ps1` 标注判定前提错误。
4. `Tools/guid-remap-last.json` 仅留作历史追溯。

**以后遇到白框 / Missing：**
1. 不要动 meta。
2. Inspector 里按资源路径重新拖一次，让编辑器自己写引用。
3. 批量用 `Tools/FixOrphanUiSprites*.py`（按美术路径重绑引用，**不改 guid**）。

**Codely：** `manifest` 保持无 `cn.tuanjie.codely.bridge`，不要装回；但它**不是** base64 guid 的原因。

## Android Package Name（勿与加密混淆）

- 报错 `Package Name must follow com.YourCompanyName...`：来自 **Player Settings**，不是资源加密。
- 原因：`productName` 为中文「像素冒险：裂隙之刃」时，若未 override，编辑器会用中文拼包名 → 非法。
- 已固定：`Android/Standalone = com.PixelAdventure.RiftBlade`，`overrideDefaultApplicationIdentifier=1`。显示名仍可用中文。

**冒险日志数据：** 设计文档 `Docs/像素冒险：裂隙之刃_冒险日志数据设计_V1.0.md` → 运行时 `AdventureLogCatalog.cs`（96 怪 / 22 佣兵 / 15 成就 / 8 世界 / 9 主线 / 16 支线）。

## 怪物弹道：弓箭 vs 法球（2026-08-27 定稿）

| 表内 style | 弹道 | 资源目录 |
|---|---|---|
| `Bow` / `Archer` | 箭矢 | `Resources/VFX/Shared/Enemy/Bow/` |
