## Unity .meta GUID（重要）

**现象：** `.meta` 里 `guid:` 变成 56 字符 base64（含 `/+=`），导致头像/装备图标/VFX/脚本引用丢失。

**根因：**  
1) 工程曾装 `cn.tuanjie.codely.bridge`；  
2) **更关键：团结编辑器自带 `com.unity.editor.guid.encryption`（GUID 加密）**——Reimport 时会把 `.meta` 的 `guid` 写成 base64。  
所以：**卸掉 Codely 包之后仍可能被改**。片头 `opening_intro.mp4` 在编辑器开着时 Reimport，meta 会立刻被再次加密（已实测）。

**已处理：**
1. 全量修复坏 GUID（`Tools/FixAllCorruptedGuids.ps1`）。
2. 工程 `manifest` 去掉 Codely；gitignore 排除 `.com-unity-codely.json`。
3. 场景/预制体 Missing Script 二次断链已补（BootManager 等）。

**你需要做的（关源头）：**
1. 在团结里找并**关闭 GUID 加密 / Codely / AI 资源相关开关**（Preferences / Project Settings / Hub）。
2. 未关闭前，尽量少 Reimport；修 meta 时最好先关掉编辑器。
3. 再出现坏 GUID → `Tools/VerifyGuids.ps1` → 坏则 `FixAllCorruptedGuids.ps1` → Refresh，并复查 Missing Script。

## Android Package Name（勿与加密混淆）

- 报错 `Package Name must follow com.YourCompanyName...`：来自 **Player Settings**，不是资源加密。
- 原因：`productName` 为中文「像素冒险：裂隙之刃」时，若未 override，编辑器会用中文拼包名 → 非法。
- 已固定：`Android/Standalone = com.PixelAdventure.RiftBlade`，`overrideDefaultApplicationIdentifier=1`。显示名仍可用中文。

**冒险日志数据：** 设计文档 `Docs/像素冒险：裂隙之刃_冒险日志数据设计_V1.0.md` → 运行时 `AdventureLogCatalog.cs`（96 怪 / 22 佣兵 / 15 成就 / 8 世界 / 9 主线 / 16 支线）。
