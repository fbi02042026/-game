# 角色界面职业装备栏 · 待办任务清单

> 状态：**方案已定，C# 未动工，无提交**。本文只给改造点与验收标准，不写完整代码；代码交给子模型（GLM 5.3 Flash / Step-5-Preview）落地。

## 一、现状（背景）

- 角色界面（`Assets/Scripts/UI/CharacterUI.cs`）明确是「无左侧装备栏」；随身仓库（`HeroVaultGrid`）里装备只静态展示、点不动（根因 `BackpackGridVisual.cs:270` 的 `interactive` 判定）。
- 战斗内已有可复用的现成件：
  - 装备属性浮窗 `EquipStatTipUI`（浮在图标上方的小框，刻意**不**做点任意处关闭）。
  - 装备替换确认弹窗 `EquipReplaceConfirmUI`，内部 `FillColumn` 填 `ColumnOld` / `ColumnNew` 两个**独立装备详情卡**（节点 `Name`/`Info`/`Desc`/`Icon`/`Iconbg`/`zhanli`/`NewMark`，一条一行属性 + 稀有度框体）—— 本需求的属性框视觉参考它。
  - 装备稀有度框体 `EquipRarityFrame.SpriteOf(Rarity)` / 描边 `EquipRarityRim`、图标 `EquipIcons.Resolve`、文本 `EquipUiText` / `DraftPool.FormatEquipDescLines`。
- 三职业 = `PlayerJobDefs.Playable`：**剑盾卫士 / 法师 / 游侠**（当前开放给玩家选的三个，不是全部 6 个）。
- 起步套真源 = `PlayerJobDefs.GetJobWeaponKit(job)` → `MainTemplateId` / `OffTemplateId`（主手武器 + 副手盾，**只有武器，无护甲**）。剑盾有盾、法师/游侠副手空。

## 二、目标

在角色界面背包栏（`BackpackPanel`）**上方**新增一个常驻「职业装备栏」面板：

1. 顶部蓝色凸标签显示当前职业名（剑盾卫士 / 法师 / 游侠）。
2. 左右金色箭头切换职业；**三个职业各有独立起步套，切换时严格按职业索引取数、互不串**（红线）。
3. 下方按部位一排装备槽：**主手 / 副手 / 头 / 脚 / 身**。
4. 起步套只有武器：主手填该职业武器、副手填盾（仅剑盾有盾），头/脚/身空框。
5. 装备栏**右侧（非截图右上角"+"位）一个装备图标按钮** → 点击展开/收起整个装备栏。
6. 点击槽位里的装备 → 弹**独立属性详情框**（仿 `EquipReplaceConfirmUI` 的 Column 卡：图标 + 名称 + 稀有度框 + 属性一条一行），**带全屏遮罩、点任意处关闭**；纯展示、不可操作、不换装。

## 三、任务清单

### T1 · 背包上方新增常驻装备栏（仿截图样式）
- **文件**：新建 `Assets/Scripts/UI/CharacterEquipBar.cs`（**运行时建树，不碰预制体**，挂 `CharacterUI` 的 `Content` 下、`BackpackPanel` 上方）
- **做法**：
  - 容器：深灰黑底 + 金色细线外框 + 四角金装饰（按截图还原色值）。
  - 顶部中央蓝色凸标签 = 当前职业名（初始 `PlayerJobDefs.GetSelected()`，限定 `Playable` 三职业）。
  - 左右两侧金色箭头 `‹` `›`（切职业）。
  - 下方横向一排圆角装备槽（主手/副手/头/脚/身；深色填充 + 细边框，仿截图）。
  - 右侧（**非**右上角"+"位）一个装备图标按钮（栏的开关，见 T2）。
  - 锚定 `BackpackPanel` 上方；竖屏 720×1280 + 瘦屏适配。
- **验收**：进角色页背包上方出现装备栏；蓝标签显示职业名；槽位正常显示。
- **依赖**：无。
- **风险**：位置锚定需适配瘦屏/不同机型；金框蓝标签色值需对像素还原。
- **子模型**：GLM 5.3 Flash / Step-5-Preview（C#）

### T2 · 左右切职业 + 右侧图标开关
- **文件**：`CharacterEquipBar.cs`
- **做法**：
  - 维护当前职业索引（限定 `Playable` 三职业：剑盾/法师/游侠）；左右箭头 ±1 循环；切换时刷新蓝标签 + 下方槽位（**必须按当前职业索引取该职业的起步套，三个职业互串 = bug**）。
  - 右侧装备图标按钮 → 点击展开/收起整个装备栏（显隐 `_root`）。
- **验收**：箭头切职业正确循环且数据不错位；右侧图标可收起/展开装备栏。
- **依赖**：T1。
- **风险**：**三套装备栏不要搞混** —— 切换时槽位填充严格按 `job` 取 `GetJobWeaponKit(job)`，三职业数据隔离。
- **子模型**：同上

### T3 · 槽位填充（按职业起步套，仿战斗装备框）
- **文件**：`CharacterEquipBar.cs`
- **做法**：
  - 槽位类型按部位：**主手 / 副手 / 头 / 脚 / 身**。
  - 数据源：`PlayerJobDefs.GetJobWeaponKit(job)` → **只取** `MainTemplateId` / `OffTemplateId` → `ConfigManager.GetEquipTemplate` → `EquipIcons.Resolve` / `ResolveIcon` 取图标 + `EquipUiText` 取名称。
    - 主手槽填主手武器；副手槽填副手盾（仅剑盾有盾，法师/游侠副手空）；头/脚/身起步套无数据 → 空框。
  - 已装备槽视觉复用 `EquipRarityFrame.SpriteOf(Rarity)` / `EquipRarityRim` + 图标 `preserveAspect`（与战斗一致）。
  - 纯展示，不接点击换装；但槽位需可点 → 接 T4 属性框。
  - **三个职业各自一套起步套，切换时严格按 `job` 取，不要串**。
- **验收**：剑盾 = 剑 + 盾、法师 = 杖、游侠 = 弓；空槽正确；三职业互不串。
- **依赖**：T1、T2。
- **风险**：只取 `GetJobWeaponKit` 的模板 id，**不复制**其写死逻辑；图标/描边口径与战斗一致。
- **子模型**：同上

### T4 · 点击装备槽 → 弹独立属性详情框（仿替换弹窗 Column 卡）
- **文件**：新建 `Assets/Scripts/UI/EquipDetailPopupUI.cs`
- **做法**：
  - 视觉对齐 `EquipReplaceConfirmUI` 的 `FillColumn` 卡片：图标(`EquipIcons.Resolve`) + 名称(`EquipUiText.RarityName` + 上色) + 稀有度框体(`EquipRarityFrame.SpriteOf`) + 属性一条一行(`DraftPool.FormatEquipDescLines`) —— 与替换弹窗**同一套文本/图标口径，避免分叉**。
  - **带全屏 Dim（raycastTarget=1）**，点击 Dim 任意处关闭（满足「点击任意地方关闭」）；**不含**换/不换按钮、不含战力行/新角标（单件展示）。
  - Canvas 走 `UICanvasSetup.ApplyPopup`（摄像机模式 + 模态），层级高于装备栏。
  - 数据源：点击槽位持有的 `EquipInstance`（由起步套模板生成，复用 `TownBackpackGrid.ToEquipInstance` 同类转换）。
- **验收**：点装备槽弹居中属性卡；点空白处关闭；图标/名称/属性/框体正确。
- **依赖**：T3。
- **风险**：单件展示，不要带替换弹窗的战力行/对比箭头；口径与替换弹窗同源。
- **子模型**：同上
