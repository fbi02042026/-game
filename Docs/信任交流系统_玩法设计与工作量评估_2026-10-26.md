# 信任交流系统 玩法设计与工作量评估

> 2026-10-26 主人拍板立项，同日二次、三次拍板修订口径：① 招募佣兵统一走三选一（佣兵名册不做酒馆入口）；② 酒馆下右卡改「信任交流」，**只有佣兵、只有已拥有的佣兵**，不做老板娘/NPC 闲聊；③ 每日**全局 3 次**对话（每佣兵每日限 1 次），对话为**选项式**；④ 满级解锁**专属双人关**（玩家+该佣兵），首通发钻石（**普通 50 / 稀有 100 / 传奇 200**）+ 该佣兵**全属性 ×1.5**，通关后入口显示「**羁绊已建立**」；⑤ 专属关**扣体力，失败重试也扣**；⑥ 功能**通关第 3 章后解锁**；⑦ 后期可送礼物；⑧ 酒馆闲话改为**场景图标入口**：每日限次点击，得随机已拥有佣兵好感 + 剧情补充；⑨ 分批开放佣兵，慢慢增加。

## 1. 一句话方案

酒馆下右卡「信任交流」（通关第 3 章解锁）= 已拥有佣兵的每日闲聊：每天全局 3 次机会、每名佣兵每天限聊 1 次，选项式对话攒信任；信任 4 阶段，满级（生死之交）解锁该佣兵的**专属双人关**——玩家单独带这名佣兵打一场与正常关同模式的战役（扣体力、失败重试也扣），首通按稀有度发钻石（普通 50 / 稀有 100 / 传奇 200），该佣兵全属性永久 ×1.5，入口变「羁绊已建立」；酒馆闲话改为场景图标入口，每日限次点击得随机佣兵好感 + 剧情补充；送礼留二期。

## 2. 玩法设计

### 2.1 信任对象

- **只有佣兵**：只显示「已拥有（SaveData.IsMercUnlocked）∩ 已开放名单」的佣兵。
- 已拥有但未开放名单 → 灰卡「还没熟起来」；未拥有 → 不显示。
- 老板娘好感（TavernEggState）保持现状独立运行，本系统完全不碰。

### 2.2 对话机制（V1 核心）

| 规则 | 设计 |
|---|---|
| 次数 | **每日全局 3 次**（跨佣兵共享），日期键控重置 |
| 每人限额 | 每名佣兵**每天最多 1 次**（3 次 = 3 个不同佣兵） |
| 形式 | **选项式**：佣兵说一段话 → 出 2~3 个选项 → 玩家选 → 佣兵给回应 |
| 收益 | 无论选哪个选项信任 +1（选项只影响回应台词，不做「正确答案」，玩家不用查攻略） |
| 存档 | 次数与「今日已聊名单」进业务存档（跨设备、重进不重置），**不用 PlayerPrefs** |

每日状态字段：`trustTalkDay`（日期）+ `trustTalkUsed`（今日已用次数，0~3）+ `trustTalkedToday`（今日已聊 hireId 集合，跨天清空）。

### 2.3 信任阶段（阈值沿用老板娘那套口径）

| 阶段 | 阈值 | 解锁 |
|---|---|---|
| 初识 | 0 | 基础对话 |
| 相熟 | 10 | 进阶对话 + 弹窗内称呼改昵称（马库斯→老盾） |
| 信赖 | 25 | 深谈（对应叙事 V2.0 §7.4 进度锁 Lore） |
| 生死之交 | 50 | **满级**：解锁专属双人关入口；称谓进佣兵信息弹窗 |

纯搭话升满 ≈ 17 天（每日 3 点），节奏合理。

### 2.4 专属双人关（满级解锁，本系统唯一的玩法大件）

| 项 | 设计 |
|---|---|
| 出战 | **只有玩家（英雄）+ 当前佣兵**二人，其他佣兵不进队 |
| 模式 | 与正常关一致：波次推进、用现有 Battle 体系（新增一种 BattleMode，参考 BattleModes.cs 现有模式注册方式） |
| 难度 | 因佣兵而异，配置表给难度档（如普通档佣兵=简单波次、传奇档=高强度波次），「有的简单有的难」 |
| 体力 | **扣体力，失败重试也扣**（每次进关都扣），数值与主线关一致（主线默认 10，落地照现有进关扣体力链路） |
| 首通奖励 | **钻石**（SaveData.diamond）：**普通 50 / 稀有 100 / 传奇 200**（2026-10-26 主人拍板） |
| 通关后 | 该佣兵**全属性永久 ×1.5**（乘区实现）；入口置灰显示「**羁绊已建立**」（不用「已结缘」） |
| 失败 | 可无限重试，但每次重试都扣体力 |

### 2.5 属性 ×1.5（实现方式，2026-10-26 主人拍板幅度）

- 存档：`trustClearedMercIds`（已通关专属关的 hireId 集合）。
- 乘区挂点：[MercRosterDefs.cs#L462](file:///y:/PixelAdventureTown/Assets/Scripts/Config/MercRosterDefs.cs#L462) 附近（`d.BaseHp * g` 一带），**照 mercOutStars（升星）/ MercGrowSystem（局外养成）两套现成模式加第三套**，互不干扰。
- 幅度：通关专属关后该佣兵**血/攻/防全属性 ×1.5**（永久）。

### 2.6 送礼（V2，先设计留位）

- 送道具加信任（礼物道具 → 背包 → 赠送动画 → 大额信任值）。
- V1 只在 TrustDefs 表和 UI 上留「送礼」按钮位（置灰「敬请期待」），不动道具系统。

### 2.7 分批开放（主人要求）

- 新建 `Assets/Scripts/Config/MercTrustDefs.cs`：每行 hireId + enabled + 难度档 + 四阶段对话组（说辞 + 2~3 选项 + 回应）+ 满级称谓。
- **加人 = 补一行表 + 写对话，代码零改动**。
- 首批建议 4 人（素材现成、职业覆盖齐）：H001 马库斯（老盾·普通）、H007 布罗克（大锤·普通）、H011 路加（牧师·普通）、H004 维克（钢盾·传奇，专属关=最难档，200 钻长线目标）。

### 2.8 功能入口解锁（通关第 3 章，2026-10-26 主人拍板）

- 下右卡按进度点亮：`TavernLore.HighestClearedChapter(d) >= 3`（现成方法，TavernLore.cs L43 附近）才可进入；未达时点击弹提示「通关第 3 章后开放」，卡面副标显示解锁条件。
- 卡面仍叫「信任交流」，置灰态不做新视觉，只拦点击（不动预制体排版）。

### 2.9 酒馆闲话 → 场景图标入口（2026-10-26 主人拍板新去向）

- **位置**：酒馆场景边上（立绘旁）加一个「闲话」小图标按钮，代码动态创建挂在 TavernUI 场景层，**不动预制体排版**（主人已授权加图标；图标资源待定，先用代码占位：圆底+「闲话」字样，资源到位后替换）。
- **每日限次点击**（建议 3 次，日期键控，存档持久）：每次点击 =
  1. 随机一名**已拥有**佣兵 **+1 信任**（走同一个 AddTrust，与对话共享成长）；
  2. 出一条**剧情补充**文本：从 TavernLore 四池（空座位/独眼/老板娘/老队员）随机；空座位文本命中时照走 `TavernLore.NoteSeatViewed()` 计数，**C26 链路保住**。
- 次数用完图标置灰 + 今日剩余提示；复用现有 Toast 展示文本。
- 原 TavernChatPopupUI 的四入口 UI 由本图标取代，弹窗壳改造为信任交流列表（见施工清单）。
