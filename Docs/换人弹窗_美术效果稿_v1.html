0. 头像框统一成酒馆稀有度框（v1.2）
v1 用 Common 的 200×96 横条压成 84×84 正方，四角金饰变形。v1.2 按主人口径，换成全项目「其他界面」（招募池 / 竞技场货架 / 佣兵获得弹窗）同款 酒馆稀有度头像框：传奇金 / 稀有蓝 / 普通银三档，原图 204×248 竖版等比显示，头像叠中心镂空。真源 MercHireSession.LoadTavernCardFrame（走路径加载）。

1. 字号不再整体缩 0.72
现状三栏连带字一起缩到 72%，720 宽下偏小。改为栏内独立字号，靠精简每栏信息腾空间，名字/稀有度/战力各自清晰。
2. 按钮带名字，点前就知道换谁
现状三颗都写「替换」，要记住点了谁。改为「换下马库斯 / 换下洛恩 / 不要了」，决策一目了然，绿=执行、红=放弃沿用项目按钮语义。
3. 新佣兵金框高亮 + 角标
新人与现有两位视觉分层，先看到「来了谁」再决定「换掉谁」，符合玩家决策顺序。
4. 倒计时降级为说明小字
现状倒计时占着 Verdict 主视觉，抢注意力。改为说明行下方灰绿小字，不干扰选择。
5. 阵亡者压暗
已阵亡那位的头像与框整体降透明度，配合红字状态，暗示「换他更划算」。
