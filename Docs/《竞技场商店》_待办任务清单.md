# 《竞技场商店》任务清单（v3 · 积分版定稿）

> 2026-10-30 主人拍板积分版（覆盖 v1「竞技币」方案）：不新增货币，商店直接用竞技场**积分**。
> 收入：输 +10 / 赢 +30 / 连赢有加成；赢一场金币 200 照发；武器买断变灰、佣兵可复购转碎片（满星置灰）；
> 徽记包职业跟随竞技场限定佣兵；弓名「逐风长弓」。
> 两轮施工已完成（2026-10-30，主架构出清单 + 子模型落码 + 回验通过），本文档＝最终口径与调参依据。

## 一、现状（已实现）

- 换位制天梯 100 机器人 + 玩家（`Scripts/Combat/ArenaRules.cs`）；
  每天 10 次免费 + 广告每天 2 次、每次 +2 场。
- 赢一场 200 金币（`WinGold`）照发：走 `ResourceWallet` 入账，胜局结算显示金币格。
- 月赛季结算：金/钻 5 档 + 第 1 名月轮换冠军传奇武器（`Scripts/Config/ArenaSeasonWeapons.cs`，
  运行时注册、Resources 掉落池扫不到 = 天然独占先例）。
- 酒馆三选一（`Scripts/Systems/MercenaryOfferGenerator.cs`），公示概率 66.5/33/0.5。
- 佣兵 22 人（`Data/Source/Tables/merc_roster.csv`）；
  复购转碎片率 `MercStarDefs.DupFragCount`：稀有×5 / 传奇×1；
  升星徽记消耗（该职业）：稀有（中级）0/10/20、传奇（高级）2/5/10（按星 1/2/3）。

## 二、积分与金币口径（定稿）

| 项 | 旧 | 新 |
|---|---|---|
| 赢一场 | 吃分差 + 距离奖励 | **+30 基础** |
| 连赢加成 | 无 | 第 2 场起每场 **+10，封顶 +30**（第 4 场起赢一场=60） |
| 输一场 | −5 | **+10**（不掉名不变） |
| 金币 | 赢 +200 | 不变（照发 +200，结算面板显示） |
| 用途 | 只做排名数字 | 排名展示 + **商店消费货币**（扣积分不动排名，见 §四.1） |

- 熔断/保底（真战斗版，**不掷骰**）：新手必赢 3 场 / 熔断（连赢 3~5 必断）/ 连输保底 / 低分保底，
  全部以**对手战力压制/放水**实现——进本组队时按门状态乘敌方战力系数
  （`ValveEasePowerMul = 0.6` 放水 / `ValveHardPowerMul = 1.9` 加压，常量可调）；
  🔴 阀门判定严禁进 `IsChallengeable`/`CanEnter` 等查询函数，只在进本组队路径生效。
- `ArenaRules.ChallengeBonusPoints` / `LosePoints` 已退役（注释标废）。
- 日收入估算（胜率约六成）：免费 10 场 ≈330 积分；拉满 14 场 ≈460 积分。

## 四、商店规则（定稿）

1. **积分扣减不动排名**：排名真源 = 换位链（`arenaPlayerPos`），积分只是数值；
   花积分不改变榜位（`EnsureLadder` 只在版本升级 / 新赛季重建时按分插位）。
   验收：买完 12000 积分的大件后排名不变、可继续正常挑战。
2. **佣兵复购 = 碎片**：首购获得佣兵本体；已拥有后再买按 `DupFragCount` 转本命碎片
   （稀有×5 / 传奇×1），未满星按钮**不变灰**，文案标注「已拥有 · 再次购买转碎片×N」；
   **满星后购买键置灰**，点击 toast「已满星，先拿碎片去升星吧」不扣分。
   ——这同时解决了限定佣兵摘池后升星碎片无来源的问题。
3. **武器买断**：购买后按钮变灰「已拥有」。
4. **周限**：周 key 照 `ShopDefs.TodayKey` 口径记周 key，跨周自动恢复次数。
5. **赛季清零**：月底 `arenaPoints` 清零 = 商店余额作废（赛季制，制造消费节奏）。
   商店页顶提醒：赛季最后 3 天挂「本赛季积分 X 日后清零」横幅（一句文案）。
6. **榜首断供修复**：登顶（第 1 名上方无人）= 收入断供。挑战范围扩为——
   · 上方相隔 ≤3 名：**换位赛**（赢=换位）；
   · 下方相邻 ≤3 名：**积分赛**（赢/输照常发积分，赢了**不换位**、输了不掉名）。
   任何排名永远有得打、有得赚，第 1 名也能刷满每日 10 场。
7. **榜单展示**：玩家积分会远超机器人段位分（几千 vs ≤1500），属预期
   （机器人分=段位参照，玩家分=赛季总积分），验收只查不破版式。

## 五、施工清单（2026-10-30 两轮已落地 · 留作验收与调参依据）

1. **积分公式**（`ArenaRules.ApplyBattleOutcome`）：
   胜 = 30 +（本场前连赢数 ≥1 时 `min(30, 连赢数×10)`）→ 30/40/50/60；败 = **+10**（不掉名）；
   金币照发 +200（`ResourceWallet` 入账 + 胜局结算金币格）；`arenaWinStreak` 恢复驱动（赢 +1 / 输清零）；
   结算展示：胜局积分格 + 金币格、败局 toast（+10）。
   验收：连赢第 1/2/3/4 场 = 30/40/50/60；败 = +10；胜局金币 +200 入账并显示；存档重启不丢。✅
2. **挑战范围扩展**（§四.6）：`IsChallengeable` 加「下方相邻 ≤3 名」分支；
   `ApplyBattleOutcome` 对下方目标赢了跳过换位段，照常发积分金币、记对战记录。
   验收：榜首可打第 2~4 名且赢后仍第 1；每日任务计数照走。✅
3. **三选一摘池**：`MercSkillMapping` 选人集合排除 H014/H017/H022（常量排除集，不动 `merc_roster.csv`）。
   验收：模拟 2000 抽不出现三名；老档已拥有不回收；公示概率文案不动。✅
4. **限定稀有弓模板**：照 `ArenaSeasonWeapons.BuildTemplate` 口径 `baseRarity=Rarity.Rare`，
   运行时注册（挂 `ArenaRules.EnsurePeriods` 调用链）；属性对 `equip_attr_ranges` 稀有档武器区间；
   获得时随机 1 词条（暮火之杖特性池先例）；出战游侠替换初始主手。
   验收：`Resources.LoadAll` 掉落/抽奖池扫不到该 id；游侠出战主手已替换；非游侠职业无感。✅
5. **商店 UI**（布局在 `ArenaPopupUI.prefab`，主人手摆；「商品」单元为示例模板，节点名/层级可改，
   美术排版保持原样，禁重跑生成器）：
   - 骨架：`Top/竞技商店Btn` 开关页；`竞技商店` 页 → `RecordsBox` → `RCloseBtn`(关) /
     `底框` / `积分icon`(Text=余额) / `商品`(示例单元) / `RTitle` / `人`（装饰，不用代码管）。
   - 需求（硬）：① 货架只放**图标 + 积分价格**；② 图标底框（规则：**没有的按说明造，已经有的原样用**）——
     prefab `商品图框` 已给 sprite 就不覆盖；现状未给 → 佣兵用佣兵稀有度框
     （`MercHireSession.LoadRarityFrame` 头像框档，`TavernCardFrameDir` 传奇/稀有/普通），其余按稀有度选底框；
     ③ 点商品弹**购买/取消**信息框（`StaminaConfirmPopup.Show`，标题=商品名、正文=价格/效果/已拥有说明）；
     ④ 页顶积分余额（订阅 `ArenaRules.Changed` 即时刷新）；⑤ 积分不足：购买键**置灰但保持可点**，
     点击 toast「积分不足」不入账（`SetOkGray` 小钩子，仍走通用弹窗）；
     ⑥ 佣兵**满星**后购买键同样置灰，点击 toast「已满星，先拿碎片去升星吧」不扣分。
   - 货架 = §三 8 件，运行时复制示例单元排格，不动 prefab YAML。
   验收：720×1280 不拉伸；缺图 `LogError` 不兜底；买后余额即时刷新；佣兵框与稀有度对得上。✅
6. **存档字段**：弓购买记录（模板 id）、佣兵首购态、周限计数 + 周 key（挂 `SaveData`，持久化）。
   验收：跨周恢复；重启不丢；积分不足/满星购买被拦，重复扣款不会发生。✅
7. **发放链**：佣兵走现有招募入队链（已拥有自动转碎片入包）；弓进随身仓库 `legacyEquipPool`
   （冠军武器邮件附件口径）；金币包走 `ResourceWallet`；徽记包走 `MercGrowInventory`。
   验收：发放失败退分可重试（里程商店口径）。✅
8. **提醒与公示**：赛季最后 3 天商店页顶清零横幅（§四.5）；
   酒馆公示弹窗补「伊芙 / 莉娜 / 索尔 仅竞技场产出」。✅
9. **掷骰阀门恢复（真战斗版）**（同 §二）：六个阀门字段全量恢复驱动；
   进本组队按门状态乘敌方战力系数（放水 ≈×0.6、加压 ≈×1.9，校准到命中率 ≈95%）；
   🔴 判定严禁进 `CanEnter` 等查询函数。
   验收：新号前 3 场必赢；连赢 3~5 场内断连；连输 2~3 场内回血；无 Random 判胜负路径。✅
10. **一键跳过**：竞技场真战斗「跳过」键（仅 `BattleModeId.Arena`；prefab 无则运行时补，主人摆了就用 prefab 的）；
    点击 → `Time.timeScale` 6× 跑到结算自动恢复；**所有退出路径**（结算/死亡/撤离/OnDestroy）必须恢复 timeScale=1。
    验收：跳过快速出结算且胜负为真实战斗产出；回城镇 timeScale=1 无残留；非竞技场无跳过键。✅
