## 九、数值基线（原文 §0.5，推演都按这套）

| 项 | 值 |
|---|---|
| 一章抽数 | 约 8~9 抽 |
| 随机价 | 80 起，每抽 ×1.1 **不封顶** |
| 定向价 | 随机价 × 2（`FOCUS_PRICE_MULT`） |
| 类型权重 | 装备 70 / 技能 20 / 佣兵 10（10-12 主人拍板） |
| 安慰奖 | 金币，权重 6 恒定，金额 = 当前抽价 × 0.5 |
| 章 1 实测品质分布 | 传说 0.6% / 稀有 23.6% / 普通 64.3% / 金币 11.4% |
| 一局见不到传说 | **至少 77%** |
| 佣兵传说一局可见率 | 仅 0.5%~2.5% |

> 传导链：**抽奖次数↑ → 单局时长↑ → 在线时长↑ → 次日留存↑ → 广告曝光↑ → 广告变现↑**

## 十、两个结构裁定的结论（原文第五节）

**任务 2「渐进开放 / 锁类别」→ 反对。** 五条理由里最硬的一条是技术约束：引导定序第 2 拍必招塔克、第 3 拍固定治愈之泉，锁类别**必须给引导局豁免**，于是「教程教三类、正式局只给一类」口径自相矛盾；且塔克的升级/升星卡就在佣兵池里，章 1 锁佣兵 = 教程给的第一个佣兵整章不能升级。替代方案是**价值可见性四件套**（#2 卡面尺子 + 槽位参照系 + 定向曝光 + #10 pity）。

> 一句话：**"一次给太多"的真解是"每一给都看得懂"，不是"少给几次"。**

**任务 3「拆按钮」→ 不拆。** 普通（随机）是主菜、定向（160 = 两抽随机换精度）是调味，这个分工不动。真正要修的是**定向池混着金币安慰奖**，花 160 可能回 40 金币，「定向 = 必出该类」目前不成立（#12 修它）。
