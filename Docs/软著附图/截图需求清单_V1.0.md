## 怎么截

1. **Tools → 软著 → 开启自动截图（Play 模式）**，再进 Play（720×1280）
2. 开机先停在健康忠告（约 3 秒，不要立刻点掉）
3. 登录页 **清除存档**，按正常流程玩
4. 打到 Boss 关停一下（18）；城镇点「冒险日志」停在怪物页（20）；点「角色」「酒馆」各停一下（34、38）
5. 左上角 `已截/18` 满了即可。重跑先 **重置自动截图进度**
