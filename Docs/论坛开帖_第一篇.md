# 《像素冒险：裂隙之刃》来了——我们的第一篇，先交个朋友

嗨，各位。

我们是做《像素冒险：裂隙之刃》的小团队。趁着游戏在 TapTap 上架，开这个论坛第一帖，先跟大家打个招呼，也算是……正式报到。

一句话先把话说清楚：**装备是随机的，技能是随机的，佣兵是随机的，关卡也是随机的**——你啥都不用操心，只负责点点点，以及，决定什么时候溜回城。

游戏现在已经在 TapTap 上架了（页面 / 试玩），正式开放下载的时间我们会在这里通知大家。
