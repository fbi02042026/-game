# 战斗流程（2026-09-14 定稿）

> 本轮改动：
> 1. 战斗结束奖励从「宝箱掉装备 → 装备三选一」改为
>    **「类型三选一（技能 / 装备 / 佣兵）→ 该类型三选一」**，并按新底部布局重绑战斗 HUD。
> 2. **取消局内升级 / 经验条**：局内不再有等级，属性只由「天赋树 + 本局构筑」决定。
> 3. **天赋产出改为「天赋石」**（`ResourceType.TalentPoint` 即天赋石，UI 文案已改）。
> 4. **Boss 关给 2 次三选一**，普通 / 精英关 1 次。
> 5. **死亡 / 撤离保留本局金币**，并按金币产出天赋石；佣兵最大 2 个。
> 6. **异常退出 3 分钟内可续关**，从中断那一关的开头重打。

## 一、完整流程

```
进战
 ├ RunDraftDirector.OnRunStart()
 │   ├ RunLoadout.BeginMemoryMode（教程）/ ResumeOrBegin（正式局）
 │   ├ RebuildPlayerSkills()   → SkillSystem.SetPlayerSkills
 │   ├ RestoreRunMercs()       → MercenaryManager.SpawnMercenary
 │   └ RunSkillBarUI.Ensure() + Refresh()
 │
战斗（自动战斗 + 玩家点技能/头像）
 ├ BattleManager.Update → RunDraftDirector.Tick()
 │     升级抽卡已移除：pendingLevelUps 一律清零，不再弹三选一
 ├ BattleStateSaver 心跳：每 10s 写一次「章节 / 关卡 / 难度 / 退出时刻」
 │
 └ 清完当前关所有波次 → 到达终点 → BattleManager 结算
      ├ 计算 bonusGold / 生成宝箱装备 rewards
      └ StageClearRewardDirector.Begin(rewards, bonusGold, stageType)
           ├ 1. 开箱动画（mu / yin / jin 三档箱皮）
           ├ 2. 金币飞入资源条
           ├ 3. ScrapRewardEquips()   宝箱装备折金（装备已并入三选一）
           ├ 4. CoStageClearDraft(pickCount)
           │      ├ 普通 / 精英关：pickCount = 1
           │      └ Boss 关：pickCount = 2（连抽两次）
           │      每次：
           │        ├ 第一层：DraftPool.BuildCategories() → 技能 / 佣兵 / 装备
           │        ├ 第二层：DraftPool.BuildCards(分类)   → 该分类 3 张卡
           │        └ 选中 → RunDraftDirector.ApplyCard(card) 立即生效
           ├ 5. RunDraftDirector.NoteStageProgress() 落档（供「继续上一局」）
           ├ 6. BattleLootMode.Enter() 整理装备
           └ 7. 传送门 → NotifyChuanSongMenOpened → 走过去 → 下一关 / 结算
```

**抽卡节奏**
- 一章 10 关，槽位共 12 个（技能 4 / 佣兵 2 / 装备 6）。
- 普通 + 精英关每关 1 抽，Boss 关 2 抽 → 一章约 11 抽，基本能在章节末凑齐构筑。

**要点**
- 三选一**只在战斗结束触发**，不再与升级挂钩（局内没有等级）。
- 佣兵**不再按酒馆等级解锁**，改为「三选一招募即解锁」，上限 2 个。

## 五、中断规则：不杀进程一直保留，杀进程 = 撤离失败

> 2026-09-14 二次修订：取消了上一版的「3 分钟内自动续关」。

```
战斗中
 ├ BattleManager.LoadStage()  → SaveBattleState()（进关写一次快照）
 ├ BattleStateSaver.Update()  → 每 10s 心跳续写（金币 / 统计 / 时刻）
 └ OnApplicationPause(true) / OnApplicationQuit → SaveBattleState()

正常结束（通关 / 死亡 / 撤离）→ ClearBattleState()  ← 不会留下档

重进游戏
 └ Town 就绪 → BattleStateSaver.SettleInterruptedRun()
     ├ 无档 → 什么都不做（正常流程）
     ├ 有档 + 引导未完成 → 静默清档，不弹面板（避免打断剧情）
     └ 有档 + 引导已完成 → 判「撤离失败」：
          · 金币按 (currentGold - goldAtRunStart) 差额写回，天赋石照发
          · RunLoadout.Clear() + hiredMercs.Clear()（技能/佣兵/装备清空）
          · 体力不退
          · 弹 BattleSettlementUI（副标题「撤离失败」）→ 回冒险页
          · 清档
```

**口径**
- 「有残留档」== 上次没走正常收尾 == 被强杀，所以**不需要 cleanExit 标记**。
- 结算数据全部来自存档快照（进程死了内存态全丢），因此心跳必须写
  `currentGold` / `goldAtRunStart` / 击杀 / 伤害 等字段。
- 不恢复血量、不恢复半关进度、不续关——本局直接结束。
- 文案已同步：`PausePanel`、`EvacuateConfirmPopupUI` 不再提「下次上线可继续战斗」。
