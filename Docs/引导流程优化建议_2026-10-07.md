# 新手引导优化建议（2026-10-07）

> 主人原话：「这个引导肯定是重中之重，玩家最初就要吸引玩家的，要有爽感、有钩子」。
> 本文只给**方案与理由**，未动代码；要动哪几条请主人点名。

---

## 一、现在的节拍（改完「两波后首抽」之后）

| 时间 | 发生什么 | 玩家的情绪 |
|---|---|---|
| 0~8s | 进场 → 教移动/自动攻击 → 第 1 波怪走过来 | **空白**，还没打到人 |
| 8~25s | 清第 1 波 + 混编第 2 波 | 开始有反馈，但怪很软，没记忆点 |
| 25s | ① 抽（装备） | 第一次"变强"，但**没仪式感** |
| 25~60s | 宝箱陷阱 → 埋伏 → 开箱 → 天赋石 | 信息量大，玩家在读字不是在爽 |
| 60s | ② 抽（佣兵小白） | 有人陪了，但**她太弱、存在感低** |
| 60~100s | 精英波 → ③ 抽（技能）→ 第 5 波 | 三次抽奖挤在下半段 |
| 100~140s | 压轴波（打不完）→ 撤离 → 回城对白 | **结尾是"失败"，没有钩子** |

### 三个真问题

1. **前 8 秒没有爽点** —— 玩家还没有"我很强"的第一印象，就已经在读教学了。
2. **抽奖没有仪式感** —— 抽到好东西和抽到垃圾的表现几乎一样，"抽奖"这个核心循环的第一次体验被浪费了。
3. **结尾是挫败** —— 压轴故意打不完 + 撤离，玩家最后的情绪是"我打不过"，而不是"我还想玩"。

---

## 二、建议：三段钩子（按性价比排序）

### 🥇 钩子 1：开场 3 秒给一次"我很强"

- 进场第一波怪**直接贴脸 + 血量压到 3 下就死**（表内可调），让玩家**3 秒内完成第一次击杀**。
- 或者更狠：开场送一次**免费的「裂隙之刃」全屏斩**（一键清掉第 1 波）。
- **理由**：第一印象决定留存。玩家在 5 秒内体验到"割草"，才会愿意继续看教学。
- **指标**：直接喂**首次留存**（前 60 秒流失是最大的漏斗）。

### 🥈 钩子 2：第一次抽奖做成"开箱演出"

- ① 抽（装备）**必给明显更强的武器**（不只是 +18%，建议直接给高一档稀有度），
  让玩家**下一波立刻能验证**：怪倒下的速度肉眼可见变快。
- 抽到紫色及以上 → 加**光柱 + 定格 0.6s + 音效**；抽到白色也要有个"开箱"动作，别只是一行字。
- **理由**：抽奖是本作核心循环，第一次抽卡的记忆点决定玩家会不会为它留存。
- **指标**：喂**在线时长 + 后续抽奖参与度**。

### 🥉 钩子 3：结尾留一个"未完成的目标"

- 撤离后不要停在"我打不过"。改成：**"成功撤离，带回 XX 奖励"** + 小白一句**"我等你回来"**。
- 再给一个**次日回归奖励**（次日登录送抽奖币 ×N），让玩家带着"明天还要来"离开。
- **理由**：引导的最后一屏 = 次留的开关。现在最后是挫败感，等于把人推走。
- **指标**：直接喂**次日留存**。

## 三、节奏建议：每 30 秒一个小高潮

现在的问题是**变强和验证不成对**。建议改成严格的循环：

```
变强（抽奖）→ 验证（打一波明显更难的）→ 再变强 → 再验证
```

| 段 | 内容 | 目的 |
|---|---|---|
| 0~30s | 贴脸割草 + ① 抽装备（演出） | 第一印象 + 核心循环初体验 |
| 30~60s | **验证波**：比第 1 波明显更多的怪，玩家用新武器轻松清掉 | 让"变强"被看见 |
| 60~90s | 宝箱陷阱 + ② 抽佣兵（小白立刻奶一口，存在感拉满） | 伙伴 + 第二次高潮 |
| 90~120s | 精英波（镜头拉近 + 血条出场动画） | 第一个"BOSS 级"记忆点 |
| 120~150s | ③ 抽技能 → **技能首秀**（全屏特效） | 第三次高潮 |
| 150s~ | 压轴 → 撤离 → **正反馈收尾 + 次日钩子** | 把人留住 |

## 四、小成本但很加分的细节

| 项 | 做法 | 成本 |
|---|---|---|
| 伤害飘字 | 暴击数字放大 + 变色 | 低 |
| 连杀提示 | 3/5/10 连杀各一句短提示 | 低 |
| 战力跳动 | 拿到装备时战力数字**滚上去**而不是直接跳 | 低 |
| 精英出场 | 镜头轻微拉近 0.3s + 专属音效 | 中 |
| 击杀精英 | 0.4s 慢动作 + 掉落爆发 | 中 |
| 小白存在感 | 入队后立刻奶一口 + 治疗数字飘绿字 | 低 |

## 五、如果要动，建议的顺序

1. **钩子 3（结尾钩子）** —— 改动最小、对次留最直接，先做。
2. **钩子 1（开场 3 秒）** —— 调表 + 一次开场演出，半天。
3. **钩子 2（抽奖演出）** —— 需要美术配合光柱/音效，排期最长。
