# 像素冒险：裂隙之刃 V1.0 装备系统核心规则

> 装备系统是战斗养成的重要支柱。本文档约定全装备共享的部位、稀有度、成长规则、属性限定总览、掉落规则与随机命名通用规则，作为武器、防具与饰品子系统的基础。

## 1. 装备部位

| 部位 | 装备类型 | 定位 |
|---|---|---|
| 武器 | 剑、斧、锤、长矛、弓、法杖、盾牌 | 主要输出或防御来源 |
| 头盔 | 轻盔、重盔、兜帽 | 防御 / 生命 / 抗性 |
| 胸甲 | 皮甲、链甲、板甲、布袍 | 防御 / 生命 |
| 护腿 | 皮裤、战裙、法袍下装 | 防御 / 生命 / 移速 |
| 鞋子 | 皮靴、战靴、布鞋 | 移速 / 闪避 |
| 戒指 | 普通戒指、元素戒指、战戒 | 攻击 / 暴击 / 元素 / 生命 |
| 项链 | 护符、吊坠、念珠 | 防御 / 生命 / 能量恢复 / Buff 时长 |

## 2. 稀有度与加成

| 稀有度 | 颜色 | 基础属性加成 | 随机词条数 | 特殊效果 |
|---|---|---|---|---|
| 普通 | 白色 | 100% 基础值 | 0 | 无 |
| 稀有 | 蓝色 | 110% ~ 120% 基础值 | 1 | 词条数值为标准区间 |
| 史诗 | 紫色 | 125% ~ 140% 基础值 | 1 | 单条词条数值比稀有高 30% ~ 50%，更突出质变 |
| 传奇 | 橙色 | 150% ~ 180% 基础值 | 2 | 2 条词条均以被动技能 / 特效为主，体现独特价值 |

## 3. 成长规则

**基础属性区间**

- 同种装备掉落时，基础属性在预设区间内随机取值。
- 稀有度决定区间上限，传奇装备基础值不会低于该装备类型的稀有下限。

**强化等级**

| 强化等级 | 消耗 | 效果 |
|---|---|---|
| +1 ~ +5 | 强化石 | 每级提升 5% 基础属性 |
| +6 ~ +10 | 强化石 + 金币 | 每级提升 6% 基础属性，+8 起有小概率失败不掉级 |
| +11 ~ +15 | 高级强化石 + 金币 | 每级提升 8% 基础属性，失败可能回退 1 级 |

> V1.0 强化上限暂定为 +10，后续版本可扩展。

**属性成长公式**

```
最终属性 = 基础属性 × (1 + 强化等级 × 成长率) × 稀有度系数 + 随机词条加成
```

- 普通成长率：5%
- 稀有/史诗/传奇成长率：6% / 7% / 8%

## 4. 属性限定总览

> 不同装备部位有主属性倾向，随机词条不会跳出该部位可出现的属性池。

| 部位 | 可出现的主属性 | 不会出现的属性 |
|---|---|---|
| 剑 / 斧 / 锤 / 长矛 | 物理攻击、暴击率、暴击伤害、攻速 | 法术强度、魔法穿透 |
| 弓 / 弩 | 物理攻击、攻速、暴击率、射程 | 法术强度、格挡率 |
| 法杖 | 法术强度、法术穿透、元素伤害、能量恢复 | 物理攻击、暴击伤害 |
| 盾牌 | 防御、生命、格挡率、减伤 | 物理攻击、法术强度 |
| 头盔 / 胸甲 / 护腿 | 防御、生命、减伤、元素抗性 | 攻击、攻速、暴击 |
| 鞋子 | 移速、闪避、生命 | 攻击、防御 |
| 戒指 | 攻击、暴击、元素伤害、生命、能量恢复 | 防御、格挡 |
| 项链 | 防御、生命、能量恢复、Buff 时长、减伤 | 物理攻击、攻速 |

## 5. 随机词条池总览

| 词条类型 | 作用 | 常见部位 |
|---|---|---|
| 物理攻击 +N | 提高物理伤害 | 武器、戒指 |
| 法术强度 +N | 提高法术伤害 | 法杖、戒指 |
| 防御 +N | 提高减伤 | 盾牌、防具、项链 |
| 生命 +N | 提高生命上限 | 防具、盾牌、项链 |
| 攻速 +N% | 提高攻击速度 | 武器、弓 |
| 移速 +N% | 提高移动速度 | 鞋子、护腿 |
| 暴击率 +N% | 提高暴击概率 | 武器、戒指 |
| 暴击伤害 +N% | 提高暴击倍率 | 武器、戒指 |
| 元素伤害 +N% | 火/冰/雷/毒等属性伤害加成 | 法杖、戒指、项链 |
| 元素抗性 +N% | 对应属性伤害减免 | 防具、项链 |
| 格挡率 +N% | 概率格挡部分伤害 | 盾牌、头盔 |
| 闪避 +N% | 概率完全躲避攻击 | 鞋子、护腿 |
| 减伤 +N% | 全伤害减免 | 盾牌、胸甲 |
| 生命恢复 +N/秒 | 战斗中持续回血 | 胸甲、项链 |
| 能量恢复 +N% | 加快技能冷却 / 能量回复 | 法杖、项链、戒指 |
| 击杀回血 +N | 击杀敌人恢复生命 | 武器、戒指 |
| Buff 时长 +N% | 增益效果持续时间 | 项链、戒指 |

## 6. 随机命名通用规则

> 装备名称由「前缀 + 基础名 + 后缀」组成。前缀表按武器、防具与饰品拆分到各自子系统文档；本文档只约定通用结构与后缀规则。

**命名结构**

```
[前缀] + [基础名] + [后缀]
```

- **前缀**：决定装备主词条倾向，同时融入世界观（裂隙、星火、磐石、流风等意象）。详见武器/防具与饰品设计文档。
- **基础名**：装备类型与外观标识，如圆盾、短剑、长弓、法杖。
- **后缀**：仅在稀有及以上出现，标识稀有度或传奇特效。

**后缀表（按稀有度）**

| 稀有度 | 后缀示例 | 说明 |
|---|---|---|
| 普通 | 无后缀 | 仅前缀 + 基础名 |
| 稀有 | ·精良 | 单条标准词条 |
| 史诗 | ·卓越 | 单条高数值词条 |
| 传奇 | ·传说 / ·永恒 / ·裂隙 | 2 条被动/特效词条，带传奇光效 |

## 7. 掉落规则

| 装备来源 | 稀有度分布 | 说明 |
|---|---|---|
| 普通关卡 | 普通 70%、稀有 28%、史诗 2% | 批量产出基础装备 |
| 精英关卡 | 普通 50%、稀有 40%、史诗 9%、传奇 1% | 概率获得史诗 |
| 首领关卡 | 普通 30%、稀有 45%、史诗 20%、传奇 5% | Boss 掉落品质更高 |
| 裂缝宝箱 | 普通 40%、稀有 40%、史诗 15%、传奇 5% | 高价值来源 |
| 里程商店 | 按商品固定 | 普通/稀有/传奇佣兵招募卷轴，不出装备 |

## 8. 装备与冒险日志的关系

- 装备图鉴可扩展进「世界图鉴 → 物品」子标签，记录玩家获得过的不重复装备名称。
- 首次获得某件史诗/传奇装备时，可解锁对应条目并奖励少量里程。
- V1.0 暂不强制做装备图鉴，但数据结构预留 `Item` 分类字段。
