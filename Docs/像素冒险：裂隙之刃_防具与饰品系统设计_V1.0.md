# 像素冒险：裂隙之刃 V1.0 防具与饰品系统设计

> 防具与饰品承担生存、机动与辅助功能，独立于武器系统成文。

## 1. 部位与定位

| 部位 | 装备类型 | 定位 |
|---|---|---|
| 头盔 | 轻盔、重盔、兜帽 | 防御 / 生命 / 抗性 |
| 胸甲 | 皮甲、链甲、板甲、布袍 | 防御 / 生命 |
| 护腿 | 皮裤、战裙、法袍下装 | 防御 / 生命 / 移速 |
| 鞋子 | 皮靴、战靴、布鞋 | 移速 / 闪避 |
| 戒指 | 普通戒指、元素戒指、战戒 | 攻击 / 暴击 / 元素 / 生命 |
| 项链 | 护符、吊坠、念珠 | 防御 / 生命 / 能量恢复 / Buff 时长 |

## 2. 防具与饰品主属性规则

| 部位 | 可出现的主属性 | 不会出现的属性 |
|---|---|---|
| 头盔 / 胸甲 / 护腿 | 防御、生命、减伤、元素抗性 | 攻击、攻速、暴击 |
| 鞋子 | 移速、闪避、生命 | 攻击、防御 |
| 戒指 | 攻击、暴击、元素伤害、生命、能量恢复 | 防御、格挡 |
| 项链 | 防御、生命、能量恢复、Buff 时长、减伤 | 物理攻击、攻速 |
| 盾牌 | 防御、生命、格挡率、减伤 | 物理攻击、法术强度 |

> 盾牌归属武器位，但主属性池与防具一致，便于统一掉落与强化。

## 3. 防具与饰品专属词条池

| 词条类型 | 作用 | 常见部位 |
|---|---|---|
| 防御 +N | 提高减伤 | 盾牌、防具、项链 |
| 生命 +N | 提高生命上限 | 防具、盾牌、项链 |
| 移速 +N% | 提高移动速度 | 鞋子、护腿 |
| 元素抗性 +N% | 对应属性伤害减免 | 防具、项链 |
| 格挡率 +N% | 概率格挡部分伤害 | 盾牌、头盔 |
| 闪避 +N% | 概率完全躲避攻击 | 鞋子、护腿 |
| 减伤 +N% | 全伤害减免 | 盾牌、胸甲 |
| 生命恢复 +N/秒 | 战斗中持续回血 | 胸甲、项链 |
| 能量恢复 +N% | 加快技能冷却 / 能量回复 | 项链、戒指 |
| Buff 时长 +N% | 增益效果持续时间 | 项链、戒指 |
| 攻击 +N | 提高基础攻击（仅戒指） | 戒指 |
| 暴击 +N% | 提高暴击概率（仅戒指） | 戒指 |
| 元素伤害 +N% | 元素伤害加成（戒指/项链） | 戒指、项链 |

## 5. 命名示例

| 名称 | 稀有度 | 词条 | 定位 |
|---|---|---|---|
| 铁壁之圆盾 | 普通 | 防御 + 生命 | 新手盾 |
| 厚甲之皮甲·卓越 | 史诗 | 生命上限（高数值） | 狂战/盾卫生存装 |
| 影步之布鞋·精良 | 稀有 | 闪避（标准值） | 脆皮职业保命鞋 |
| 回春之链甲·传说 | 传奇 | 生命恢复 + 「受到伤害概率回血」被动 | 坦克续航装 |
| 灵能之护符·永恒 | 传奇 | 能量恢复 + Buff 时长 + 「技能冷却刷新」被动 | 法师/牧师辅助装 |

## 6. 特殊效果规则

- **稀有**：1 条随机词条，数值为标准区间。
- **史诗**：1 条随机词条，数值比稀有高 30% ~ 50%，追求单属性质变。
- **传奇**：2 条随机词条，且以被动技能 / 特殊效果为主，体现装备的不可替代性。
