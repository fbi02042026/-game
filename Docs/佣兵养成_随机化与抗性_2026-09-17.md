## 7. 🆕 徽记掉落（怪物掉落表 + 按地图分职业）

### 7.1 落到哪张表

**`Assets/Data/Source/Tables/monster_stats.csv` 末尾加 3 列**（改完必须 Cook 成 `.bytes`）：

```
...,note,badgeJob,badgeTier,badgeRate
```

| 列 | 含义 |
|---|---|
| `badgeJob` | 该怪掉哪个职业的徽记（剑盾/游侠/狂战/法师/牧师/重武），**留空 = 不掉** |
| `badgeTier` | 低 / 中 / 高 |
| `badgeRate` | 掉落率（0~1）。Boss 填 1 = 必掉 |

现有怪物 **96 只，每章 12 只**（10 普通 + 2 Boss）。**每章只有部分怪挂徽记**（约 3 个职业 × 3~4 只），其余留空 → 这就是"不要全部都掉"。

### 7.2 掉落率

| 怪类型 | 掉落 | 数量 |
|---|---|---|
| 普通怪 | **1%** | 1 |
| Boss | **100%（必掉）** | 1 |
| 精英关额外 | 结算时 +1（`stageType=Elite`） | 1 |

一局（约 10 关、1 Boss、~60 普通怪）≈ **1.6 个徽记** → 一周目（195 局）≈ **310 个**。
对照需求：主力 5 人 250 个 → **约 1 周目**；全员 855 个 → **约 3 周目**。
✅ 徽记**不是瓶颈**（瓶颈仍是本名碎片），但按职业凑会显著拉长，正好实现"想要哪个职业就去刷哪张图"。

### 7.3 按地图分职业（每章主产 3 个职业）

| 章 | 主产职业（各 3~4 只怪） | 档位分布 |
|---|---|---|
| ch1 暮影森林 | **剑盾卫士 / 游侠 / 重武者** | 低 100% |
| ch2 墓园 | **剑盾卫士 / 狂战士 / 游侠** | 低 100% |
| ch3 雨林 | **狂战士 / 游侠 / 重武者** | 低 85% / 中 15% |
| ch4 原野 | **狂战士 / 法师系 / 游侠** | 低 65% / 中 35% |
| ch5 海渊 | **法师系 / 牧师 / 狂战士** | 低 35% / 中 65% |
| ch6 岩窟 | **法师系 / 牧师 / 剑盾卫士** | 中 80% / 高 20% |
| ch7 炼狱 | **狂战士 / 牧师 / 法师系** | 中 55% / 高 45% |
| ch8 永霜 | **剑盾卫士 / 重武者 / 法师系** | 中 30% / 高 70% |

**覆盖自检**：
- 低级：8 章全有 ✅
- 中级：剑盾 ch4/6/8、游侠 ch3/4、狂战 ch4/5/7、法师 ch4~8、牧师 ch5/6/7、重武 ch3/8 ✅
- 高级：**只有剑盾(ch6/8)、狂战(ch7)、法师(ch6/7/8)** —— 见下方说明 ✅

> ⚠️ **重要发现**：传奇佣兵只有 3 个（H004 剑盾 / H010 狂战 / H014 法师），**所以「高级徽记」只有这 3 个职业真的用得上**。
> 游侠 / 牧师 / 重武者目前没有传奇档，只需要低 + 中。这 3 个职业的高级徽记**可以先不做**，等以后加了传奇佣兵再补。
> 注意：徽记是**职业绑定、不绑个人**，所以同职业多个佣兵共用一套。

### 7.4 保底（防脸黑）

每章**首次通关**额外给 **2 个「自选职业徽记」**（档位 = 该章主产档位上限）。这样即使某职业的图没刷到，也不会卡死。
重复通关同一章不再给自选，只靠怪物掉落 —— 保持"刷图"动力。

## 8. 抗性（不变）

- 只分物抗 / 魔抗（0~50%）：`最终伤害 = 原伤害 × (1 - 抗性)`。
- 类型由**施法者职业**定：**法师系 + 牧师（7 人）= 魔法**，其余 15 人 = 物理；玩家 Mage/Priest = 魔法；**治疗不吃抗性**。
- `monster_stats.csv` 加 `physResist` / `magicResist` 两列（0~50），与徽记列**同一次 Cook**。
- 按章递增、同波混编（ch1 物抗 15% → ch8 双 50%）；精英/Boss 一高一低，第 7/8 章 Boss 双高。
