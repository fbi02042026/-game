## 三、待落地任务（等子模型恢复后按序做）

### T1 战斗 HUD 里二次抽到塔克头像不显示 ★
- **现象**（主人已澄清）：**战斗 HUD** 的佣兵头像；**第二次**抽到后不显示。
- **排查方向**：HUD 头像槽的创建 / 刷新（`BattleUI*.cs`、`AutoGameInitializer.cs` 的 HUD 绑定段）。
  重点：槽位预创建固定数量、第二次新增佣兵没给新槽赋值 / 复用组件没刷新 sprite / `RunLoadout` 列表与槽索引错位。
- **验收**：连续两次抽到同一佣兵，头像都正确显示；换佣兵时头像跟着换。

### T2 结算「最佳 MVP」显示真名 ★
- **现象**：现在显示「重盾」（昵称），主人要求**必须真名「塔克」**。
- **根因**：`Mercenary.SetDisplayName:195` 优先 nickname，MVP 读 `merc.DisplayName`。
- **做法**：**不要**改全局 `SetDisplayName` 优先级（会影响所有战斗名签）。
  在结算取名字处加单一出口，例如 `GetAllyMvpDisplayName(UnitBase)`：优先花名册真名 → 回退 `DisplayName`。
- **验收**：结算页 MVP 显示「塔克」。

### T3 结算「总伤害」数值爆表（**数值 bug，不是换行**）★
- **现象**（主人原话）：「总伤害不可能那么高，这才引导关伤害就这么高的话，以后的那得多少个数啊」。
- **排查方向**：伤害累加链路（`UnitBase.TakeDamage` 相关 / `BattleManager` 统计 / `BattleSettlementUI` 数据源）：
  ① 是否**重复累加**（施加者与全局各加一次）；② DOT / 多段是否每次都计；
  ③ 是否把**溢出伤害 / 护盾吸收 / 治疗量**算成伤害；④ 是否统计的是「未钳制的原始伤害」。
- **先算清倍差与根因**，再定改法；口径类改动标「待主人拍板」。
- **验收**：引导关总伤害落回与怪物血量总和同量级。

### T4 抽奖槽位更随机（主人：「把随机值弄大点」）
- **做法**（二选一，推荐 ①）：
  ① **防连续同槽**：记录上一件抽到的槽位，下一次在候选里排除它（单槽时除外）；
  ② 提高 `wantWeapon` 权重波动、或对四防具槽做**近期去重**（最近 N 件内不重复）。
- **验收**：连抽 10 次，鞋不再连续出现；四槽分布肉眼可见均匀。

### T5 引导关第 4 波精英怪「没见到」
- 配表已有 `eliteCount=1` → 二选一确认后修：
  - 若**真没生成** → 查 `WavePlanner` 精英槽位分配（`eliteQuota` 取最后 N 个槽位）与波次推进是否提前结束。
  - 若**生成了但看不出** → 需要**精英视觉标识**（体型放大 / 描边 / 血条样式 / 名字前缀）。
    ⚠ 涉及美术表现，先报主人，**不要自己造资源**。
- **验收**：第 4 波能明确认出 1 只精英（或按主人指定方式）。

### T6 佣兵属性按「玩家装备平均值」折算 + 稀有度拉开 ★
- **主人原话**：「就算佣兵吃不到装备也要差不多一点，换算一下玩家大概的装备数值然后取个平均点的，
  稀有的佣兵的属性不能这么少，传奇的更是」。
- **做法**：在佣兵属性计算处加一项**装备折算加成**（等于"玩家该阶段装备的平均属性"），
  并**按稀有度递增**（普通 < 稀有 < 传奇，倍数要拉开）。
- ⚠ 系数是数值决策 → **先给建议值报主人拍板，再改配表**（改 csv 必须同步 `.bytes`）。
- **验收**：同等级下，塔克（Rare）血量接近玩家同期的合理比例；传说佣兵明显更高。

### T7 抽到技能后不显示图标（**赋值链路**，不是缺图）
- 图标资源齐全（§2.1）→ 查 `DraftCard` / 抽奖卡片 / 技能槽的 icon 赋值路径：
  卡片生成时 `icon` 是否被赋空、技能槽刷新时是否只在特定分支设图。
- **验收**：抽到技能卡片和进入技能槽后都能看到图标。
