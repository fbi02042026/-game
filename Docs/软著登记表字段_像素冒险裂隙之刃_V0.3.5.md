## 说明性字段

### 开发目的
开发一款竖屏 2D 像素风 Roguelike 冒险游戏客户端，为玩家提供「城镇养成—章节战斗—关卡选择—回城」的完整可玩闭环，用于移动端娱乐与产品验证。

### 面向领域 / 行业
文化娱乐；移动游戏；休闲 / 角色扮演（Roguelike）

### 软件的主要功能
1. 启动登录与本地 JSON 存档、离线收益。  
2. 城镇大厅：公会、角色、冒险、酒馆、冒险日志五入口。  
3. 主线选章开战（普通 / 困难 / 噩梦），消耗体力进入战斗。  
4. 横版自动战斗：英雄与佣兵协同、普攻与技能、暂停与撤离。  
5. 通关宝箱选装备、石墩关卡图与轮盘抽取下一关（普通 / 精英 / 恢复 / 首领四类）。  
6. 恢复关回血、战前遗产三选一、死亡 / 撤离遗产结算。  
7. 角色属性 / 天赋 / 技能 / 背包，装备 SPUM 实时换装。  
8. 酒馆佣兵三选一招募、成就里程、邮件、顶栏资源激励模拟。  
9. 新手引导（剧情对话 + 教学战斗 + 回城指引）、全局声音开关。

### 软件的技术特点
1. 组件化 C# 架构：Boot / Town / Battle 三场景分离，单例管理战斗、存档与对象池。  
2. 关卡抽取与演出解耦：`StageRoller` 加权抽取四类关卡，`NextStageRouletteUI` 与 `BattleStageMapUI` 负责展示与交互。  
3. 本地 JSON 存档：金币、体力、天赋、佣兵、遗产池、章节进度分模块读写。  
4. SPUM 像素换装：装备与城镇预览、战斗形象同步刷新。  
5. 佣兵池数据驱动：三选一招募，同形象可异名 / 等级 / 星级 / 技能。  
6. URP 2D 渲染；720×1280 竖屏 UI 适配；城镇页预加载降低切页卡顿。
