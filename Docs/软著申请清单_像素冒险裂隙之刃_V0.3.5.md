# 软著申请清单（功能 + 截图）

**软件全称：** 像素冒险：裂隙之刃  
**版本：** V0.3.5  
**说明：** 只列本版**保留功能**与**需要的截图**；正文你自行丰富。隐藏功能不要写进说明书。

---

## 一、申请里写哪些功能（保留）

### 主闭环
1. 启动健康游戏忠告 → 登录（协议勾选 → 开始游戏）  
2. 本地存档  
3. 城镇大厅（顶栏金币 / 体力）  
4. 底栏五入口：公会、角色、冒险、酒馆、冒险日志  
5. 选章开战（主线；普通 / 困难 / 噩梦）  
6. 横版自动战斗（普攻 + 技能）  
7. 通关宝箱选装备 → 传送门  
8. 石墩关卡图 + 轮盘选下一关  
9. 回城 / 撤离结算  

### 关卡类型（本版仅四类）
- 普通关卡  
- 精英关卡  
- 恢复关卡（回生命 50%）  
- 首领关卡  

### 养成与系统
- 角色：属性、天赋、技能、背包；装备后 SPUM 换装  
- 酒馆：佣兵三选一招募（可反复招）  
- 战前：遗产三选一（有遗产时）  
- 冒险日志：怪物（含 Boss）、佣兵、成就、世界、主线、支线；不设装备图鉴  
- 成就里程  
- 邮件领取  
- 顶栏金币+ / 体力+（激励模拟）  
- 离线收益弹窗  
- 新手引导（对话 + 教学战斗 + 撤离回城）  
- 全局声音开关（音乐 / 音效）  

### 不要写进说明书（隐藏 / 未开放）
商城、公告、排行、公告栏、武器库、执照厅、活动副本、扫荡、章节奖励；酒馆信任 / 任务 / 情报；商人 / 诅咒 / 锻造 / 附魔关；战斗中断续关；真实云存档 / 真实广告 SDK；符石等后期构筑。
