## 1. 现状与根因（已定位，2026-10-21）

- **根因**：物强/魔强（`AttrType.PhyPower / MagicPower`）在战斗侧**只有一处消费**——`Assets/Scripts/Combat/DamageFormula.cs` 的 `BuildSkillBase`（约 88~97 行）：`baseDamage + attack * atkMul * (1f + phy + mag)`，只放大**技能**伤害。
- **普攻链路不读魔强**：`UnitBase.Attack.cs:195` → `DamageFormula.BuildAttackRaw`（`DamageFormula.cs:62~82`，取 MagicAttack、判暴击，无魔强乘区）→ `FinalHit`（扣魔防）。
- **词条来源**：`SpecialWeapons.cs` 的 `TwilightTraitPool`（约 135~142 行，`MagicPower = 0.25` 加算）→ `CreateRandomTwilightTrait` → 装备 attrBonus → `Hero.RecalcAttr` → `AttrSystem` 汇总。汇总侧无需改。
- **连带口径**：`AttrSystem.cs:230` 智力派生 MagicPower（intel × 0.01）；面板显示已正确（`EquipUiText` 按比例属性 ×100，0.25 → +25%）。
- **攻略已预写**：`Docs/稀有暮火之杖_玩家攻略_2026-10-21.md` 第 4 条随机属性已按「普攻 +25% 加成」口径描述——代码落地后该表述即成立，攻略不用再改。

## 2. 目标

魔法伤害单位的**普攻**也享受 (1 + MagicPower) 乘区，与技能口径统一；物理普攻、技能伤害、固定火伤、怪物伤害均不变。

## 3. 任务清单

### T1 核心改动：普攻吃魔强（唯一必改项）

- **文件**：`Assets/Scripts/Combat/DamageFormula.cs`
- **位置**：`BuildAttackRaw` 内，`magicAttack` 分支结束（77 行 `}`）之后、`RollCrit`（78 行）之前。
- **做法**：仅对 `magicAttack == true` 的伤害乘 `(1f + attacker.GetAttr(AttrType.MagicPower))`（与 `BuildSkillBase` 的 mag 项同口径；未登记属性 `GetAttr` 返回 0，天然 no-op，无需 HasAttr 守卫——照抄 94~95 行现有写法即可）。
- **验收**：
  1. 同一法师，MagicPower = 0 与 = 0.25 两种状态打同一目标，普攻伤害比 ≈ 1.25（锁暴击或多次采样取均值，排除暴击扰动）；
  2. 物理职业（剑盾/狂战/游侠等）普攻伤害与改前完全一致（回归）；
  3. 技能伤害与改前一致（`BuildSkillBase` 一行不动）；
  4. 暮火杖每击 +8 固定火伤数值不变（该伤害不走 `BuildAttackRaw`，不应被波及）；
  5. 怪物普攻伤害不变（怪物未登记 MagicPower，乘区恒为 1）。
- **依赖**：无（`DamageFormula` 是纯静态公式类；属性汇总侧 `AttrSystem` 已正确汇总魔强，含装备词条 + 智力派生）。
- **风险**：法系普攻整体上浮——智力派生魔强（1 智力 = +0.01）会一起进乘区，高智力法师普攻增幅可能很大；暮火杖 + 法师开局第一章可能明显变强。**需主人上机实测第一章~中期曲线**，若过强再议压值（见待确认 ①）。
