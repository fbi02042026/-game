## 1. 软件概述

《像素冒险小镇》是一款竖屏像素风 Roguelike 冒险游戏客户端。玩家在城镇（冒险者大厅）进行养成与准备，进入章节裂缝进行横版自动战斗；通关后通过石墩关卡图与随机轮盘决定下一关类型，形成「引导 → 战斗 → 结算 → 城镇养成 → 再开战」的可玩闭环。

本登记版本为 **V0.3.2 软著演示版**：保证上述主闭环可演示；商人关、诅咒关、中断战斗续关、微信正式云存档与真实激励广告 SDK **不在本版本功能范围**。

**运行环境（申请可填）：**

| 项 | 内容 |
|----|------|
| 硬件 | 支持 Android 的智能手机 / 模拟器；亦可在 PC 上以 Unity/团结引擎播放器运行 |
| 操作系统 | Android 8.0 及以上（目标平台）；开发与调试支持 Windows 10/11 |
| 开发工具 | 团结引擎 1.10.0（基于 Unity 2022.3.62t12） |
| 编程语言 | C# |
| 分辨率基准 | 720×1280 竖屏 |

## 2. 主要功能（与说明书目录对应）

### 2.1 启动与存档

1. Boot 场景进入进大厅流程。  
2. 本地 JSON 存档读写，含备份；预留云存档上下行接口（本版本为本地镜像模拟）。  
3. 体力、金币、材料、成就进度等持久化。

### 2.2 城镇（冒险者大厅）

底部固定导航五入口：**公会 / 角色 / 冒险 / 酒馆 / 冒险日志**。

| 模块 | 功能说明 |
|------|----------|
| 公会 | 大厅主界面；顶栏金币/体力；加号走激励视频接口（本版本本地模拟发放）；邮件；执照/遗产摘要；成就里程；武器库浏览遗产 |
| 角色 | 角色属性、装备与背包相关界面 |
| 冒险 | 选择章节与难度，消耗体力进入战斗（章节数据以现有 8 章为准） |
| 酒馆 | 佣兵名册与出战槽；可招募弓手 |
| 冒险日志 | 探索统计、怪物/Boss/装备/佣兵/剧情/成就/世界设定查阅 |

未完成的商城、公告、排行榜、扫荡、章节奖励、信任/任务/情报等入口在客户端中隐藏。

### 2.3 战斗与关卡

1. 横版自动战斗：英雄与佣兵协同，技能与普攻（含弓箭/法球飞行命中）。  
2. 波次刷怪、精英/Boss 按章节系数缩放。  
3. 通关宝箱三选一装备、传送门（chuansongmen）结算；未选装备折合金币并提示。  
4. **石墩关卡图 + 滚动随机关卡：** 通关后进入 10 石墩地图；轮盘展示关卡类型。本版本实际抽取类型：普通、精英、恢复、锻造或附魔、首领。  
5. 局内节点：恢复（回血并发材料）、锻造（材料+升星）、附魔（随机词条）。  
6. 死亡本局金币清零、撤离保留金币；遗产一件带回城镇。  
7. 本版本不支持中断战斗后续关。

### 2.4 战前与养成

1. 非引导局开战前遗产三选一（可走激励接口刷新一次，本版本为模拟）；选中遗产从池中消耗。  
2. 天赋、资源上限与邮件溢出。  
3. 成就进度与里程碑领取。

### 2.5 平台与性能

1. 设计分辨率统一 720×1280。  
2. 激励视频、云存档桥接层：接口预留，本版本为本地模拟/镜像。  
3. 对象池与战斗特效入池等性能策略。

## 3. 操作说明（用户手册）

### 3.1 进入游戏

安装并启动客户端 → 完成启动流程进入城镇公会大厅。（附图 01、02）

### 3.2 首次引导

按屏幕引导完成对话与教学战斗，撤离或结束后回到城镇。

### 3.3 开始冒险

1. 点击底栏「冒险」。  
2. 选择已解锁章节与难度（普通/困难/噩梦）。  
3. 点击开始，消耗体力进入战斗。  
4. 若有遗产，开战前选择一件装备（选后从遗产池移除）。（附图 04）

### 3.4 战斗中

- 角色自动前进与攻击；可点击技能/佣兵技能。  
- 可暂停；主动撤离走遗产流程。  
- 清怪后打开宝箱选装备，走近传送门结算。  
- 未选中的奖励装备折合金币，界面有提示。（附图 05）

### 3.5 选下一关（石墩与轮盘）

1. 出现章节石墩图。  
2. 观看解锁与关卡类型轮盘滚动。  
3. 类型旗落到当前石墩后，点击该石墩进入下一关。  
4. 若进入恢复/锻造/附魔节点，按弹窗提示领取效果后继续。  
5. 本章首领通关后解锁后续章节并回城。（附图 06）

### 3.6 城镇养成与日志

- 「角色」「酒馆」进行装备与佣兵管理；酒馆可打开名册并招募弓手。（附图 07）  
- 顶栏「+」领取体力/金币：激励视频接口，本版本本地模拟发放，有每日次数。（附图 03）  
- 「冒险日志」查看探索与图鉴；可打开成就里程领取。（附图 08）  
- 「武器库」可浏览遗产池中的装备列表。  
- 离线一段时间后返回城镇，弹出离线收益说明（金币已到账，点确定关闭）。

## 4. 技术特点（鉴别材料可用表述）

1. 基于团结引擎的组件化 C# 架构：场景 Boot / Town / Battle，单例系统管理战斗、存档、章节、对象池。  
2. 关卡类型运行时加权抽取与 UI 轮盘演出解耦（StageRoller + NextStageRouletteUI + BattleStageMapUI）。  
3. 存档采用 JsonUtility 可序列化 List 与运行时 Dictionary/HashSet 双向同步。  
4. 竖屏 UI 统一 CanvasScaler 基准分辨率。  
5. 伤害公式集中结算，武器距离/攻速表与章节 TTK 系数可配置。  
6. 顶栏资源统一经 ResourceWallet 发放；战斗金币按差额写回，避免重复加金。
