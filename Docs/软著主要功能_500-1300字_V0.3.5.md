## 正文（约 980 字）

本软件为一款面向 Android 平台的竖屏二维像素风 Roguelike 冒险游戏客户端，软件名称为「像素冒险：裂隙之刃」。软件以「城镇养成—章节冒险—关卡战斗—回城结算」为核心闭环，向玩家提供完整的单机可玩体验。

**一、启动登录与本地存档。** 软件启动后进入登录界面，玩家阅读并勾选用户协议与隐私政策后，点击「开始游戏」进入城镇。软件采用本地 JSON 格式持久化保存玩家数据，涵盖金币、体力、章节进度、角色装备、天赋配置、佣兵队伍、遗产池及成就记录等；支持清除存档以重新体验新手流程。再次登录时可弹出离线收益界面，自动结算离线期间的部分资源收益。

**二、城镇大厅与功能导航。** 进入城镇后，界面顶部统一展示金币、体力等资源条，底部提供公会、角色、冒险、酒馆、冒险日志五个入口，玩家可在各模块间自由切换。顶栏资源旁设有补充领取入口，用于模拟激励获取流程；邮件模块支持查看与领取系统奖励。全局可设置音乐与音效开关。

**三、主线选章与开战。** 玩家在「冒险」模块选择主线章节及难度（普通、困难、噩梦），确认消耗体力后进入战斗。若玩家拥有可用遗产，开战前弹出「遗产三选一」界面，从候选增益中选择一项带入本局；若无遗产则直接进入战斗。

**四、横版自动战斗。** 战斗采用横版卷轴视角，英雄与已招募佣兵自动寻敌并释放普攻与技能。玩家可在战前配置技能栏，战斗中手动触发已点亮的主动技能。界面支持暂停、继续及主动撤离；局内可拾取地面装备，部分关卡存在诱饵装备等风险事件，需玩家判断取舍。

**五、通关结算与关卡推进。** 关卡通关后弹出宝箱界面，玩家从多件候选装备中选择一件带走，确认后经传送门进入下一环节。软件提供石墩关卡地图与轮盘抽取两种关卡选择形式，按规则随机确定下一关类型，包括：普通关卡（常规敌人，稳定掉落）、精英关卡（更强敌人，装备品质更高）、恢复关卡（回复生命 50%）、首领关卡（章节首领，必掉高品质装备）。玩家确认后继续挑战，直至通关章节、主动撤离或战败回城，并完成相应结算。

**六、角色养成与换装。** 在「角色」模块，玩家可查看主角属性、天赋树、技能配置与背包物品；更换装备后，角色立绘与 SPUM 像素形象实时刷新，城镇预览与战斗形象保持一致；旧装备可作为强化材料消耗。

**七、酒馆佣兵招募。** 在「酒馆」模块，软件从佣兵池中随机展示三名候选佣兵，玩家三选一招募加入队伍；同一形象可呈现不同名称、等级、星级与技能组合，支持反复招募以扩充阵容。

**八、日志、成就与引导。** 「冒险日志」提供图鉴与探索统计等查阅功能；成就里程系统记录玩家达成的各类里程碑。首次游戏时，软件通过剧情对话、教学战斗与分步软提示，引导玩家完成签署委托、进入冒险、熟悉自动战斗与拾装、体验撤离回城等关键操作，帮助快速理解核心玩法。

## 精简版（约 520 字，字数紧张时用）

本软件为竖屏二维像素风 Roguelike 冒险游戏客户端「像素冒险：裂隙之刃」，以城镇养成、章节冒险、关卡战斗、回城结算构成完整单机闭环。

软件启动后需勾选用户协议方可进入游戏，采用本地 JSON 存档保存金币、体力、章节进度、装备、天赋、佣兵、遗产及成就等数据，支持清除存档与离线收益结算。城镇界面顶栏展示资源，底栏提供公会、角色、冒险、酒馆、冒险日志五入口，并含邮件领取与全局声音开关。

玩家在冒险页选择主线章节及普通/困难/噩梦难度，消耗体力开战；有遗产时可战前三选一增益。战斗为横版自动作战，英雄与佣兵协同普攻与技能，支持暂停、撤离及地面拾装。通关后从宝箱选装备，经石墩地图或轮盘抽取下一关，类型含普通、精英、恢复（回血 50%）、首领四类，直至通关、撤离或战败回城。

角色页可管理属性、天赋、技能与背包，SPUM 换装同步城镇与战斗形象。酒馆提供佣兵三选一招募。冒险日志、成就里程记录探索与里程碑；新手引导以剧情、教学战斗与提示完成入门教学。
