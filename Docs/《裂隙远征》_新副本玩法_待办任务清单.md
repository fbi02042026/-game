## 一、命名与定位

**玩法名：裂隙远征**（4 字）
- 「远征」= 一次打多层、有终点的长周目，和「无限」正好对照，玩家一眼能分。
- 与项目名「像素冒险：裂隙之刃」同源，但和「无限裂隙」是两个玩法、两套进度、两套存档。
- 备选（主人一句话可换）：`层渊试炼`（强调层数）、`深潜副本`（更直白）。

**第一个副本：锈铁回廊**（6 层）

**定位**（主人原话）：「有的玩家喜欢打长的有成就感的可以打这个」= 长周目 / 成就感 / 刷装备词条，**不要求人人打**，与短平快主线、与无限裂隙并行存在。

**边界（最高优先）**
- ✅ 新增：`BattleModeId` 成员、新 `BattleMode` 子类、注册表条目、独立入口、新副本定义表、新存档字段、新结算链、新装备模板。
- ❌ **禁止改动**：`EndlessBattleMode` / `EndlessRiftRules` / `EndlessRiftCheckpoint` / `SettleEndlessStageClear` / `AdventureUI.EndlessReset.cs` / `GameConfig.Waves.cs` 的裂隙常量 / `SaveData.endlessRift*` 字段 / 无限页签与重置徽章。
- ❌ 禁止复用 `PendingEndlessRift`、`endlessRiftTriesToday`、`endlessRiftClearedStage` 等原裂隙标记与存档字段（会串档）。

|---|---|---|---|---|---|---|

### 15.3 缺失补全（本轮梳理发现，此前各节未覆盖）

1. **难度档 UI**（=T24，见 15.1-2）：副本详情面板难度区只开放普通；战斗 HUD 难度名走 GameConfig.GetDifficultyName 现成出口。
2. **入口图标加载方式**：铁锈回廊入口图**按路径 Resources.Load**（主人 2026-10-23 口径「运行时要用的图一律路径加载、代码不得依赖 prefab sprite guid 引用」）；若 modeButtonSpriteIcons 预制体绑定不可用，运行时路径注入第 6 槽。
3. **战斗背景挂接**：1~5 层 = 幽晶遗迹.jpg、第 6 层 = 幽晶遗迹boss.jpg；副本分支按层切背景（同样路径加载），主线 / 四本 / 无限裂隙背景链一行不动。
4. **清档复位**：expeditionWornEntries 与副本周键 / 次数字段纳入【NewGameReset.ApplyAll()】复位链（清档≠重启进程硬规则）；运行时 Dictionary 缓存一并复位。
5. **抽奖面板常显**：进副本后抽奖面板一律不收（对齐既有口径「所有玩法点开始战斗后抽奖面板不收，裂隙/四本就地切 LiveMode 常显」）；通关 / 剧情 / 结算 Hide 不变。
6. **宝箱品质展示**：装备稀有=蓝框、传奇=金框，**只走 EquipRarityFrame.SpriteOf 唯一出口**；宝箱 / 替换窗 / 详情一处不落就 LogError（不兜底）。
7. **数值区间真源**：§13.1 的副本品质档区间（RARE / LEGEND 的主属性 LO~HI + 词条条数区间）挂 GameConfig 新常量（副本专用），**不复用 equip_rarity_rules.csv**（那是裂隙战斗内生成链的数值，避免串味）。
