## 一、现状与根因

- 现象：玩家天赋点满后 80 物防 / 75 魔防（对账：10.5 职业基底 + 65 天赋 + ~5 体质派生；魔防无体质派生、MAGIC_DEF 词条仅法师/牧师可滚 → 装备防御贡献 ≈ 0），仍感"掉血多"。
- 伤害公式本身没坏：`FinalHit` 减伤率 = def/(def+100) 封顶 75%，80 防 = 减 44.4%，链路逐段验证无断点。
- 🔴 真 bug：装备「减伤」词条（DMG_RED，头盔/胸甲池，1%~15%）被映射成 **物防 ×(1+值)**：
  - `RiftEquipTables.cs:214` `case "DMG_RED": type = AttrType.Defense; isPercent = true;`
  - 生成链：`RiftEquipGenerator.cs:443` ÷100 → `:500` 存 `{Defense, isPercent=true, 0.08}` → `AttrSystem.cs:263` 乘算 `物防 × 1.08`
  - 后果① 名义 8% → 80 防时实际只减 3.4%；② 不加魔防 → 打法系怪零效果；③ UI 显示「防御 +8%」，语义偏离配表备注「减伤」。
  - 同家族前科：2026-10-19 修的 POISON（0×(1+v)=0）/ ELE_DMG（÷100 双瞎）。

## 二、旧档迁移（T3）—— 结论：不做，无迁移对象

- 局内装备**不存档**：`GridBackpackSystem.ClearRunEquipment()`（回城清零，裂缝装备不带出），每局重新生成 → 代码修好后新掉落自动是新口径。
- 存档唯一装备数据 `SaveData.legacyEquipPool` 实测 **0 条**（`player.dat` 扫描），且 `TownBackpackGrid.ToEquipInstance` 注明"仅 UI 用"，从不进战斗 Recalc。
- 模板资产（EquipTemplate 的 globalBonus/attrBonus）不走 CSV 映射，不受本次改动影响。
- ⇒ 无迁移脚本；若日后 legacyEquipPool 有存量再议。

## 三、改造点（4 处，最小增量）

### T1 新属性 `AttrType.DamageReduce`
- 文件：`Assets/Scripts/Core/AttrType.cs`（枚举**末尾追加**，防序列化错位； Poison 之后）
- 语义：装备「减伤」词条真源 = **最终减伤**（0.08 = 减伤 8%），不登记基础值（恒 0），装备段加算叠加。

### T2 最终减伤消费 + 总减伤封顶
- 文件：`Assets/Scripts/Combat/DamageFormula.cs`
- 新增常量 `MaxTotalReductionRatio = 0.85f`（2026-10-21 主人拍板封顶；物/魔防减伤与装备减伤**乘叠后**封顶，至少 15% 伤害必进；调平衡只改这一个数）
- `FinalHit` 尾部（现 149-151 行）改为：
  1. `defRed = Mathf.Min(MaxReductionRatio, defSafe/(defSafe+DefenseK))`（原口径不动）
  2. `gearRed = Mathf.Clamp01(defender.GetAttr(AttrType.DamageReduce))`
  3. `totalRed = Mathf.Min(MaxTotalReductionRatio, 1f-(1f-defRed)*(1f-gearRed))`
  4. `return Mathf.Max(MinDamage, dmg*(1f-totalRed))`
- 物魔两侧都吃（减伤不区分伤害类型）；`ignoreDefense=true` 的路（引导/反伤/DoT）不过 FinalHit，天然不减。

### T3 映射改线
- 文件：`Assets/Scripts/Config/RiftEquipTables.cs:214`
- 改为 `case "DMG_RED": type = AttrType.DamageReduce; isPercent = false; return true;` + 2026-10-21 拍板注释
- 生成链其余不动：`RollAttrValue` ÷100（IsRateAttr 已含 DMG_RED）、`ApplyDropBonus` 跳过比率词条，均沿用。

### T4 UI 三件套
- 文件：`Assets/Scripts/UI/EquipUiText.cs`
  1. `Attr()` 加 `case AttrType.DamageReduce: return "减伤";`
  2. `IsRateAttr()` 加 `case AttrType.DamageReduce: return true;`（Value 走 ×100 显示「8%」）
  3. `Value()` 不改（isPercent=false + IsRateAttr 自动走百分比分支）
