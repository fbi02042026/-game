## 三、验收（编辑器里逐条看）

1. 普通局点佣兵头像 → 弹窗右下有「离开」；点它：角色往左走出画面后消失，头像栏剩的人前移，第二格变「三选一解锁」。
2. 阵亡佣兵点头像 → 「离开」→ 头像直接消失（无动画、无报错）。
3. 引导局 / 羁绊本 / 竞技场点头像：**没有**「离开」按钮。
4. 波间三选一在 2/2 满员时仍可能出佣兵卡 → 选中后弹「换下谁？」三栏窗。
5. 三栏窗：左栏新佣兵、中/右栏现有两位，名字随稀有度上色，头像框与战斗头像栏同款。
6. 点中栏「替换」→ 中栏那位往左走出，新佣兵从屏外走入同一个坑，头像栏立刻换人。
7. 点「不要了」/ 暗带 / 等 15 秒 → 队伍不变，波次照常推进（不许卡住）。
8. 满员且没有「其它可招募佣兵」时，三选一**不出现**佣兵方向（不掷空）。

## 四、风险 / 待调

- **三栏是运行时按常量摆的**（`MercReplaceConfirmUI` 顶部 `ColScale / ColX / ColY / BtnY / BtnScale`），不是预制体 authored。位置/大小不合适改常量，别改预制体。
- 栏内文字是装备栏那套字号×0.72，竖屏 720 宽下偏小；若看不清，优先调 `ColScale`（调大就要减 `ColX`）。
- `Verdict` 那行被占用来显示倒计时；它和按钮行的间距没实测过，可能挤。
- 旧人走出的 0.85 秒内场上同时存在 3 个佣兵单位（账本只有 2 位），血条/蓝条按 index 取值可能闪一下，属正常过渡。
