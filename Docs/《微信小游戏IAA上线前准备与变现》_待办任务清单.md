- 小程序备案：情况二约 10–30 工作日，最长关键路径。
- IAA 资质审核：情况二，1–3 自然日。

  - 广告分成：普通 IAA 小游戏 50%；创意小游戏单日流水 200 万内 70%、超出部分 50%。
  - 广告金：买量/视频号来源注册且累计活跃>3 分钟用户，二选一：30 天流水 40% / 180 天流水 35%；默认 30 天 40%，一年最多切 6 次，次日生效。自然量不配广告金。
  - 结算：现金半月结；广告金 T+2，有效期 365 天；入口 MP → 流量主 → 财务管理。
  - 畅玩权益：官方放在「广告变现」下，平台托管，收益走流量主数据统计，不要求开发者开虚拟支付；是否对本游戏可见以 MP 后台入口为准。
  - 首发新游激励金/成长激励金/PC 内购返 10% 均属 IAP 口径，纯 IAA 不适用。

## 二、目标

1. 上线前完成 IAA 情况二全部合规闭环（资质、备案、适龄、健康忠告、防沉迷核验）。
2. 上线前备齐可提前做的流量/变现预热物料，上线当天即可生效。
3. 流量主开通后按最小增量接广告：填 adUnitId → 真机验收 → 主人拍板开广告档。
4. 全程不碰虚拟支付/内购/自建收银，守住无版号 IAA 红线。

## 三、任务清单

### T0【最高优先·主人操作】小程序备案（情况二）

- 做法：MP → 设置 → 小程序备案 → 选情况二（IAA）→ 按引导提交。
- 验收：拿到备案号，可提交版本发布。
- 依赖：无，最先启动。
- 风险：10–30 工作日，晚启动会卡上线日。

### T1【合规·主人操作】IAA 资质审核（情况二）

- 做法：MP → 设置 → 游戏设置 → 资质管理 → 前往管理 → 选「情况二：当前及未来均不需要开通虚拟支付」→ 三级类目与内容一致 → 不申请支付资质 → 上传材料。
- 注意：游戏名称含英文/「软件」字样、涉及品牌或公众人物合作时需软著或授权材料；材料错位上传会被驳回。
- 验收：资质审核通过；无支付资质。
- 依赖：T0 并行。
- 风险：主体签署名/盖章/日期不一致是常见驳回原因。

### T2【合规·主人操作】适龄提示设置 + 健康忠告核验

- 做法：MP → 设置 → 基础设置 → 基本信息 → 适龄提示，按内容评 8+/12+/16+ 并提交审核。启动页图标由平台统一加。
- 项目侧：`HealthNoticeUI.cs` 已有健康忠告，保持不动。
- 验收：MP 适龄审核通过；真机启动页同时出现健康忠告与适龄标记，不遮挡内容。
- 依赖：无。
- 风险：未完成设置平台会代为标记，结果可能不符实际。

### T3【风险核验·必须先确认再动代码】防沉迷/实名

- 现状：仅检索到 `Assets/Scripts/UI/HealthNoticeUI.cs` 的健康忠告；**未见实名认证/防沉迷接入代码**。
- 做法：向微信侧或已上线同主体游戏确认：平台是否代管实名与未成年人时长限制；若需自接，另立任务并按官方规范施工。
- 验收：有明确结论；需要自接时审核前已完成接入并真机跑通。
- 依赖：无。**阻塞上线。**
- 风险：漏接会被版本审核驳回。按项目纪律：只报位置不私自改。

### T4【变现准备·主人操作】广告主账户 + 新游启动金

- 做法：注册/开通微信广告主账户（个人/企业均可）。盯 MP/微信广告通知里的「新游启动金」入口：上线 30 天内可领约 1000 元投放额度；创意游戏认证后另有约 3000 元。
- 验收：广告主账户可用；额度到账并按期投放核销。
- 依赖：无。
- 风险：额度非现金、有使用期限；错过 30 天窗口不补。

### T5【流量主门槛·主人操作】游戏圈 5 帖 + UV 500

- 做法：建内置游戏圈；备好 5 篇官方帖素材，上线后发布并引导用户进圈产生消费/转评赞等有效活跃。同步攒自然 UV 到 500。
- 验收：满足流量主三条件之一，次日资格刷新后可开通。
- 依赖：T0/T1 完成后游戏可发布。
- 风险：UV 门槛刷粉会被驳回且留违规记录。

### T6【流量预热·主人操作】视频号内容 / CPS 挂载

- 做法：注册/养视频号，先拍 3–5 条素材并谈达人；上线后挂载小游戏组件（视频号加热、短视频 CPS、直播 CPS）。
- 验收：有可发布内容与达人合作；上线后能挂载组件并产生注册用户。
- 依赖：游戏上线。
- 风险：需累计活跃>3 分钟才有广告金激励；不含视频号广告。

### T7【流量预热·主人操作】邀请有礼 / 社交红包

- 做法：
  1. MP → 游戏能力地图 → 社交能力 → 邀请玩法组件，配邀请礼包，活动开始日对齐上线日（7–365 天）。
  2. 社交红包：先确认主体能否开通现金发放能力，再配红包节点。
- 验收：活动配置完成、礼包/红包可在游戏内领取。
- 依赖：主体类型确认（见待确认 ②）。
- 风险：现金发放能力个人主体可能受限；以 MP 后台为准。

### T8【变现·主人操作】创意小游戏认证材料

- 做法：整理玩法/美术/剧情/音乐创新说明与素材，上线后从官方入口申请。
- 收益：通过后现金分成 50% → 70%（日流水 200 万内）。
- 验收：认证标识出现在游戏名称下方，后台分成比例生效。
- 依赖：游戏上线。
- 风险：认证不通过不影响普通分成；优选计划不配赠广告金，别当必拿项。

### T9【流量变现·主人操作】CPS 推荐组件

- 做法：注册微信服务商账号 + 结算信息；上线后在游戏内推荐其他小游戏赚分成。
- 验收：组件可投放，点击染色与分成数据可见。
- 依赖：主体资质与结算信息审核。
- 风险：广告收益需先开票再提现，个人主体需确认能否开票。

### T10【客户端·最小增量】广告位 ID 与真机验收（暂不施工）

- 触发条件：流量主开通 + 主人拍板开广告档。**未触发前禁止翻 `ADS_ENABLED`。**
- 做法：
  1. 流量主 → 广告位管理 → 建激励视频广告位，复制 adUnitId。
  2. 填入 `WeChatMiniGameConfig.cs:19` 的 `RewardedAdUnitId`。
  3. 微信真机/开发者工具验证：能拉起广告、中途关闭不发奖、看完 `isEnded=true` 发奖、连点不双发奖。
  4. 验收通过后才把 `GameConfig.Progression.cs:140` 的 `ADS_ENABLED` 翻 true。
- 验收：广告漏斗（请求/展示/获奖/失败）数据可查；无双发奖、无误发奖。
- 依赖：T5 完成。
- 风险：提前开档会导致玩家看到「暂未开放」或白给奖励。

### T11【客户端/QA】体验版全流程与包体

- 做法：真机跑 健康忠告 → 登录 → 新手 → 关卡 → 复活/结算 → 退出；检查主包 ≤4MB（超出按既有分包方案拆）。
- 验收：无崩溃、无卡死、无内购/充值入口；包体达标。
- 依赖：T0–T3 完成。
- 风险：无。

## 五、施工红线

- 无版号 IAA：不开虚拟支付、不做内购/充值、不自建免广告卡收银。畅玩权益只走平台托管或官方 `wx.createAdSkipCard()`。
- `GameConfig.ADS_ENABLED=false` 未经主人拍板不得翻 true；`RewardedAdUnitId` 为空时不得拉广告。
- 出错只报位置（路径 + 行号 + 原文 + 判断），不私自改；禁止删掉重建；不动美术排版。
- 分享得奖/分享埋点已核实违规（官方 2.5.1/2.5.3），不再接；分享保持被动转发无奖励。
- 提交只推 `origin`（微信小游戏端仓库）；`ProjectSettings/ProjectSettings.asset` 的 `activeSubplatform` 行不提交；不提交 `minigame/`、`TextToolDatas/`、`LocalPackages/`、SDK 包与微信本地配置。
- 新拖图必须连同 `.meta` 一起提交；不跑 `Tools/CheckDanglingRefs.py`、不跑 `Tools/ScanGuid56.py`。
- 提交前跑 `Tools/EnsureMeta.py` 与 `Tools/Guardrails.py`，有 ERROR 先修。
