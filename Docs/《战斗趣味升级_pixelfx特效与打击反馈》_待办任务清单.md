## 二、受击后退（已拍板，规则 14:2x 细化）

**规则（主人拍板）**：
- **普通怪受击 → 退**（小退 0.2~0.4 单位）；
- **精英 / Boss 受击 → 不退**（免击退，体型重量感；Boss 二阶/狂暴同样不退）；
- **精英 / Boss 的攻击命中玩家或佣兵 → 玩家/佣兵被击退**（退幅明显大于普通受击，突出威胁感）。

- 现状：受击反馈=白闪（hit flash）+ 飘字（UnitBase.TakeDamage 取整）+ 震屏（仅预警释放时一次）。
- 改造点：
  1. 受击位移：按上表规则分层——普通怪被击退小位移，精英/Boss 完全免疫；玩家/佣兵吃精英/Boss 命中时被击退更大位移。位移用 Tween/协程短促完成，**不打断攻击动画锁**（攻击间隔下限 0.18s 的锁别被位移重置）。
  2. 边界钳制：退到场地边缘/墙不再位移（clamp），两个单位重叠时做轻量分离，别挤进彼此身体。
  3. 与索敌兼容：退开后近战 AI 重新索敌（现有"索敌换目标"机制已支持，确认退 0.4 单位不会造成抖动换靶——必要时加 0.2s 换靶冷却）。
  4. ⚠️ 待确认：普通怪打玩家/佣兵要不要也轻退？（建议轻退，全量反馈统一；若主人只要精英/Boss 打人才退也行，规则就两条）
- 验收：普通怪受击有可感知的小顿挫+位移；精英/Boss 受击纹丝不动（重量感）；精英/Boss 重击能把玩家/佣兵打出预警圈；无穿墙、无抖动换靶。
