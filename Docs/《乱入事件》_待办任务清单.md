## 二、目标行为（定稿规格）

- **敌对乱入**：指定章节/关卡的某一波，开打前播一小段对方放话 + 我方吐槽的剧情；剧情结束后这一波里有 **3 只怪被换成机器人冒险者**（本波怪数不变、波数不变）。打赢后掉一点额外奖励（徽记之类，走现有奖励链）。
- **友军救场**：Boss 波中，我方血量降至 **40%** 且本关未触发过 → 播一段剧情（接本章主线或所在支线岛的口吻）→ 剧情演完临时生成 **3 人小队**入场帮忙 → 本波结束撤场。**不算已拥有、不进抽卡池、不写永久解锁**。
- **入场救援（新）**：进入指定 Boss 关，**首波刷出前**先播一段剧情——玩家撞见那支 3 人小队正被围攻（剩一口血）；随后这 3 人作为**友军**已在场开打，血量按配置的低比例起步（如 25%），玩家清怪 / 打 Boss 拉住他们。友军全部阵亡 → 播"撤退 / 失手"台词（**关卡照常继续**）；至少一人活到本波结束 → 播"谢了，是她让我们看着你的"暗线台词。
- **频次与复用**：主线全流程只安排 **3–5 次救场类事件**（含前期第一章最终 Boss 10-5 那次），后期不铺满；救场队伍可以是**同一支**，靠"艾丽娅拜托他们暗中保护玩家"这条暗线串起来。入场救援占其中 1–2 次，不额外叠加频次。
- 引导局、羁绊本、竞技场：**零触发**（脚本固定，不能被乱入打断）。
- 剧情不主动弹：全部挂在波次节点 / 受伤节点，随战斗进度触发。
