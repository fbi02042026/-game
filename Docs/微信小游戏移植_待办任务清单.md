## 官方文档对照结论（2026-11-02 对照 developers.weixin.qq.com/minigame 官方文档）

**与方案一致（已确认）**：
- 分包限制：主包 ≤4MB、整包（主包+分包）≤30MB、单普通分包不限、单独立分包 ≤4MB —— 方案口径正确。
- 视频跳过（P3-A）正确：小游戏原生视频 API 是 `wx.createVideo` / `VideoDecoder`，Unity VideoPlayer 不可用。**二期替代**可用 `wx.createVideo`（支持 `underGameView` 画布下渲染 + `onEnded` 回调），不必改图片序列方案。
- 本地存档可行：wx storage 上限 **10MB/用户**（KV、用户维度隔离），只有代码包被清理时缓存才清 —— 存档 JSON 远小于 10MB；换设备/清微信数据会丢档（方案已接受无云备份）。

**方案需修正（3 个新结论）**：
1. 🔴 **小程序备案（ICP）是强制的**：接入指南明说「小游戏发布前必须完成版本审核**和备案**」——原方案"无后端无域名就不用备案"的假设**不成立**。IAA（纯广告）全流程审核时效 **13~37 个工作日**，流程＝注册→名称/类目→适龄提示→资质审核（软著）→版本审核（可与备案并行提交）→发布。**软著"先选无"争取早上线的口径不变，但备案要提上日程。**
2. 🟡 **流量主开通有 3 条路径**，不必死等 UV：① 累计独立访客 **UV>500**（官方条件一原文是"大于500"，且资格**次日刷新**）；② 开通内置**游戏圈**并产生活跃 + 发布官方帖 5 篇；③ 同主体名下其他小程序已开流量主且持续变现。路径②可作为攒 UV 期间的替代方案（需做游戏圈运营）。
3. 🟡 **激励视频单例坑（已彻底解决 2026-11-02）**：`wx.createRewardedVideoAd` 在小游戏端是**全局单例**（官方 API 文档明说），重复 create + 每次挂 onClose 会监听器堆积 → 一次关闭多次回调 → **双发奖**。现走官方 SDK `WX.CreateRewardedVideoAd(multiton=false)`：实例只建一次并缓存、onClose 只挂一次、`_pending` 指针指向本次回调；`res` 为 null 或 isEnded=false 一律不发奖；上游另有 RewardedAdBridge busy 守卫 + WeChatAd._pending 双保险。

**接入时要避免的问题（官方硬约束）**：
- 网络白名单：`downloadFile` 合法域名必须 **HTTPS + ICP 备案**；配了端口就只能请求该端口；DNS 预解析域名最多 **5 个**（CDN 域名可配上加速首屏）。
- 并发上限：request/downloadFile **10 个**；进后台 **5s** 内网络请求未完成会被 `fail interrupted`，回前台前不可再调（CDN 下载要考虑切后台恢复）。
- 启动性能红线：**首屏渲染资源必须放首包内**，官方明确反对首屏资源从 CDN 拉（弱网卡黑屏闪烁）；CDN 只放非首屏资源 + 分批下载。首屏目标 **4s 内**（官方数据：可救回约 30% 首开流失）。数据看「小游戏数据助手-性能分析」。
- 团结引擎小游戏构建应启用**引擎插件**能力（玩家装过同引擎游戏可复用/增量下载，加快首启）。
- `api.weixin.qq.com` 不能配为服务器域名（本方案无后端，正好无关）。

1. **切构建目标**：Build Settings → WeChat MiniGame（团结原生目标）；AppID 可先填测试号/占位。
2. **最小场景出包**：新建空场景（或只含 Boot）作为唯一构建场景出一次包——验证 URP 兼容性、ASTC 支持、Console 零红字。
3. **看产物结构（核心）**：
   - 主包体积多少？wasm+引擎本身占多少（决定留给登录 UI 的余量）？
   - data 文件是否自动拆分？团结构建面板有没有「数据文件放远程/Resource Server」选项？分包怎么配（场景分包还是资源分包）？
   - 记下产物目录树和各文件体积（截图或文本存 `Logs/P0_build_产物分析.txt`）。
4. **真机预览**：微信开发者工具打开产物 → 真机预览空场景能否跑通（渲染/触摸/音频三件套）。
5. **出结论**：主包预算表（引擎 X MB + 登录场景资源 ≤4MB 还剩多少）→ 反推贴图优化目标；若 data 拆不动 → P3-B 直接走 CDN 方案。
6. **回归红线**：测完把 Build Settings 切回原目标，避免污染安卓构建配置。
