   - `allowMercWhenFull` 默认值全部改为 `true`（`BuildCards` / `BuildWeightedPool` / `HasMercContent` / `SlotMachineSystem.AvailableCategories`）→ 老虎机付费抽、波间三选一、免费三选一、通关奖励口径一致。

## 四、施工红线

- **战斗内**读等级一律走 `MercLevelSystem.LevelOf`；`RunMercEntry.level` 只是本局缓存。
- **战斗外**（酒馆招募 / 进阶 / 佣兵池详情）一律读 `permanentMercs.level`，禁止改读 `MercLevelSystem`；`MercLevelSystem` 也禁止写回 `permanentMercs`（两边互不读写）。
- 升星不得再改等级；`RunLoadout.TryLevelUpMerc` 只做「转发 `MercLevelSystem`」，禁止在里面自己 `+1`。
- 不要恢复击杀经验：会变成可刷的成长线（主人已明确否决）。
- 满员时不得再让佣兵方向「只出相同卡」：池子必须同时含换人卡（队列里没入队的人）与升级卡（队内），两类同权重；`allowMercWhenFull` 默认 `true` 不许悄悄改回 `false`。
- 升级后刷单位沿用 `RefreshMercUnit`（内含 `OnDead` 重挂），不要另写一套初始化。
