### ⚠️ T1 的实现方式（与字面不同，重要）
`DamageFormula.cs:95-96` 用的是 **`1f + phy + mag`** → `MagicPower` 语义是「**加成量**」（0 = 无加成），不是倍率。
- ❌ 若按字面「给基础值 1f」→ `(1 + 1 + 0.85)` = **伤害直接翻倍**。
- ✅ 实际做法：把 `AttrSystem.cs:204/207` 派生的 `isPercent` 从 `true` 改成 **`false`（加算）**，
  让 `MagicPower` 从 0 开始 `+= intel × 0.01f`。已写进注释挡住后手。
- 验算：基底智力 5 → ×1.05；点满天赋（+85）→ **×1.90**（增量口径 +0.85 = ×1.85）。

## 一、现状（关键事实，改之前必看）

### 1.1 天赋智力现在走的是魔攻，不是智力属性
- `TalentDefs.cs:16` 定义，注释写死「只加 `AttrType.MagicAttack`」。
- **唯一消费点** `AttrSystem.cs:362-365`：`AddAttr(AttrType.MagicAttack, fx.value, false)`。
- 数值：`TalentDefs.cs:568` `{3,4,5,6,7,8,10,12,14,16}`，**10 个节点点满合计 +85 魔攻**。
- 天赋是**跨局账号成长**，且**只有玩家走**（`AttrSystem.cs:119`，佣兵 / 怪物不走天赋，佣兵没有天赋）。
- → 天赋**完全不写 `AttrType.Intelligence`** → `BattleManager.PlayerIntelligence()` 读不到 → **蓝条吃不到天赋**，与主人判断一致。

### 1.2 🔴🔴 最大隐患：智力 → 魔攻的派生目前是「死代码」
`AttrSystem.ApplyDerivedAttributes()`（`:194-216`）：
```csharp
AddAttr(AttrType.PhyPower,   str   * 0.01f, true);
AddAttr(AttrType.MagicPower, intel * 0.01f, true);   // 百分比
```
但 `AttrSystem.AddAttr`（`:224-229`）里 `isPercent=true` 走的是 `_attr[type] *= (1 + value)`，
而 **`MagicPower` / `PhyPower` 从来没有被写入过基础值**（`WriteGameConfigCombatBases:82-95` 和
`PlayerJobBaseStats.WriteCombat:158-193` 都没写这两个键）→ **`0 × 1.3 = 0`**。

→ **就算装备成功喂进去 +30 智力，魔攻一点不会涨，只有蓝条会涨。**
`DamageFormula.cs:95-96` 的 `(1f + phy + mag)` 恒等于 1。

**要让「智力影响魔攻」成立，必须先解决 MagicPower 的真源问题**（见 T1，架构决策，需主人拍板）。

### 1.3 装备侧通道其实是通的（好消息）
- `EquipStatRollup.AppendEquipBonuses:41-101` **没有 AttrType 白名单**，无差别透传。
- 已有先例：`EquipInstance.cs:221/233`（Arcane / Sage 前缀给 `Intelligence`）、`:249`（披风随机四属性之一）。
- UI 显示已通：`EquipUiText.cs:78` 有「智力」中文名，`EquipStatTipUI.cs:32` 显示顺序含四大属性。
- **派生时机没问题**：`ApplyDerivedAttributes()` 在 `RecalcAllAttr()` 的第 6 步（`:179`），排在装备加成（第 5 步 `:172`）**之后**
  → 装备给的基础属性**会**被派生成 MagicPower / MaxHp / Defense，**不需要改调用时机**。
  换装 / 强化 / 打造 / 点天赋 / 换职业 / 开战都会触发 `RecalcAttr` 全量重算。

### 1.4 装备词缀：白名单里没有四大基础属性
`RiftEquipTables.TryResolveCombatAttr`（`:196-222`）共 **15 条**：
`ATK / DEF / HP / MS / CRIT_RATE / ATK_SPD / RANGE / DODGE / LIFE_STEAL / ELE_DMG / CRIT_DMG / DMG_RED / POISON / MAGIC_ATK / MAGIC_DEF`。
**没有 `Intelligence` / `Strength` / `Agility` / `Vitality`**。`default: return false`（不静默发明映射）。
