## 三、任务清单（只给改造点 + 验收，不写完整代码）

### T1 · 新建 `Assets/Scripts/UI/MercStarReadyHint.cs`（静态类，照 `SkillOrderGuide.cs` 骨架）

**做法**
- `public const string Text` = 唯一文案源，≤20 字。建议：「碎片够啦！有佣兵能升星，去酒馆点「升阶」」。调性按 2026-10-16 拍板（有趣、别端着、别书面腔）。
- `static bool Shown` 读 T2 的存档字段；`static bool _pending` 做本进程去重（防三个到账点同帧重复开协程）。
- `public static void NotifyResourcesChanged()`：**第一行必须 `if (Shown) return;` 短路**，再 `if (!MercStarRedDot.HasAnyStarUpReady()) return;`，然后置 `_pending` 并开等待协程。
- 等待协程：等「气泡不会被收掉」的时刻（见 T5），再 `TutorialHintUI.Ensure()` → `Show(Text, null, 6f)`；**只有 Show 真的执行了**才写 T2 标志 + `SaveSystem.Instance?.Save()`（照 `SkillOrderGuide.cs:108-110`）。
- `public static void ResetRuntimeStateForNewGame()`：清 `_pending`、停等待协程、不动存档字段。
- 不要用 PlayerPrefs（换机会重弹、清档还要额外复位）。

**验收**：条件首次满足冒一次气泡；重进游戏 / 反复进出页面 / 反复到账都不再弹；气泡 6 秒自动消失、不挡点击。

**依赖**：T2、T5。

**风险**：`NotifyResourcesChanged` 会被高频调用（见 T4），短路必须放在最前面，弹过之后全局零成本；不顺手做额外节流优化。

## 四、验收清单（逐条过）

1. 新档通第 2 章解锁升星后，第一次资源到账使某佣兵 `CanStarUp` 为真 → 冒一次气泡。
2. 同一账号之后任意操作（重进游戏、反复到账、反复进出酒馆 / 冒险页）都不再弹。
3. 进镇预热点亮、登录、回城、领奖、升星关窗都不会误弹。
4. 碎片 / 徽记 / 金币三样各自作为「最后凑齐」的那一下都能触发。
5. 战斗结算凑齐时：结算界面不被气泡干扰，回城后气泡完整可见、不被 `BattleSettlementUI.Show` 吞掉。
6. 清档重开：标志归零，条件再次满足时能再弹一次；清档前的等待协程不残留。
7. 气泡 6 秒自动消失、不挡点击、文案不溢出底框（34 号字实测两行放得下）。
8. 全程无新增预制体 / 无新增图片资源 / 无美术排版改动。
