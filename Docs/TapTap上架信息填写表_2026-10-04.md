## 2. 商店资料 · 文案（成品，直接复制粘贴）

### 2.1 简介（必填）

```
《像素冒险：裂隙之刃》是一款 2D 像素风自动战斗 Roguelike 冒险游戏。

你将扮演一名刚入职的见习冒险者，从冒险者公会出发，一次次深入变幻莫测的裂缝。战斗中队伍会自动索敌出手，你负责更关键的决定：走哪条路线、捡哪件装备、要不要再往深处走一层。

装备词条、符石组合、佣兵搭配与天赋树相互纠缠，每一局都能长成不同的流派。活着带着战利品撤离，还是贪一层再赌一把——裂缝之前，由你决定。

· 自动战斗，操作轻松，胜负看搭配
· 随机关卡与随机掉落，每局都是新体验
· 多职业佣兵自由组队，装备词条自由构筑
· 章节推进与长期养成并存
```

> 前 47 字已把「类型 + 核心玩法」说完，符合官方「主要内容控制在前 50 字」的建议。

### 2.2 开发者的话

```
这款游戏诞生于一次次"再改一版"的深夜。我们想做的是一款不用拼操作、但每一步都要想的像素冒险：自动战斗负责爽感，取舍与构筑负责乐趣。

开发过程中我们重做了叙事、重排了关卡节奏，也踩过数不清的 UI 坑。它还不够完美，但每次下裂缝的选择都是真实的。

欢迎来公会坐坐，也欢迎把不满写在评论里——我们会一条条改。
```

**建议截的 5 张**（全部竖屏 720×1280，实机）：
1. 战斗主画面（队伍自动战斗 + 怪物成群）
2. 装备三选一 / 背包对比界面
3. 酒馆佣兵招募三选一

5. 城镇冒险者大厅（底栏五入口）

**录屏脚本建议**（60~90 秒）：0-5 秒直接进战斗 → 5-30 秒连续战斗展示 → 30-50 秒掉落拾取与装备替换 → 50-70 秒 Boss 战 → 70-90 秒结算撤离。
