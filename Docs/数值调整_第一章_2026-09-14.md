# 第一章数值调整报告（2026-09-14）

目标：初始装备 **3~4 刀**、换上新装备 **1~2 刀**；敌方**近战血 > 远程血**；第一章（含引导关）节奏顺畅。

---

## 一、改数值前必须知道的一件事

之前按「装备资产里的 `baseAttr`」调是无效的。真实链路是：

```
武器攻击 = equip_attr_ranges.csv 的 ATK 区间随机       ← 会覆盖资产里写的值
           × 星级系数(1~1.2) × 稀有度系数
           → equip_anchors.csv 按 (category, rarity) 上限钳制

英雄攻击 = 职业基础攻击 + 主手攻击 (+ 副手，封顶 0.85×主手)
伤害     = 攻击 − 防御        （第一章普通怪防 2、精英防 6）
怪物血   = baseHp × 章节倍率 × 公会 × 难度 × (1 + 0.05×波次)
```

两个坑：

1. **狂战士双持** ≈ 主手 + 0.85×主手 = **1.85 倍**武器攻击，所以职业表里他的基础攻击必须压低。
2. **引导关血量由 `tutorial_battle.csv` 单独覆盖**，跟 `monster_stats.csv` 无关。

## 二、改了什么

| 文件 | 改动 |
|---|---|
| `equip_attr_ranges.csv` | ATK 普通 **8~15 → 9~12**（收敛方差）；稀有 **20~40 → 28~40**（保证升级体感） |
| `equip_anchors.csv` | 主手/双手弓普通上限 15→12；副手普通 12→10 |
| `player_job_base_stats.csv` | 狂战士基础攻击 **18 → 12**（补偿双持） |
| `monster_stats.csv` | 第一章普通怪重排（近战 68~70 / 远程 52~56，原 54~88）；Boss 900/1200 → **800/1050**；第 5/6/8 章近战上调、远程下调 |
| `tutorial_battle.csv` | 精英血 170~189 → **150~175** |
| `GameConfig.cs` | `MONSTER_ELITE_HP` 180→**105**；`ELITE_GLASS_HP_MUL` 0.7→0.75；`ELITE_TANK_HP_MUL` 1.4→**1.1** |
| `TutorialDirector.cs` | 引导宝箱**强制稀有**武器；首选从「破旧木剑」换成常规武器 |
| `TalentDefs.cs` | 左列天赋早期收益上调：力量 3→5、体质 10→25、防御 2→3、暴击 0.5%→1%、攻速 1%→2% |
| `player_skills.csv` | 战意爆发 攻击 +30%→**+50%**；天雷裁决 300%→**350%** |

> 引导宝箱原来掉的是 `equip_training_sword`（破旧木剑），它走 `isStarter` 分支锁死在普通档 70%，
> 玩家拿到手反而比初始武器弱，爽点直接塌。改成优先常规武器 + 强制稀有后才成立。

## 四、引导关流程检查

`tutorial_battle.csv` 5 步，实际导演只走 1 → 3 → 4 → 5（第 2 步是死数据）。

| 步骤 | 内容 | 怪数 | 装备 | 预计耗时 |
|---|---|---|---|---|
| 1 | 首波右侧进场 | 6 | 初始 | ~18s |
| 3 | 宝箱左右埋伏 | 7 | 初始 | ~21s |
| — | 开箱拿稀有武器 | — | → 稀有 | 爽点 |
| 4 | 佣兵围攻 + 1 精英 + 牧师救援 | 7+1 | 稀有 | ~12s |
| 5 | 佣兵入队后右侧增援 | 8 | 稀有 | ~10s |

- 普通怪 **3~4 刀**（初始）→ **1~2 刀**（宝箱稀有），换装前后手感落差明显 ✓
- 引导精英（150~175）稀有武器 **2~4 刀**，作为小 Boss 不拖沓 ✓
- 净战斗约 60s，加对话/演出整关 3~4 分钟，节奏合理 ✓
