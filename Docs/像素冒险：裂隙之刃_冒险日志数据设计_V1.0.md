# 像素冒险：裂隙之刃手机游戏软件 V1.0
# 冒险日志数据设计

> 冒险日志用于记录玩家在游戏过程中解锁的怪物、佣兵、成就、世界观、主线与支线内容。数据按 V1.0 已实装内容（第一章「暮影森林」）设计，后续章节可扩展。

---

## 一、怪物图鉴

> 本版怪物描述偏趣闻、传闻与冒险者口耳相传的笑话，不代表公会官方立场。
> 怪物按章节/主题分层，每个主题包含 12 个资源位：普通 ×7、精英 ×3、首领 ×2。V1.0 实装第一章「暮影森林」，后续章节图鉴在解锁前显示为灰色剪影。

### 怪物图鉴解锁规则

- **首次遭遇：** 玩家在任意关卡中第一次见到该怪物时解锁基础图鉴与趣闻。
- **首次击败：** 击败后解锁完整描述、对应资源编号与更多传闻。
- **精英 / 首领：** 遭遇即解锁，击败后追加掉落信息提示。
- **V1.0 实装：** 仅第一章「暮影森林」的 12 只怪物可正常解锁；其余章节怪物在图鉴中显示为灰色剪影，提示"在后续裂缝层中可解锁"。
- **资源对应：** 每个怪物编号与 `对应资源` 字段一一对应，数据层可直接通过资源 ID 读取模型、动画与图标。

### 支线故事解锁规则

- 支线通过特定条件触发，如佣兵参战次数、NPC 对话、关卡掉落、Boss 战后事件、累计击杀、收集进度、好感度等。
- V1.0 共设计 16 条支线，覆盖角色羁绊（S001、S006~S008、S015）、世界探索（S003、S009、S011~S013、S016）、主线伏笔（S002、S004、S014）与消费/成就类（S005、S010）。
- 部分支线存在前置或链式解锁（如 S014 需完成 S004 与 S009）。
- 支线奖励不影响主线推进，但可补充世界观、角色背景与战斗资源。
- 已完成的支线标记「已完成」，可反复阅读文本。

## 七、冒险日志界面规则

### 入口

冒险日志入口位于城镇主界面底部导航栏「冒险日志」。

### 标签页

| 标签 | 内容 | 默认排序 |
|---|---|---|
| 怪物 | 已解锁怪物图鉴 | 按编号 |
| 佣兵 | 已解锁佣兵图鉴 | 按入手顺序 |
| 成就 | 成就列表与进度 | 按分类 → 编号 |
| 世界 | 世界观、地点、组织、物品、传说条目 | 按编号 |
| 主线 | 主线章节回顾 | 按章节顺序 |
| 支线 | 支线任务回顾 | 按完成时间倒序 |

### 未解锁展示

- 怪物 / 佣兵 / 世界条目未解锁时显示灰色剪影与问号名称。
- 鼠标长按或点击查看解锁条件提示。
- 主线 / 支线未解锁章节显示锁图标与章节标题占位。

### 红点提示

- 新解锁条目在对应标签显示红点，阅读后消失。
- 成就完成时全局弹出提示并引导玩家打开冒险日志领取奖励。
