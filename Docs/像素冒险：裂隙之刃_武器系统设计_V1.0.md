# 像素冒险：裂隙之刃 V1.0 武器系统设计

> 武器决定角色的主要输出方式与战斗节奏，功能独立，单独成文。

## 1. 武器类型

| 武器类型 | 攻击方式 | 主属性 | 适用职业 |
|---|---|---|---|
| 剑 | 近战物理 | 物理攻击、暴击率 | 战士、骑士、剑士 |
| 斧 | 近战物理 | 物理攻击、暴击伤害 | 狂战士、战士 |
| 锤 | 近战物理 | 物理攻击、眩晕/破甲 | 圣骑士、战士 |
| 长矛 | 近战物理 | 物理攻击、射程 | 枪兵、骑士 |
| 弓 | 远程物理 | 物理攻击、攻速 | 游侠、弓箭手 |
| 法杖 | 远程法术 | 法术强度、元素伤害 | 法师、牧师 |
| 盾牌 | 防御/格挡 | 防御、格挡率、减伤 | 盾卫、圣骑士 |

> 盾牌虽归属武器位，但承担防御功能，其主属性与防具接近；本词条池与命名规则与防具互通。

## 2. 武器主属性规则

> 武器主属性限定决定该类型武器不会出现与其定位冲突的词条。

| 武器类型 | 可出现的主属性 | 不会出现的属性 |
|---|---|---|
| 剑 / 斧 / 锤 / 长矛 | 物理攻击、暴击率、暴击伤害、攻速 | 法术强度、魔法穿透 |
| 弓 / 弩 | 物理攻击、攻速、暴击率、射程 | 法术强度、格挡率 |
| 法杖 | 法术强度、法术穿透、元素伤害、能量恢复 | 物理攻击、暴击伤害 |
| 盾牌 | 防御、生命、格挡率、减伤 | 物理攻击、法术强度 |

## 3. 武器专属词条池

| 词条类型 | 作用 | 适用武器 |
|---|---|---|
| 物理攻击 +N | 提高物理伤害 | 剑、斧、锤、长矛、弓 |
| 法术强度 +N | 提高法术伤害 | 法杖 |
| 攻速 +N% | 提高攻击速度 | 武器、弓 |
| 暴击率 +N% | 提高暴击概率 | 武器、弓 |
| 暴击伤害 +N% | 提高暴击倍率 | 武器（弓除外，部分弓可带） |
| 元素伤害 +N% | 火/冰/雷/毒等属性伤害加成 | 法杖、元素弓 |
| 元素穿透 +N | 无视部分元素抗性 | 法杖 |
| 击杀回血 +N | 击杀敌人恢复生命 | 武器 |
| 射程 +N | 增加攻击距离 | 弓、弩、长矛 |
| 破甲 +N% | 降低目标防御 | 锤、斧 |

## 5. 武器命名示例

| 名称 | 稀有度 | 词条 | 定位 |

| 碎骨之双手斧·卓越 | 史诗 | 暴击伤害（高数值） | 狂战士爆发武器 |

## 6. 特殊效果规则

- **稀有**：1 条随机词条，数值为标准区间。
- **史诗**：1 条随机词条，数值比稀有高 30% ~ 50%，追求单属性质变。
- **传奇**：2 条随机词条，且以被动技能 / 特殊效果为主，体现装备的不可替代性。

## 7. 新手过渡武器示例：暮火之杖

> 为了帮助玩家平滑度过新手期，同时避免后期破坏平衡，设计一把专门克制第一章暮影森林、用到中期后自然退环境的过渡武器。

**武器信息**

| 项目 | 内容 |
|---|---|
| 名称 | 暮火之杖 |
| 类型 | 法杖（远程法术） |
| 品质 | 稀有 |
| 获取方式 | 完成新手引导后自动获得；或达到里程 Lv.2「森林行者」时领取 |
| 适用职业 | 法师、牧师、圣骑士可装备；主角通用装备位亦可使用 |
| 有效区间 | 第一章「暮影森林」全程，第二章「雨林遗迹」前中期 |

**基础属性**

| 属性 | 数值 |
|---|---|
| 攻击 | 18~24 |
| 攻速 | 1.20 |
| 火属性附加伤害 | 命中时额外造成 8 点火伤 |
| 特效 | 「暮火点燃」：对植物、虫类、木质敌人造成伤害时，有 30% 几率点燃目标，3 秒内持续造成火伤 |

**核心机制：章节克制**

- 对第一章暮影森林的所有怪物伤害提升 **40%**：
  - 普通：走路菇、毒伞菇、红浆果怪、森林史莱姆、硬壳甲虫、冰晶虫、食人花苞
  - 精英：刺毛兽、赤甲蟹、岩块傀儡
  - 首领：巨型食人花、獠牙野猪王
- 对第一章最终 Boss「森之守护者」额外造成 **20% 伤害**并削弱其回血技能。

**后期定位**

- 第二章起，多数怪物火抗提高或不再被植物/虫类克制，暮火之杖退化为一把普通稀有法杖。
- 玩家需要在第二章中期更换为对应章节属性的武器（如雷/冰），促使养成流转。

**设计目的**

- 降低新手期操作门槛，让玩家更快熟悉战斗节奏。
- 提供清晰的「属性克制」教学：遇到被克制的怪物时伤害数字变红/出现克制提示。
- 避免一把武器通吃全章节，保留后期装备追求空间。

> 备选方案：若项目更偏向物理远程，可将暮火之杖改为「暮火长弓」，属性与克制效果不变，仅适配游侠/弓箭手职业。
