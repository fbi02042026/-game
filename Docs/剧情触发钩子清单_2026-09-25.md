# 剧情触发钩子清单（2026-09-25 全量盘点）

> 用途：主人要「把触发剧情的钩子整理一下」。本文档是**只读盘点**——列出当前所有会播剧情的入口、触发条件、代码位置，以及**当前没有钩子的位置**（缺口）。
> 结论先行：**剧情钩子并不缺，缺的是「城镇内的日常节拍」**。战斗侧有 4 个钩子，城镇侧只有酒馆 1 个 + 引导 1 次性流程。

## 一、剧情播放的唯一底层

所有剧情都走同一个总线：

| 方法 | 作用 | 文件 |
|---|---|---|
| `StoryDirector.Ensure().Play(beats, onDone)` | 播一串节拍，可带回调 | `Assets/Scripts/Story/StoryDirector.cs` |
| `StoryDirector.Solo("说话人", "台词", 立绘)` | 造一条**对话**节拍 | 同上 |
| `StoryDirector.Narration("旁白")` | 造一条**旁白**节拍 | 同上 |
| `StoryDirector.Instance.IsPlaying` | 是否正在播（多处用于互斥/防重入） | 同上 |
| `StoryDirector.Instance.StopPlaying()` | 强制中断 | 同上 |
| `.Bg(StoryBackgrounds.XXX)` | 指定背景（链式） | `StoryBackgrounds.cs` |

**互斥现状**：`FirstRunGuide`、`TutorialDirector`、`SoftCopyrightUiProbe` 都会查 `StoryDirector.Instance.IsPlaying` 做防重入。
⚠ **`DailyLoginUI` 不在互斥体系里** —— 它进城镇时自动弹全屏，会盖住正在播的剧情（这就是主人看到「关了每日登录才露出剧情」的原因）。

## 三、缺口分析（主人说的「其他地方没有剧情触发」）

**现状**：除引导期外，玩家**进入城镇后没有任何自动剧情**。想看到剧情只有三条路：
1. 打战斗（战前 / Boss 战后）
2. 手动点酒馆「佣兵情报」
3. 点主线任务跳转

**明确空缺的位置**：

| 缺口 | 说明 | 建议（待主人拍板） |
|---|---|---|
| 进城镇每天 1 次 | 缺「回城日常节拍」——目前回城什么都没发生 | 每天首次回城播 1 短段（咨询台/老板娘），与每日登录**错峰** |
| 角色页 | 切到角色 tab 无任何叙事 | 首次切到角色给 1 段（可选） |
| 冒险页 | 首次进冒险页无叙事 | 首次进给 1 段章节预告（与 `TryPlayPreBattle` 二选一，别重复） |
| 冒险日志 | 只有条目解锁，无播报 | 解锁新条目时弹气泡（非全屏） |
| 农场 / 商店 / 邮件 | 完全无叙事 | 建议不做，纯功能 |

**关键约束（必须遵守）**：
- 新增钩子必须查 `StoryDirector.Instance.IsPlaying` 防重入。
- **必须与每日登录错峰**：`DailyLoginUI` 是全屏弹窗且进城镇自动弹；两条同时触发会互相盖住（本次 bug 的根因）。建议规则：**每日登录未关 → 剧情排队等待**，或每日登录改为**不自动弹**（改成咨询台气泡提示）。

## 四、与「每日登录」的冲突（本次 bug 定位）

- 每日登录入口：`TownSceneBootstrap.cs:139 TryDailyLoginOnce()` → `HasClaimable()` → `DailyLoginUI.Show()`（进 Town 自动弹，全屏）。
- `DailyLoginUI.Hide()` 只有 `_root.SetActive(false)`，**没有任何剧情回调**。
- 酒馆剧情的入口：`TavernUI.cs:301` 的「佣兵情报」按钮（**手动**）。
- 两者是**遮挡关系**：剧情对话 UI 已开 → 每日登录盖在上面 → 关掉它才露出剧情。

**修法选项（需主人选）**：
- **A**：每日登录不自动弹，改成城镇内一个红点/气泡入口（主人本次说「每日登录不触发剧情」，倾向此项）。
- **B**：保留自动弹，但弹之前**先让剧情播完**（每日登录排队）。
- **C**：每日登录期间**暂停剧情队列**，关闭后再播。
