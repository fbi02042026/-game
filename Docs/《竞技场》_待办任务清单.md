### 2. 排行奖励面板「黑底没生效」——根因不是颜色

- 现象：面板 Dim 已配 (0,0,0,0.6)，打开仍看不到黑底。
- 根因：`EvacuateConfirmPopup` 被拖进主预制体后是 anchor(0.5,0.5) + sizeDelta(0,0) → **自身 0×0**；
  其下 `Root`/`Dim` 都是 stretch(0,0~1,1)，stretch 相对父级算 → 父 0×0 整条链塌成 0 像素。改颜色/alpha 无效。
- 修法：`BuildRewardPanel` 里 `UiLayoutStretch.ApplyFillScreen(root as RectTransform)`（唯一出口，不动 .prefab）。
- ⚠ 教训：**弹窗皮节点拖进别的预制体当子节点时，先查 anchor/sizeDelta 是否 0×0**——stretch 链会整条塌成 0。
