### N-1　佣兵参战计数　【阻塞 S006 / S007 / S008】

```csharp
// 队伍确认进入战斗时，对每个参战佣兵调用一次

    AdventureLogCatalog.MercBattleKey(mercAssetId), 1, evaluate: false);
```

- 资产 ID：米娅 `H005`、布罗克 `H007`、索菲 `H011`

- **不做会怎样**：这 3 条支线继续锁死
