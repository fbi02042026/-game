# 《天赋界面简单直观化》验收与微调指南（2026-11-19）

## 一、做了什么（对照参考截图的四个直观要素）

参考图的核心：「大图标 + 数值角标」「节点串成一条直线」「点开看当前→升级后」「一键升级」。本轮四步全部落地：

| 步骤 | 内容 | 落点文件 |
|---|---|---|
| ① 右列拉直 | 界面隐藏 R_F1/R_F2（物理/法术专精二选一），数据/存档全保留；右列剩 13 个节点排成一条直线 | `TalentDefs.cs`、`TalentUI.Lists.cs`、`TalentSystem.cs` |
| ② 左列图标化 | 图标放大、效果文字改成右下黄色数值角标（+15 / +4%）、名字降为副标题；Number/连线/升级按钮不动 | 新增 `TalentUI.NodeStyle.cs`、`TalentUI.Lists.cs`、`TalentUI.Refresh.cs` |
| ③ 点击对比卡 | 点左列节点先弹「效果 + 消耗金币 + 持有量」确认卡，确认才扣钱（原来点一下直接买） | 新增 `TalentUI.LeftBuy.cs`、`TalentUI.Interaction.cs` |
| ④ 一键升级 | 左列底部区域加「一键升级」按钮，弹一次确认→连买到金币不足/等级门槛/点满，最后汇总反馈 | `TalentUI.LeftBuy.cs`、`TalentUI.cs` |

**没动的部分**：数据表 csv/bytes、存档结构、解锁规则、属性结算、右列专精效果、美术资源、预制体坐标（全部保持原样）。所有视觉改动是运行时适配，可随时回退。

## 二、关联坑一并处理

- R_DUAL「技能精通」原前置是「主流派 R_F1/R_F2 满 5 级」。隐藏流派节点后新玩家会永久点不了它 → 按主人拍板**改挂等级门槛**（R_DUAL 自身 `unlockLeftIndex=40`，即 40 级可解锁）。
- 红点链路（`EntryDotShouldLight` / `CollectUpgradeableRightIds` / `HasUnseenUpgradeableRight` / `NotifyLevelUp`）统一过滤 R_F1/R_F2，避免「红点亮了却找不到节点」。

## 三、进引擎验收清单

1. 打开天赋页：右列应是一条直线，不再有「流派·专精」那行二选一。
2. 左列每个节点：图标明显放大；右下有黄色数值（+15 / +4% 那种）；名字是上方小字；左侧 L 序号、连线、升级按钮仍在。
3. 点左列任一可买节点：弹确认卡（L序号+名字+效果+消耗金币+持有量），点「确定解锁」才扣钱；点取消不扣。
4. 金币不足时点节点：仍弹卡，卡里写明「金币不足」；点确定弹 toast 提示。
5. 右下「一键升级」按钮：点→弹一次确认（写明买几个、消耗多少）→确定后连续买，钱不够/等级不够自动停→汇总 toast。
6. 人物升级跨门槛的右列红点、行内「新」字仍正常；点开天赋页红点灭。
7. 老存档：之前点过物理/魔法专精的玩家，属性效果照常生效（数据没删），只是界面不显示那两个节点。
