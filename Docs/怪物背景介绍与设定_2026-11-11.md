## 一、创作假设（请主人过目，有出入直接说）

1. **受众 / 使用场景**：竖屏 720×1280 自动冒险构筑手游（安卓 / TapTap），全年龄轻喜剧。这 84 条只出现在「冒险日志 → 怪物图鉴」，**击败该怪之后**才解锁显示，属于可选层信息，主线不通读也完全看得懂。
2. **调性**：延续项目 10-16 拍板的「有趣、流行、适合年轻人，别端着别书面腔」，加上本轮「可以好玩一点」。不写悲剧、不写血腥、不碰现实宗教 / 政治 / 品牌 / 真人 / 版权角色。
3. **世界结构**：单一世界「裂隙之刃」，八章裂隙层，章名与顺序以 `chapter_theme_map.csv` 为准。第四章名单偏「洞窟工地」而章名是「晨曦草原」，介绍里用「草原底下那片洞窟」把两边接上，**章名一个字不动**。
4. **交付形式**：图鉴 `MonsterEntry.Desc` 的中文常量（击败后解锁的「完整描述」），不是对白、不是分支剧情、不涉及玩家选择，因此不设计分支与后果。
5. **返工范围**：【2026-11-11 主人拍板后改写】**所有章节统一**——第一章 12 条也按同一口径重写，不只改后 84 条。外号从文案里**抽成独立字段**（`Nickname`），怪物 `Lore` 从玩梗趣闻改成**传闻**。佣兵条目不动（它的 `Lore` 才是趣闻）。

## 二、写法口径

- **介绍 / 传闻 / 趣闻，三者分工**（本稿核心判断，11-11 主人拍板后定稿）：
  - **介绍（`Desc`）= 设定层**：它在这一章的哪儿、以什么方式活动、为什么挡你的路。玩家击败后才解锁。
  - **传闻（`Lore`，怪物专用）= 半信半疑的那部分**：冒险者之间口口相传，带一点未知感 / 危险感 / 离奇感，勾着玩家去打。未击败时它是唯一能看到的正文。
  - **趣闻 = 佣兵专用**（佣兵条目的 `Lore`）：外号玩梗那一套，怪物不再占用，所以怪物 `Lore` 里不再出现「江湖人称「X」：」这种句式。
  - **外号（`Nickname`）独立成字段**，不再塞在文案里；一处只干一件事，介绍不被外号句截断。
- **陆 / 空、远 / 近化成画面**，不写系统词：不出现「空中单位」「远程攻击」，改成「悬在半空，脚下影子还留在地上」「隔老远把东西送过来」「贴上来才动手」。空中怪的「影子留在地上」正好呼应已落地的 0.3 浮空 + 阴影贴地表现。
- **不描述具体长相**：按 v3 拍板「按名字走」，约 55/96 正式名与当前图片不完全贴合。介绍只写行为 / 位置 / 战斗方式，从根上避开「看着像水却说生活在沙漠」。
- **不升级暗黑尺度**：墓园、炼狱的既有名字照用，但不新增死亡、离别、创伤类背景；「剔骨师」只写手法利落，不写骨头。
