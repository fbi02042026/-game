### 6.1 攻击距离二次修（远程宠吃不到近战 0.9 系数）
- 根因：`GetEffectiveAttackRange()` 里我方近战的 `r *= 0.9f` 只在 `UsesMeleeBasicAttack()==true`（刀光）时执行。
  - 近战宠（刀光）有效射程 = 0.96×0.9 = **0.864**，本就与玩家一致；
  - 远程/法术宠改 Orb 弹丸后 `UsesMeleeBasicAttack()==false`，吃不到 0.9 → 有效射程 0.96，再加 `BasicAttackRangeSlack=0.12` → 视觉上「隔一段距离就出手」。
- 修法：`Pet.cs` `SetupPetAttributes` 配置射程 `GameConfig.RangeSword * (IsMagicPet||IsRangedPet ? 0.9f : 1f)`，
  远程/法术宠预乘 0.9 → 全部宠物有效射程统一 **0.864**（与玩家/近战佣兵同），弹丸子弹样外观保留不动。
- 未动 `UnitBase.Attack.cs`（会影响全单位），未动表/bytes。

### 6.2 形象再放大一倍
- `Pet.cs` `PET_HEIGHT_RATIO`：0.5 → **1.0**（从「玩家一半高」改为「与玩家等高」= 再放大一倍），`internal` 暴露。
- `BattleManager.PetRescue.cs` `SpawnRescueDogVisual`：`hs * 0.5f` → `hs * Pet.PET_HEIGHT_RATIO`，剧情狗与战斗宠物共用真源、大小一致。
- 派生项自动跟随同一套 bounds 逻辑：血条头顶定位 `PlaceHpBarAboveHead`、受击/发射点 `ConfigureHitFirePoints`、血条宽度 `GetHpBarWorldWidth`（都按实时 bodyH 算，无需另改）。

### 6.3 阴影再放大一倍
- `Pet.cs` `BATTLE_SHADOW_SIZE_SCALE`：6 → **12**。
- 注意叠加：形象翻倍后阴影节点的 origSize 取自 `r.bounds.size`（已随体型放大），再乘 12 → 阴影实际比上一版约大 2×（体型）再 2×（系数）。真机若偏大，优先回调此常量（`BATTLE_SHADOW_FLATTEN=0.6f` 纵压保持）。
