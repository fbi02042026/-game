## 隐私政策

**生效日期：【____】年【____】月【____】日**
**更新日期：【____】年【____】月【____】日**

苹果核工坊（以下简称「我们」）作为《像素冒险：裂隙之刃》（以下简称「本游戏」）的运营者，深知个人信息对您的重要性。我们将按照法律法规的要求，保护您的个人信息及隐私安全。请您在使用本游戏及相关服务前，仔细阅读并理解本隐私政策。

### 一、我们如何收集和使用您的个人信息

为保障游戏正常运行与设备兼容，我们会收集以下设备信息：
- 设备标识（**Android ID**）；
- 设备型号、操作系统版本、屏幕分辨率；
- CPU / GPU 信息、系统语言、运行区域。

上述信息主要用于：提供游戏服务、设备兼容性适配、运行统计与反作弊。我们使用的 **Unity3d（团结）引擎** 会在游戏运行时读取 Android ID 用于设备识别与兼容性适配。

### 二、第三方 SDK

本游戏接入的第三方 SDK 及其收集的信息，详见《接入第三方SDK情况说明》。我们会对第三方 SDK 的数据处理进行监督，但其处理行为受其自身隐私政策约束。

### 三、您的权利

您有权查阅、更正、删除您的个人信息，并可随时撤回对个人信息收集的同意。撤回同意后，我们将停止相关收集与处理，但可能影响部分功能的使用。

### 四、未成年人的保护

我们高度重视未成年人保护。若您为未成年人，请在监护人陪同下阅读本政策，并在其同意下使用本游戏。
