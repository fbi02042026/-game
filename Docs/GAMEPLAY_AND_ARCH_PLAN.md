# 像素冒险：裂隙之刃 — 战斗粘性提升 + 架构整改方案

> **证据日期**：2026-09-12，基于 `Assets/Scripts` 262 文件 / 7.4 万行全量只读审查。
> **对照**：[`ARCHITECTURE_REVIEW.md`](./ARCHITECTURE_REVIEW.md)（架构）、[`OPTIMIZATION_PLAN.md`](./OPTIMIZATION_PLAN.md)（Phase 0–6）、[`MOBILE_MINIGAME_PLAN.md`](./MOBILE_MINIGAME_PLAN.md)（多端与排期）。
> **一句话诊断**：战斗不上瘾不是手感不好，而是**玩家在里面没有事可做、没有东西可贪、也没有变强的感觉**——决策、反馈、回报、多样性、成长五层同时缺位。

---

## 0. 结论速览

| 层级 | 现状 | 一句话方案 |
|------|------|-----------|
| 决策 | 普攻/技能/佣兵全自动，无闪避打断，玩家只剩摇杆走位 | 技能改手动优先、加闪避、加打断 |
| 反馈 | 顿帧/暴击慢放/受击闪白都有，但**屏震、击杀镜头、雷击奥义默认关闭** | 打开三个开关 + 连杀兑现 |
| 回报 | 风险全在战前难度，战斗中无"贪一波" | 加低血加成、连杀奖励、局内高风险事件 |
| 多样性 | 敌人只有血厚/打疼一个维度，Boss 二阶段只是数值翻倍 | 复用现有表字段做行为差异化 |
| 成长 | **等级是死轴（恒 Lv1）**，局内变强只体现为数字变大 | 接线等级 或 加局内三选一强化 |

## 1. 战斗为什么不上瘾：五层诊断与方案

### 1.1 决策层：玩家现在是"观众"

| 现状 | 证据 |
|------|------|
| 普攻全自动，进射程自动出手、松手自动锁最近怪 | `Hero.cs:246-254`、`Hero.cs:390-398` |
| **玩家技能强制自动释放、禁止点击** | `PlayerSkillPassive.cs:10-19` |
| 佣兵技能全自动 | `MercSkillMigrate.cs:149` |
| 无闪避/翻滚/冲刺/打断/仇恨拉扯 | `Hero.cs` 全文无 dodge/dash；怪物固定找最近友军 `Monster.cs:398-419` |
| 能量只由"我方挨打"回充 → 玩家无法经营大招 | `UnitBase.cs:1224` |

**方案（按性价比排序）**

| # | 改动 | 成本 | 预期 |
|---|------|------|------|
| D1 | **技能改手动优先**：点击头像可放，自动只作兜底（有能量时高亮可点） | 低（改 `PlayerSkillPassive` 门控 + HUD 高亮） | 立刻多出一个决策点，且是"经营大招"的核心乐趣 |
| D2 | **闪避/翻滚**：短按摇杆双击或独立按钮，0.3s 无敌帧 + 位移 | 中（新状态 + 动画 + 无敌帧） | 走位从"躲避"升级为"操作"，对抗远程/红圈的手感质变 |
| D3 | **打断机制**：怪蓄力红圈期间打足伤害可打断 | 中（红圈已有，加可中断判定） | 给输出一个"该不该贪输出"的抉择 |
| D4 | 能量改为"挨打 + 主动命中"双通道回充 | 低 | 打得越凶大招越快，正循环 |

> 注意：D1/D4 与现有"自动战斗"定位不冲突，建议**手动优先 + 自动兜底**，保留挂机舒适区。

### 1.2 反馈层：最提味的开关被关着

`CombatJuice` 骨架其实齐全，但：

| 项 | 状态 | 位置 |
|----|------|------|
| 顿帧 0.035–0.08s | 开 | `GameConfig.cs:609-611` |
| 暴击慢放 timeScale=0.1 | 开 | `CombatJuice.cs:193` |
| 击退 / 受击白闪 / 四档伤害数字 / Boss 处决压暗 | 开 | `CombatJuice.cs:83-91`、`UnitAnimation.cs:1045` |
| **屏震** | **关** | `COMBAT_JUICE_CAMERA_SHAKE = false`（`GameConfig.cs:602`） |
| **击杀镜头** | **关** | `COMBAT_JUICE_KILL_CAM = false`（`:652`） |
| **雷击奥义演出** | **关** | `THUNDER_ULT_ENABLED = false`（`:662`） |
| 残影 | 已改只随攻速 buff（连杀不再触发） | 本次改动 |

**连杀是"只显示不兑现"的数字**：窗口 3.2s，奖励仅攻速最多 +50%；源码注释直写"连杀（仅展示，击杀不掉金币）"（`BattleManager.cs:1542`）；`COMBO_BONUS_GOLD = 1` 定义了却全项目无引用（`GameConfig.cs:598`）。

**方案（最低成本、最高感知，建议聚光灯前就做）**

| # | 改动 | 成本 |
|---|------|------|
| F1 | 打开屏震 + 击杀镜头（击杀镜头建议只在精英/Boss 触发，避免晕眩） | 极低（改 2 个常量） |
| F2 | **连杀兑现**：连杀 ≥3 起每杀额外金币/能量，`COMBO_BONUS_GOLD` 接线 | 低（常量已存在） |
| F3 | 连杀档位演出：x5 / x10 / x20 各给一次全屏演出（字效 + 短慢放 + 屏震叠加） | 低（复用 `CombatJuice.cs:308-340` 的 Toast 改成演出） |
| F4 | 打开雷击奥义演出（若演出资源已就绪） | 低 |

### 1.3 回报层：战斗中无东西可"贪"

现状：死亡惩罚是金币清零 + 局内装备清空（`BattleManager.cs:1960-1964`）；风险只由战前难度决定（属性 ×1/1.35/1.8，金币 ×1/1.8/3，`GameConfig.cs:512-524`）；战斗内唯一"贪"点是花金币提前出兵（`WAVE_SKIP_GOLD_PER_SEC = 3`）。

**方案**

| # | 改动 | 说明 |
|---|------|------|
| R1 | **低血加成**：HP < 30% 时攻速/暴击提升，血量越低越猛 | 把"危险"变成"收益"，制造紧张—释放 |
| R2 | **连杀不掉连击条**改为可续杯：连杀窗口内击杀回少量血/能量 | 让"连"本身成为资源 |
| R3 | **局内风险事件**：精英关可选"诅咒换奖励"（受 20% 增伤换一件传奇） | 复用现有弹窗，加一个二选一 |
| R4 | 撤离价码可视化：撤离能带走多少金币实时显示 | 把"走还是贪"变成持续决策 |

### 1.4 多样性：敌人只有一个维度

现状：攻击风格只有近战/远程/弓三种（`MonsterAttackStyleTable.cs:8-13`）；同章内 `baseAtkSpeed` 全 1.5、`attackRange` 全 1.5、`moveSpeed` 全 2.2，仅 HP/ATK 线性递增（`monster_stats.csv:3-38`）；Boss 二阶段只是数值乘倍率 + 连砸第二下（`Monster.cs:1356-1361`），**无新招式**。唯一交互窗口是红圈预警 2.0–3.2s（`GameConfig.cs:452-463`）。

**方案（复用现有表字段，避免新系统）**

| # | 改动 | 成本 |
|---|------|------|
| E1 | 给 `monster_stats` 加行为标签列（冲锋 / 自爆 / 护盾 / 召唤 / 后跳射击），按标签切 AI 分支 | 中 |
| E2 | 同章内至少三种节奏：快而脆 / 慢而重 / 远程骚扰，打散 `baseAtkSpeed` 与 `moveSpeed` 的整齐划一 | 低（改表） |
| E3 | **Boss 二阶段加新招**（哪怕只有一招：范围冲刺或召唤小怪） | 中 |
| E4 | 混搭波次：远程 + 冲锋组合，逼迫走位而不是站桩 | 低（改波次表） |

### 1.5 成长层：玩家从来没"变强"过（最严重）

**已验证的两条硬伤：**

1. **等级是死轴**：`Hero.AddExp` 定义了（`Hero.cs:97`）但**全项目零调用点**；实际经验走 `HiddenLevelSystem`（击杀 8/精英 20/Boss 50 + 通关 35，`HiddenLevelSystem.cs:129-143`），而那是**隐藏等级、不展示、只影响掉落稀有度权重**（`RiftEquipGenerator.cs:93`）。所以玩家等级恒为 1，`LevelSystem` 的 Attack+3 / MaxHp+15 从未发生。
2. **成长无沉淀**：撤离与死亡**都清空局内背包**（`GridBackpackSystem.cs:26-38`、`BattleManager.cs:1964`），跨局只剩天赋与建筑等级。

这意味着：一局之内玩家的"变强"只有装备词条，而它还会在结算时消失。**玩家没有雪球感，这是不上瘾的深层原因。**

**方案**

| # | 改动 | 成本 |
|---|------|------|
| G1 | **二选一**：要么把 `Hero.AddExp` 接进击杀（让等级真的动起来），要么删掉 `LevelSystem` 死代码。推荐先接线 + 每级弹一个升级演出 | 低 |
| G2 | **局内三选一强化**（每层通关一次：攻速 / 暴击 / 吸血 / 范围），复用现有宝箱三选一弹窗 | 中（高收益，直接制造 build 乐趣） |
| G3 | **成长沉淀**：撤离时允许带出 1 件装备（或折算成材料），让局内掉落转化为局外收藏 | 中（需改结算与背包） |
| G4 | 局内 HUD 显示"本局已获得提升"清单，让变强可见 | 低 |

## 2. 元游戏：长线粘性

| 问题 | 证据 | 建议 |
|------|------|------|
| **伪随机、零决策** | 层间轮盘是预先 Roll 完的动画，减速段精确停到钉死的赢家槽（`NextStageRouletteUI.cs:365-371,415-429`）；`StageType` 只有 Normal/Elite/Rest/Boss，无事件/祝福/商人 | 改为真 2–3 选 1，补事件/祝福/商人节点 |

## 5. 需要策划拍板的取舍

| 议题 | A 方案 | B 方案 |
|------|--------|--------|
| 技能自动还是手动 | 手动优先 + 自动兜底（多决策，需 HUD 改造） | 保持全自动（省事，但决策点仍缺） |
| 是否加闪避 | 加（操作上限高，但有动画/无敌帧成本） | 不加，用打断 + 走位替代 |
| 局内成长用哪条 | 局内三选一强化（build 乐趣强） | 接线等级系统（改动小，但成长曲线平淡） |
| 装备是否可带出 | 允许带 1 件（有沉淀，削弱单局风险） | 维持清空（保留 Roguelike 纯粹性） |
