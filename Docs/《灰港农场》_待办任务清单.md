## 二、目标与范围

1. 把停用的离线链路与没接 UI 的建筑数据层接起来，扩出「灰港农场」：4 座建筑 + 离线产出 + 升级 + 闲置佣兵下地 + 广告加速。
2. **不新增资源品类**：农场产出只有「作物」一种（分低/中/高三档），是**农场内部材料**（存 `SaveData` 农场字段，不进 `ResourceWallet` 顶部资源条、不新增 `ResourceType`）。建筑升级吃「金币 + 作物」——金币消化「约 6.8 万金没有明确去处」，作物只有下地才有 → 玩家必须又打本（攒金币）又派佣兵下地（攒作物）才能扩地，两条线都拉动。
3. **🔴 作物绝不直接卖金币**（2026-11-11 主人拍板 + 项目 C 级警告）：离线产钱会让在线战斗贬值。作物只有三条出口 = ① 建筑升级材料 ② **市集换道具与礼物** ③ **城镇网络送物资涨好感、交换别镇特产**。
4. **建筑的获得物 = 职业向加成**：菜畦→近战系攻击、温室→远程系攻击、粮仓→全体佣兵生命、农舍→地块数。走独立外层乘区（照 `ApplyOutStarBonus` 模式），**不碰玩家自身属性**（天赋已占）、**不动升阶/升星**（单佣兵线）、**不改羁绊**（已并入花名册公式）。
5. **不碰三条产出**：不产金币主体、不产装备、不产抽卡资源；离线 8 小时起封顶。在线打本仍是变强主路。
6. 留存钩子：次日「睡前下种、早上进农场收菜」；3/7 日「建筑等级链 + 四季作物解锁」；广告「催熟 / 双倍收成」均为可选。
7. **三层分工**（本主题的骨架）：**农场 = 产**（把闲置佣兵变作物）→ **市集 = 本地换**（作物→道具/礼物，稳定无概率）→ **城镇网络 = 远途贸易**（作物→别镇特产，概率、好感驱动、长周期）。三层的产出最终都落到**既有成长线**（升星 / 升阶 / 羁绊 / 天赋），不新开数值线。
8. **一期范围**：T1~T8 + T3A（市集）+ T4A。**二期**（T3B/T3C 城镇网络、T9~T13）一期跑通再上——**推荐先上农场+市集**（作物先有出口，闭环成立），城镇网络工程量大（地图 UI + 8 节点 + 道路 + 好感度）放二期。**若主人要 SLG 同期上，见 §四 待确认 14**。

### 2.1 岗位制与产出节奏（**建议值待实测**）

**三层关系（互不重叠）**：

| 层 | 内容 | 性质 |
|---|---|---|
| 建筑等级 | 菜畦→近战系攻击 +2%/级、温室→远程系攻击 +2%/级、粮仓→全体佣兵生命 +2%/级、农舍→地块数每级 +1 | **永久 · 全局 · 所有该职业佣兵都吃到 · 与谁在不在地里无关**��无关**；上限 Lv10（满级 +20%） |
| 派遣（岗位） | **四座建筑全部设岗位，每岗位派 1 名佣兵**；派下去的人本局不能上阵；职业与地块匹配产速 ×1.2 | **临时占用** · 只影响产速与可用人力 · 不影响加成归属 |
| 四季 | 每季解锁**新作物 + 一种新机制**（不是更多数字），共 4 季 | **长期目标** · 防建筑满级后功能作废（见 §2.2） |

**四岗位分工（四座建筑全部吃佣兵，治「闲置佣兵太多」）**：

| 建筑 | 岗位产出 | 值守价值 |
|---|---|---|
| 菜畦 | 作物（升级主料） | 主力产出位；职业匹配 ×1.2 产速 |
| 温室 | 稀有作物（高级档，Lv8+ 升级料） | **必须派人**，否则高阶升级卡死 |
| 粮仓 | 无直接产出 | 每多 1 人值守，存作物上限 +50%（不升就溢出浪费） |
| 农舍 | 无直接产出 | 每多 1 人值守，**总地块数 +1**（人越多能派越多） |

→ 闲置佣兵全部有活干；「派谁去」不再只在地里排队。

→ **市集不是岗位、不是建筑**：它是农场面板里的一个页签（作物兑换站），不派人不占地块，只吃作物。

→ **城镇网络也不占农场岗位**：贸易队是从同一批闲置佣兵里再抽人（同一佣兵不能同时在地里和路上），走的是完全独立的第三条通道。

**产出**：1 块地 = 10 份作物/小时（4 小时一茬、每茬 40 份），离线 8 小时封顶 = 80 份/天；1 座温室 = 4 份稀有作物/小时（4 小时一批、每批 16 份，8h = 32 份/天）；菜畦等级每级 +20% 产速。**作物分三档**：低级（小麦·土豆）/ 中级（番茄·黄瓜）/ 高级（南瓜·辣椒）；当季作物按章节解锁，集市种子站可用低级作物换高档种子（3:1 / 9:1）。

| **局外升星**（`MercStarSystem`，0→3 星） | 物攻/物防 +8%/星、魔攻/魔防 +7%/星 | 本命碎片 + 职业徽记 + 金币/钻石 | ❌ 不碰（单佣兵线，农场给全局就重复） |
| **局外升阶**（`MercGrowSystem`，Lv1→25/35/50） | 累计资质（攻/防/血百分比）+ 技能强化档 0~3 | 金币 + 职业徽记 | ❌ 不碰（同上） |
| **羁绊**（好感满 60 → 通关羁绊副本） | 血/攻/防/魔攻/魔防 **×1.5** | 好感值（对话 / 送礼 / 闲话） | ❌ 不碰（已并入花名册公式唯一出口） |
| **建筑等级**（本方案） | **一整队同职业佣兵**的永久加成 | 金币 + 作物 | ✅ **农场只占这一条** |
| **天赋树** | 玩家自身属性（🔴 **佣兵吃不到**，`AttrSystem.cs:266-275` 只给 Player） | 天赋石 | ❌ 不碰 |

**所以农场的定位很明确**：农场不是「又一条数值线」，它是 **「给一整队同职业佣兵加永久加成」的加速器** —— 唯一的第四条线。

**作物不是新货币，是「补缺口用的通用料」**：市集把作物换成**既有道具**与**既有礼物**，礼物再喂佣兵好感 → 羁绊副本 → ×1.5。玩家不用作物去开第三条数值线，而是用作物去补自己缺的那条线 —— 既有新目标（种菜），又没有新负担（又要记一种货币、又要记它能干什么）。

| 玩家缺口 | 作物怎么补 | 接到哪条线 |
|---|---|---|
| 天赋点不够点下一个节点 | 市集换天赋石 | 天赋树（玩家） |
| 某个佣兵升阶卡徽记 | 市集换职业徽记 | 升阶 / 升星 |
| 某个佣兵好感差一点 | 市集换礼物 → 送礼 | 羁绊（×1.5） |
| 想更快拿本命碎片 | 市集/城镇网络换碎片 | 升星 |

### 2.4 让玩家一眼看懂：三招（UI 口径，落地照抄）

1. **砍掉中间货币层级**：不设「口粮 / 加工品 / 合成币」这类二道材料。作物直接分三档（低/中/高），玩家手上永远只有「作物」一种新东西。
2. **叫「市集」，不叫「交易所」**：市集是玩家最熟的词，一进去就知道「这里拿东西换东西」。
3. **把因果链直接画在面板上**：`菜地 → 市集 → 道具/礼物 → 佣兵`，一行箭头图，标清中间扣什么、到账什么。

**面板文案范式**（照抄，别自创）：

| 场景 | 文案 |
|---|---|
| 建筑升级按钮 | `升级：小麦 20 · 金币 300 → 近战佣兵攻击 +2%` |
| 市集兑换行 | `小麦 20 → 天赋石 5` ／ `小麦 30 → 礼物（金块）1` |

### 2.5 市集：作物换道具与礼物（主人 11:15 拍板）

**定位**：农场面板里的一个页签（不是建筑、不派人不占地块）。**本镇 = 稳定兑换，无概率**，把作物接进既有成长线。

| 兑换档 | 用什么换 | 换到什么 | 接到哪条线 |
|---|---|---|---|
| **普通档** | 低级作物（小麦 / 土豆） | 天赋石、佣兵碎片（普通）、普通材料（分解材料）、**普通礼物** | 天赋树 / 升星 / 装备强化 / 佣兵好感 |
| **高级档** | 高级作物（南瓜 / 辣椒，🔴 **需建筑等级达标才解锁**） | 传奇碎片、高级徽记、**高级礼物（珍品档）**、稀有材料 | 升星 / 升阶 / 羁绊 |

- **不新增资源品类**：作物是农场内部计数；换出去的天赋石走 `ResourceWallet`、徽记走 `MercGrowInventory`、碎片走 `ItemGrantSystem.GrantItem`（→ `townBagItems`）—— 发放出口全部现成。

### 2.6 城镇网络（SLG 玩法层，主人 11:15 / 11:20 拍板）

**一句话**：玩家在一张大地图上选城镇，**由近到远逐段开通道路**，每个镇有**不同的物资偏好**；先**送物资把好感度送满**，达标才能**开启交换**；交换是**自动的**，每次换到什么是**概率**的 —— 普通物资几率大，**好感度越高换得越好**。

**与农场/市集的关系**：农场产作物 → 作物送镇涨好感 → 好感达标开交换 → 换回**别镇的特产道具**（本镇没有的东西）。市集是「本镇稳定换」，城镇网络是「远途概率换」，两条不重复。

#### 2.6.1 地图与道路

- **8 个城镇节点**（本镇「灰港」+ 7 个外镇），按**距离圈**分三层：**近圈（2 镇）/ 中圈（2 镇）/ 远圈（3 镇）**。
- **道路逐段解锁**：相邻节点之间一段道路，未开通 = 灰虚线不可走；开通条件 = **上一圈全部城镇好感达标**（不是资源门，是好感门 → 逼玩家真的去送物资）。
- **地图 UI**：抄 `WorldMapPopup` 的框架（拖拽缩放、节点三态、灰锁、解锁渐显 `CoUnlockReveal`）；🔴 **连线必须新做**（全库无任何路径绘制实现），唯一现成范式 = `AdventureUI.ChestConnectors.cs:24-73` 的**运行时菱形点串**（纯色 Image，可直接套到任意两点连线上）。
- 🔴 **美术红线**：`Assets/Art/城镇/` 5 套图集**全库 0 引用**且**不在 `Resources/` 下** → 要按路径加载必须**挪进 `Assets/Resources/`**；且 `WorldMapPopup.prefab` 里 24 个 sprite 引用**已断链** → 新做一律 `Resources.Load<Sprite>(路径)`，**不要用 prefab 拖图**（56 字符 Base64 guid 坑）。

#### 2.6.3 好感度（城镇好感）

- **数据层全新做**（现成的好感是**佣兵好感**，key = hireId）：`SaveData` 加 `townFavorEntries`（List<StringIntEntry>，key = townId）+ `[NonSerialized]` 运行时字典，照 `SaveData.cs:615,634` 的双写范式。
- **加值唯一出口**：`SaveData.AddTownFavor(townId, amount)`（照 `AddMercTrust` 写法）。
- **阈值**：好感 **30 / 40 / 50 / 60** 分别解锁下一圈的交换（凑成整数，进度条好看）。
- **UI**：抄 `MercFavorUI.cs:704-729` 的「Filled 裁剪进度」范式（不用 Slider），但城镇卡片上改成**横向数值条 + 爱心/星标**，够用就行。
- 🔴 **不与佣兵好感混用**：两套 key 空间、两套 UI、两套文案，禁共用字段。

#### 2.6.4 交换（自动 + 概率）

- **自动**：贸易队派出后**不需要玩家点交换**，按真实时间推进（近圈 4 小时/次、中圈 8 小时、远圈 12 小时），到点自动换一次，产出进背包。
- **消耗**：每次交换消耗该镇偏好物资若干（近 20 / 中 40 / 远 60 份作物，**按档位自动换算**：送的必须是该镇偏好的那一档）。
- **产出 = 概率掷点**，照 `MercenaryOfferGenerator.cs:138-149` 的四常量范式（`RollTotal=200` + 三档权重），**权重随好感度分段变化**：

| 好感度 | 普通 | 稀有 | 传奇 |
|---|---|---|---|
| 0~29 | 90 | 10 | 0 |
| 30~49 | 70 | 26 | 4 |
| 50~69 | 45 | 43 | 12 |
| 70+ | 25 | 50 | 25 |

- 🔴 **公示口径与掷点共用同一份常量**（照 `MercenaryRecruitPopupUI.Actions.cs:283-316` 的做法）——不能公示假概率。
- **「有几率换别的」**：产出池 = 该镇特产 60% + **邻近镇的低档货物 30%** + **跨镇稀有货 10%** → 玩家会收到「咦，这是盐湖镇的盐晶？」的惊喜，同时天然形成收集欲。跨镇稀有货只在该镇好感 ≥ 50 后才进池。
- **好感度里程碑回赠礼物**：好感每到 25 / 50 / 75 / 100 各回赠 1 件礼物（走 `MercFavorSystem.GrantRandomGifts`）→ 送礼 → 佣兵羁绊 → ×1.5，形成「种菜 → 送镇 → 换礼物 → 送佣兵 → 羁绊」的完整回环。

#### 2.6.5 贸易队派遣

- 从**同一批闲置佣兵**里抽人（一个佣兵不能同时在地里、在路上、在本局出战队列）。
- 派 1 人 = 一次交换周期（4/8/12 小时）；派更多人 = 并行更多条商路（每队独立结算）→ 又是消化闲置佣兵的口子。
- 存档照项目 `List<XxxEntry>` + `[NonSerialized]` 运行时镜像双写（队伍 id、townId、hireId、开始时间戳、已结算次数），同步挂 `SyncRuntimeFromLists` / `SyncListsFromRuntime`。

### 2.7 明确不做（红线）

**明确不做**：① 加成只在农场生效的临时版（与局内强化卡 / 玩家技能 buff 即 `tempBuffs` 重复 —— 🔴 局内**没有**升星，别再拿「局内升星」当挡箭牌，且玩家会觉得「派主力去种地反而变弱」）；② 农场给单个佣兵无限成长（**与升阶 `MercGrowSystem` 的单佣兵局外成长重叠**）。折中方案「**田间手记**」（某佣兵累计参与耕作满时长 → 一次性给一份永久加成，可迁移）列入二期 T12。

- 出错**只报位置不改**（路径 + 行号 + 原文 + 判断）；禁删掉重建，只做最小增量；不顺手优化没问题的地方；不动美术排版，改前先问。

- 字号 12 的倍数；命名 ≤7 汉字（「灰港农场」4 字）；叙事文案走 C# 常量。
- 改预制体 ≠ 重跑生成器：`Assets/Editor/*PrefabBuilder.cs` 是一次性脚手架，直接改 prefab YAML（备份 + 定位块 + 计数断言 + 回读）。
