## 一、现状（改造前）

- 疾风架势（`gale_stance`）是玩家主动技之一，定位「攻速 +35% 增益，CD 15s，持续 6s」。
- 当前已改为**全自动**：由 `PlayerSkillPassive` 调度，CD 好 + 身边 ≥1 怪 / Boss 进入半径即放附攻速 buff（`UnitBase.Combat.cs:40` 走到期时间）。
- 战斗中玩家**不可手动放**（`AllowManualCast=false`），点技能槽只弹详情。
- 代码引用面：
  - `PlayerSkillPassive.cs:92,107` — 触发条件（`NearbyMonstersAtLeast ≥1`）
  - `UnitBase.Combat.cs:40` — 攻速增益计时倍率（到期自动回 1）
  - `SkillCastService.cs:499` — **历史 bug 提示**：gale_stance 曾因 bug 放一次 +35% 攻速永久生效，现攻速走到期时间
  - `KillComboAfterimage.cs:35` — 残影只与攻速技能绑定，攻速生效期间才出现
  - `SkillDraftMeta.cs:36,56` / `PlayerSkillDefs.cs:199` — 抽卡元数据与技能定义
  - `PlayerJobDefs.cs:154` — **重甲职业 `DefaultSkillId = "gale_stance"`**（改造时勿破坏选职业逻辑）
- 已知关联坑：`SkillCastService.cs:499` 提及的永久攻速 bug，改造务必保留「到期归 1」逻辑，**禁止再引入永久攻速**。

## 二、目标（改造后）

把疾风架势从「自动攻速 buff」改造为**手动窗口点击机制**：

1. 进入就绪（CD 好 + 身边有敌人）→ **弹出倒计时进度条窗口（约 4 秒）**。
2. 窗口内玩家**点击战场空白区 = 英雄多打一次普攻**，该次伤害 **×0.8（-20%）**。
3. 窗口结束结算：点过 → 多打 N 次（每次 -20%）；没点过 → 多打层跳过、CD 重置。
4. **基础攻速 buff：默认仍自动给**（不点也有增益、不亏）。★待确认项。
5. **CD**：基础 30s，每完成一次窗口释放 +6s 左右，**封顶 60s**（逐次递增封顶）。
6. **不点不亏**：常规普攻照常，缺失的只是可选额外多打。

## 三、改造点 + 验收

### 1. 从自动池摘出疾风
- 文件：`BattleManager.Skills.cs`（`FindReadySkillSlot:43`、`IsPlayerSkillGcdReady:84`）、`PlayerSkillPassive.cs`（`TickAutoCast:197`、`IsTriggerMet:161`、`Triggers:107`）
- 改造：`FindReadySkillSlot` / `TickAutoCast` 自动遍历时**跳过 `gale_stance`**（加 `ManualWindowOnly` 标记或 id 黑名单），疾风不再由自动逻辑释放。
- 验收：挂机不打点，疾风攻速 buff 不再自动触发；其他 5 个技能自动逻辑完全不受影响。

### 2. 窗口状态机 + 倒计时进度条 UI
- 新增/改造：`BattleManager.Skills.cs` 或新脚本 `GaleStanceWindow`；UI 在 `BattleUI` 新增倒计时进度条（屏幕中部或技能槽上方）。
- 改造：检测疾风 CD 好 + `IsTriggerMet("gale_stance")` 满足 → 进入窗口态，启动约 4 秒倒计时，显示进度条。
- **UI 纪律**：新增 Canvas 必须走摄像机模式，用 `UICanvasSetup.ApplyPopup(canvas, sortOrder)`，禁止裸 Overlay。
- 验收：满足条件时弹出进度条；4 秒后窗口自动关闭。

### 3. 点击监听 + 多打一次
- 文件：新增战场层点击监听；英雄普攻入口 `UnitBase.Attack.cs:183` `Attack(UnitBase target)`。
- 改造：窗口激活 且 `isInBattle && UnitsCanAct` 且点击落在**战场空白区**（`EventSystem.IsPointerOverGameObject` 过滤 HUD/弹窗/按钮）→ 选当前目标（或最近敌人）调用一次 `Attack`，伤害 ×0.8（Attack 需支持伤害系数参数，或外层包一层）。
- 验收：窗口内点空白 → 英雄立刻多打一次（伤害数字约为普攻 80%）；点 HUD/弹窗/按钮不触发；窗口外点击不触发。

### 4. CD 逐次递增封顶
- 文件：`GameConfig.Combat.cs`（新增常量 `GALE_BASE_CD=30`、`GALE_CD_STEP=6`、`GALE_MAX_CD=60`、`GALE_WINDOW=4`、`GALE_EXTRA_DMG_MULT=0.8`）、`BattleManager.Skills.cs`（CD 管理）。
- 改造：疾风 CD = base + completedCount*step，clamp 到 max；每次窗口结算后 `completedCount++`。
- 验收：首轮 CD≈30s，逐轮 +6s，到 60s 封顶不再增。

### 5. 文案 / 引导同步
- 文件：`PlayerSkillPassive.TriggerText`（`BattleUI.Skills.cs` 展示「身边有敌人时自动释放」）→ 改为「就绪时点击屏幕多打（窗口期）」。
- 文件：`TutorialDirector.cs` 引导第 12 步台词「冷却好了会自动释放」→ 改为手动窗口提示。
- 文件（非强制，可后补）：`Docs/像素冒险：裂缝之刃_玩家技能设计.md` 疾风条目注明现为窗口手动机制。
- 验收：技能弹窗、引导台词、新手提示一致，无「自动释放」残留。

### 6. 误触与边界
- 验收：仅战场空白区点击有效；弹窗/背包/技能槽/按钮上点击不触发；非战斗 / `UnitsCanAct=false` 不触发；与无摇杆设定无冲突（项目已无摇杆）。
