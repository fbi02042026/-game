## 一、改造点（文件 + 做法）

### 1. 酒馆暗化背景 — `InformantQuizDirector.cs`

- 新增常量：`TavernBackgroundPath = "Art/UI/Tavern/酒馆_0007_图层-4"`、`TavernBgDim = 0.42f`
- 新增 `ApplyTavernBackdrop(DialogueUI)`：`SetSceneBackground(酒馆底图)` → `SetRevealBlack(0)` → `SetBgDim(0.42)` → `SetSceneBackgroundAlpha(1)`
- 调用点：`CoDaily` 与 `CoRunQuiz` 各一次（在 `ui.PrepareForStoryBeat()` 之后）
- **底图选型依据**：`酒馆_0007_图层-4.png` 是 `Resources/Art/UI/Tavern/` 下唯一满屏高的图（800×1424，`textureType:8` 单图 Sprite）；其余 图层-3/5/6/7/8 都是 362×194 ~ 800×617 的小图层，不是底图
- **0.42 的依据**：与 `StoryDirector.PlayRoutine` 换背景时的 `SetBgDim(0.42f)` 同值

### 2. 玩家无台词 → 隐藏玩家立绘 — `InformantQuizDirector.cs`

- `CoSpeak` 改签名：`(ui, speaker, line, speakerSp, speakerPortraitId)`，去掉 `playerSp` / `speakerLeft`
- 三处 `ShowLine`（`CoDaily` 的 独眼/老板娘 + `CoRunQuiz` 的 提问/剧情回复/对错回复）统一改为：
  `otherName = ""`、`otherPortrait = null`、`speakerIsInitiator: true`
- **依据**：情报流程里玩家只点选项、从不开口，不存在「玩家说话」的分支

### 3. 立绘大小归一化 — `StoryPortraitLayout.cs` + `StoryPortraitPresenter.cs`

- `StoryPortraitLayout` 新增：`PortraitContentFit` 结构、`PortraitContentFits` 字典、`TryGetContentFit()`、常量 `PortraitTargetCharHeightPx = 968`、`PortraitFootBaselinePx = 42`
- `StoryPortraitPresenter.Context` 新增 `NormalizeSize`（**默认 false，只有情报对话开启，主线剧情排版完全不受影响**）
- `ApplySlot` 在 `ApplyNativePixelSize` 之后：`k = 目标高 / (rawH × charHeightFrac)` 统一角色高；`footAdjustPx = 42×scale − belowFrac×h` 做脚底对齐

**根因（PNG 像素实测，非估算）**：立绘显示尺寸原本 = **整张 sprite 像素 × 屏幕系数**，但各图透明留白差太多：

| 立绘 | 整图 | 角色内容包围盒 | 留白 |
|---|---|---|---|
| 独眼 C004 | 687×1035 | y[25..993]，角色高 968 | 脚下 42 |
| 玩家 player | 1171×1345 | y[213..1277]，角色高 1064 | 头顶 213 / 脚下 68 |
| 酒吧老板娘 | 440×1143 | **整张不透明**（角色即全图） | 无 |

→ 留白多的图，角色实际就看着**偏小、偏下**。归一化后三者角色高统一 968，脚底同一条线。

### 4. 对话可上下滑动回看 — `DialogueUI.cs`

- `ShowLine` 末尾新增参数 `bool normalizePortraitSize = false`（带默认值，**旧调用方零影响**），透传 `ctx.NormalizeSize`
- 新增 `ScrollRect _dialogueScrollRect` + `EnsureDialogueScrollRect()` + `RefreshDialogueScrollable()`
- 启用条件：`_typeComplete && !_typing && 文本溢出`；启用时 `verticalNormalizedPosition = 0`（贴底，停在最新一句）
- `ScrollDialogueText` 在 ScrollRect 启用时**不再抢 `anchoredPosition`**（否则滑动会被拽回底部）
- **打字期间强制关闭**并把 `dialogueText.raycastTarget` 置 false → 「点击迅速说完」在任何位置都仍然有效

### 5. 右侧名字半透明 — 结论（非 bug）

- 成因：`SetSpeakerHighlight(-1)`（情报恒为独眼发起）会把**非发言方**名牌压暗 → `plate alpha 0.55`、`字 alpha 0.7`
- 玩家永不发言却一直挂着这块牌，所以看着像坏了
- **玩家立绘一隐藏，右侧名牌随之消失**（`otherName` 为空 → `SetDialogueChromeVisible` 不显示）

## 四、待确认项（等主人拍板）

1. **独眼要不要居中**：现在隐藏玩家后独眼仍在左槽（anchorX 0.18），右侧是空的。改 `soloCentered:true` 即居中。
2. **老板娘要不要进归一化表**：她整张不透明，现在按「角色=全图」缩到高 968（比原 1143 小）。若嫌她太小，可把她从表内移除或单独调 `charHeightFrac`。
3. **玩家立绘以后还会不会用**：若以后情报里加玩家台词，需要把 `player` 那条归一化的效果重新眼判（当前表内已有，k≈0.910）。
4. **播完后点正文不推进**是否可接受：需不需要加手势判别，让「轻点=推进、拖拽=滚动」。
