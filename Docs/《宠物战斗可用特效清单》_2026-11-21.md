# 宠物战斗可用特效清单（2026-11-21 盘点 · 攻击 + 专属技能）

> 口径（用户 2026-11-21 21:36）：「攻击的特效要有，特有的技能也要有」——宠物战斗做**普攻特效 + 每只一个专属技能特效**，
> 出场、受击、逃跑、治疗这几类不额外叠外挂特效（受击/逃跑靠宠物 prefab 自带动画，见第四节）。
> 全部为 `Assets/Resources/` 下已存在的 prefab，**不新增任何资源**。
> 生成出口统一走 `BattleVFXSystem`（单例，`Assets/Scripts/Systems/BattleVFXSystem.cs`），
> 禁止调用方自己 Instantiate + 手搓旋转（该文件 `PlayPreparedVfx:931` 明确约束）。

---

## 一、普攻特效（按宠物远近/法术定位分三套）

代码唯一出口 = `Pet.GetAttackVfxKit()`（`Assets/Scripts/Unit/Pet.cs:101`）覆写基类，
由 `UnitBase.Attack.cs:210` 的攻击链统一消费，宠物不需要自己 Instantiate。

| 定位 | 谁用 | 特效 | 路径（Resources 下） |
|---|---|---|---|
| 近战刀光 | 修勾/狐大仙、顶梁柱/菇凉、嗷呜（灰狼本体） | 刀光 1/2/3 | `VFX/Shared/Ally/MeleeSlash/刀光1`（2/3 做变体） |
| 远程箭矢 | 钱嘎嘎/复读机、影嗷（恶魔狼换皮后） | 箭矢飞行 + 命中 | `VFX/Shared/Ally/Bow/vfx_ally_bow_fly` + `vfx_ally_bow_hit` |
| 法术法球 | 焰角/小火炭（火球术） | 法球飞行 + 命中 | `VFX/Shared/Ally/Orb/vfx_ally_orb_fly` + `vfx_ally_orb_hit` |

判定真源与宠物属性同源，不另立一份：
- 法术 = `id` 以 `lizard` 开头（`Pet.IsMagicPet`）
- 远程 = `id` 以 `toucan` 开头 或 `id == "wolf_demon"`（`Pet.IsRangedPet`）
- 其余近战

> 皮肤共用本体的套：`dog_fox` → 近战、`lizard_fire` → 法球、`toucan_parrot` → 箭矢、
> `wolf_demon` → **箭矢**（唯一换皮改定位的）、`goat_mushroom` → 近战。

## 二、专属技能特效（每只 1 个，皮肤跟随本体同一套）

代码唯一出口 = `Assets/Scripts/Unit/Pet.Skills.cs`（`CoSkillLoop` 调度 + 每技能一个方法）。
调度照 `MercSkillCaster` 口径（`UnitsCanAct` 闸门 / 眩晕不放 / 无目标 0.3s 重试），
但**不吃蓝、不查 merc_skills 表**（宠物 id 不在表里，硬走会 fail closed）。

| 本体（含皮肤） | 技能 | CD | 效果 | 特效出口 |
|---|---|---|---|---|
| 修勾 / 狐大仙 | 猛扑 | 9s | 前冲 0.18s + 攻击×1.8 物伤 | `PlaySlash` + `PlayCritical` |
| 钱嘎嘎 / 复读机 | 拾金 | 12s | 攻击×0.9 小额伤害（只做表现，无金币掉落系统） | `PlayCritical` |
| 顶梁柱 / 菇凉 | 羊毛盾 | 22s | 玩家+全体佣兵 8% 生命上限护盾 6s | `PlayShield`（玩家 + 自身） |
| 焰角 / 小火炭 | 火球术 | 12s | 落点 1.6 半径内 攻击×1.4 法伤 | `PlayFireball` + `PlayFireImpact` |
| 嗷呜 / 影嗷 | 裂爪 | 11s | 三段 攻击×0.65 物伤 | 三段 `PlaySlash` |

护盾走现成团队盾层 `PlayerPassiveCombat.ApplyTeamShieldFromActive` + `MercPassiveRunner` 同款口径，
不做治疗（羊毛盾按规格是盾不是奶）。伤害统一进 `UnitBase.TakeDamage`。

## 三、现成生成出口（BattleVFXSystem 常用 API）

`Assets/Scripts/Systems/BattleVFXSystem.cs`（单例），宠物用到这些：

- `PlaySlash(position, facingDir, faction)` — 近战刀光（已封装朝向/染色/回收）
- `PlayBowProjectile(from, to, ...)` — 箭矢飞行
- `PlayOrbProjectile(from, to, ...)` — 法球飞行
- `PlayFireball(position, facingDir, faction)` — 火球
- `PlayFireImpact(position, faction)` — 火光命中
- `PlayShield(position, faction)` — 护盾光圈
- `PlayCritical(position, target, faction)` — 暴击/金光

## 四、宠物自带动画（受击/逃跑不叠特效，只靠动画）

10 个宠物 prefab 在 `Assets/Resources/UI/Pets/{Animal,Bird,Goat,Lizard,Wolf}/`，每个自带：
- SpriteRenderer 子节点：`Head/Body/Arm/Arm2/Leg/Tail/Shadow/Attack/Hit/Hit_2/Dead/Roll` + 骨骼节点
- `Animator` + controller，含 `Idle/Walk/Attack/Hit/Dead` 五个状态，但**无参数、无 Transition**

**播放方式**：controller 无 Trigger/参数，不能用 `SetTrigger`，按状态名直接 `animator.Play("{Species}_{State}")`
（`Species` = Animal/Bird/Goat/Lizard/Wolf；`State` = Idle/Walk/Attack/Hit/Dead）。
已接：`PetUI.PetArt` 播 Idle（实例化即播）、`Pet.PlayAnim` 在出手/受击/逃跑时切 Attack/Hit/Walk。

## 备注

- 特效本体颜色多烧在精灵图集里（粒子 `startColor` 为白），按图层名 + 目录判用途可靠。
- 目录另有 6 套逐帧图集（`VFX/PixelFx/`，`PixelFxSheetPlayer` 播放）：starfall/whirlwind/heavy_cleave/shield_block/fire_tornado/plasma_burst（宠物本批不用）。
- 无「金币飞溅」战斗特效；无现成「受击闪白」prefab；无专门「逃跑消散」prefab —— 本批均不新增。
