## 四、敌方佣兵生成（定案 · 2026-10-30 主人拍板「用战力倒推装备技能和佣兵，找简单方法」）

> **关键发现（调研已验证）**：UnitBase 层早有阵营抽象——
> · `UnitBase.cs:77` `public bool isAlly; // true己方 false敌方`；
> · `UnitBase.AI.cs:329` 索敌双向现成：`isAlly ? monsters : allyUnits`（敌方自动从玩家队伍找目标）；
> · `BattleManager.monsters` 是 `List<UnitBase>`（BattleManager.cs:22）——佣兵实体可直接进怪物列表；
> · SPUM 模型/属性/动画/技能施放全在 Mercenary 现成链路（MercenaryManager.SpawnMercenary :302-345）。
>
> **结论：不新写战斗实体、不做皮套。敌方佣兵 = Mercenary 实体 + `isAlly=false` + 进 `bm.monsters`。**

### D1. 敌方佣兵实体（照 SpawnMercenary 生成链，改动最小化）

| 文件 | 改造点 | 验收 |
|---|---|---|
| `MercenaryManager.cs`（或新静态入口 `ArenaEnemySpawner`） | 新增敌方生成入口：照 `SpawnMercenary`（:302-345）加载链，生成后 `isAlly=false`、**不进 allyUnits/_activeMercs、Add 进 `bm.monsters`**、名字牌=机器人名（SetDisplayName）、不挂友军 OnDead（OnMercenaryDead） | 场上出现敌方佣兵，玩家侧自动索敌到它 |
| `Mercenary.AI.cs` | 三处己方专属逻辑按 `isAlly` 分流（全加分支，不改己方路径）：① `UpdateHeroLeash`（:169）敌方跳过拴绳；② `FollowHeroOrIdle`（:263）敌方不跟玩家推图——站住等敌人进索敌距/向玩家半场推进；③ 牧师治疗目标（AllyNeedsHeal/MercSkillCaster）敌方奶敌方队友，不许奶玩家 | 敌方佣兵行为像一支敌方队伍 |
| `BattleManager.Waves.cs:1088` 死亡清理 | 确认 monsters 遍历清理对 Mercenary 实例同样生效（isDead → RemoveAt）；若按 Monster 类型过滤则放宽 | 敌方佣兵死掉正常出列、清场判定正常 |
| 属性喂入 | 倒推出的 **lv 与 ★ 都要进属性计算**（PowerCalc 口径 lv×70+★×110）；`Mercenary.Init(id, level)` 签名不够就加重载传 ★ | 同 power 机器人难度感 ≈ 主线对应进度 |
