  `FirstUnclearedStageIndex0`（BattleManager.cs:363-371）扫完本大关返回 5 被 BattleManager.cs:327
  钳回 0 → 永远从 1-1 开打；而冒险页 `FirstUnclearedStage`（AdventureUI.ChestNodes.cs:1062）
  按单关 key 显示 3-5 → 两边打架。
