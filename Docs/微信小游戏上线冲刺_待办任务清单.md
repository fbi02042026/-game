## 任务清单（按顺序做）

### T1 开发者工具本地验证（半小时，主人操作）
- 微信开发者工具 → 导入项目 → 选 `Y:/PixelAdventureTown/Builds/wechat/minigame/`，AppID 用 wx37eb...（已写入 project.config.json）。
- 验收：能进主城、战斗一场、存档退出重进正常；**开场/登录视频被跳过**（P3-A 守卫生效的铁证）。
- ⚠️ 前提：引擎重启过一次（2026-11-02 提交修复了 22 个换发 guid，编辑器内存需刷新）。
- 通过后顺手真机预览二维码跑一遍。

### T2 P1-A 资源搬家重做（1 小时，AI 可执行）
- 背景：待办清单里"11-01 已搬家"是**假的**（从未落到 weixin/main），`Art/Effects` 仍 8466 文件/3011MB 被跟踪。
- 做法：`python Tools/MoveUnusedAssets.py --go Art/Effects`（先 dry-run 报主人确认清单）→ 搬完编辑器 Missing 回归 → 重新转换小游戏看 data 变化。
- 验收：Art/Effects 零引用清空；转换后 `webgl.data` 体积下降。

### T3 贴图 ASTC 批量压缩（挂机长，主人点按钮）
- 工具就绪：`微信小游戏/包体优化/贴图ASTC(预览)` 已跑：命中 3765 张 / 778MB 源 / 0 张已压。
- **顺序：T2 搬家之后再点应用**（少压 ~3600 张零引用图，重导时间砍半）。
- 应用后抽查像素风画质（城镇/战斗/背包界面），发闷/糊了回报，工具里可调档。

### T4 数据压缩 + CDN（P3-B 主线）
- 转换面板勾选 `compressDataPackage`（webgl.data brotli，103MB→估 40-60MB）。
- 开微信云开发 → 静态托管上传压缩产物 → CDN 字段填托管地址 → 小程序后台配 `downloadFile` 合法域名（HTTPS+备案）。
- 验收：开发者工具断网重进不卡死；真机首屏（含进度条）<8s。
- 二期可选：AssetBundle 拆分做"按需下载"（当前全 Resources 打进 data，做不了细粒度）。

### T5 广告开通（变现开关，等门槛）
- 流量主开通（UV≥500，或先开内置游戏圈攒活跃）→ 拿 adUnitId → 填 `WeChatMiniGameConfig.RewardedAdUnitId`。
- 真机验：拉起、中途关不发奖、看完 isEnded=true 发奖 → `ADS_ENABLED=true` + `PlatformClosed=false`。
- 同场验证转发：分享面板真机拉起一次。

### T6 备案（长周期，尽早启动）
- IAA（无虚拟支付）发布需小程序备案，审核 13-37 工作日——**与 T2-T5 并行启动**。
