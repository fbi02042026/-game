## 三、设计定稿口径

1. **等级上限**：读 `merc_roster.csv` Rarity 列（0 普通/1 稀有/2 传奇）→ 25/35/50。
2. **阶位**：初始阶 I，每过一个升阶节点 +1 阶。普通封顶阶 III、稀有阶 IV、传奇阶 VI。阶位是显示概念（卡面角标/文案），数值真源仍是 level。
3. **每级消耗**：v4 §4.1 五段表原样（金币 → +碎片 → +低徽×1/级 → +中徽×2/级 → +高徽×3/级；金币公式 `基础价(90/150/240)×(1+0.25(n-1))`、碎片 `1+floor((n-5)/10)`）。按**佣兵自身稀有度**取基础价，不按职业。
4. **升阶节点加码消耗**：节点级（10/20/30/40/50）在当级消耗之外**额外**扣 当段徽记×5 + 本名碎片×5（数量待主人拍板，可为 0）。
5. **每级随机属性**：攻/防/血各 +2%（保底）+ 等权抽 1 项再 +3~5%，按基础值百分比；**每 5 级保底换项**（记录 `lastRolled`，第 5/10/15…级先从非上轮项里抽）。
6. **技能节点**：强化 = 该技能效果 ×1.20/1.40/1.60（统一系数，差异化延后）；新增技能槽从**职业被动池**抽（保证主动最多一个）。节点分布按 v4 §1 表（普通 Lv10 强化I / Lv20 第2技；稀有 +Lv30 强化II；传奇 +Lv40 第3技 / Lv50 强化III）。初始技 = `DefaultSkillId`。
7. **等级重置**：等级归 1、随机属性与技能清空重掷；金币返 50%，碎片/徽记 100% 返还。
8. **属性生效**：养成加成按**基础值百分比乘区**，作用在 `Mercenary.SetupAttributes` 拿到基础值之后，不改 `MercRosterDefs.ApplyCombatStats` 内部公式。
