## 1. 立绘的通用规格（所有立绘都适用）

### 1.1 尺寸与可见区域 —— 这一条决定构图，必须遵守

代码把立绘**按原尺寸显示，只取上方 72% 高度**，底部对齐屏幕 17% 处再下移 88 像素
（见 `StoryPortraitLayout.Unified`：`clipHeightFrac = 0.72f`）。

换算一下：**1171 × 1345 的图，实际只显示 1171 × 968**（y = 0 到 968）。

所以构图硬约束是：

- 头顶留白：**项目里实测从 2 px 到 242 px 都有，不必刻意对齐**（见下表）。别贴顶也别留出超过 300 px 的白
- **脸 + 肩 + 胸 + 腰必须在 y ≤ 968 以内**（这条卡死人，画高一点点就被切）
- **膝盖以下会被整段裁掉** —— 画到膝盖就够，不必画完整双腿
- 人物水平居中（单人对白走居中槽位；双人对白走左右两槽，各取图宽的一半）
- 不要纯侧面，用**正面偏 3/4**，与现有立绘一致

现有立绘的实测构图（用 alpha 包围盒量的，可作为新图的参照）：

| 立绘 | 尺寸 | 头顶留白 | 左 / 右留白 | 人物底边 y |
|---|---|---|---|---|
| 前台小姐 | 1171×1345 | 2 | 0 / 0 | 1328 |
| 会长·大众 | 1171×1345 | 2 | 0 / 0 | 1342 |
| 艾丽娅 C001 | 1171×1345 | 242 | 288 / 392 | 1270 |
| 劳顿 H001 | 1171×1345 | 148 | 236 / 184 | 1294 |
| 索菲 H011 | 1171×1345 | 192 | 308 / 308 | 1286 |
| **梅莉莎** ✅ | 1171×1345 | 146 | 400 / 420 | 1314 |

规律：**所有立绘的底边都在 1270 ~ 1345 之间**，也就是上半身到膝盖这一段无论如何都会被裁掉。
把人物的**头和肩放在 y < 600** 就一定是安全的。

### 1.2 文件格式

- PNG，24 位 + Alpha，**透明底**
- **不要**投影、**不要**外发光、**不要**白色描边（UI 层自己处理）
- **不要**画背景
- 线稿用**深棕 / 暗金**描边（现有立绘的通用做法），不要纯黑粗边

### 1.3 命名与放置 —— 两个位置都要放，少一个运行时就看不到

| 路径 | 作用 |
|---|---|
| `Assets/Art/UI/Icons/佣兵立绘/佣兵立绘_melissa.png` | 编辑器直读，日常改图看这个 |
| `Assets/Resources/Icons/MercStand/melissa.png` | 打包后运行时加载 |

（`MercPortraitSprites.LoadEditorStand()` 拼的是 `佣兵立绘_{id}.png`；运行时走 `Resources/Icons/MercStand/{id}`。）

出图完成后，把 `Assets/Scripts/Story/StoryPortraits.cs` 里 `AwaitingArt` 集合中**对应的那一行删掉**，
这样以后万一图丢了会开始报缺图警告——那是防漏保护，不是让你长期留着。

### 1.4 图还没到位时会看到什么（占位图机制）

**现在所有缺的图都已经用占位图顶上了**，剧情里不会出现空白槽位。占位图长这样：

- **尺寸与真图完全一致**（立绘 1171 × 1345、背景 576 × 1024），所以布局和换成真图后一模一样，不会跳变
- 深灰底 + 斜纹 + **金色描边**，一眼看得出"这不是正式素材"
- 中间一个剪影：立绘是人形（头 + 肩）、背景是山和太阳、图标是方框
- 图上印着**该资源的 ID**（如 `MELISSA`、`RIFTWILL`）和一行 `MISSING PORTRAIT` / `MISSING BACKGROUND`
- 第一次用到某张缺图时，Console 会打一条日志：缺 立绘：melissa（梅莉莎）——先用占位图顶着

**怎么换成真图**：把图按 §1.3 的两个路径放好，重新进游戏就自动生效，不用改任何代码。

**发版前必做**：把 `Assets/Scripts/Story/PlaceholderArt.cs` 里的 `Enabled` 改成 `false`，
缺图就会退回原来的"干脆不显示"，不会把占位图带进线上包。

| ID | 占位图现在顶的是谁 | 状态 |
|---|---|---|
| `melissa` | 梅莉莎 | ✅ **已完成**，占位图不再出现 |
| `riftwill` | 裂缝意志 | **已定案不出图**，长期用占位图 |
| 结局背景 ×4 | `bg_end_*` | 待出图（P1）；目前结局演出还没挂背景，所以暂时看不到 |

## 2. 梅莉莎（Melissa）立绘　✅ 已完成（2026-09-16 交付）

> **状态：图已到位。** `1171 × 1345`、透明底、RGBA8，与项目标准完全一致，无需任何处理。
> 已放入 `Assets/Art/UI/Icons/佣兵立绘/佣兵立绘_melissa.png` 与 `Assets/Resources/Icons/MercStand/melissa.png`。
> 本节的设定说明保留下来，作为**后续画差分 B / C**（交代真相 / 松开）时的依据。

### 2.1 她是谁（先看她干了什么，再决定她长什么样）

三句话说完：

1. 十一年前"灰鸦小队"的随队记录员，现在是公会装备科的记录员。
2. **每一支被挑中的小队的补给箱，都是她装的。** 她往每个箱子里塞一张纸条，署同一个名字：**M**。
3. 十一年前她装死（她自己墓碑上刻的是假名），躲进裂隙第二层，此后一直在给后来者留路标、翻新被撕掉的标记。

她的动机是**赎罪，不是牺牲**：

> "我装箱的时候就知道他们回不来。我至少得让后来的人看得懂。"

出场：**第 3 章分支 B（翡翠秘境，二周目）**遇到她；**第 8 章《最后一个箱子》真结局**。

### 2.2 最重要的一条：她不能撞脸，也不能撞色

把现有三位女性角色摆一起看：

| | 前台小姐（现有） | 艾丽娅（现有 `portrait_xiaomei`） | **梅莉莎（新）** |
|---|---|---|---|
| 发色 | 亮橙红，长卷 | 暗栗红，双丸子 | **亚麻灰褐**（全项目唯一的冷色发） |
| 眼 | 明亮蓝 | 褐红 | 褪色的灰褐 |
| 服装 | 公会制服：深蓝 + 金，崭新 | 绿色束腰短衣 + 牛皮件，战士装 | **公会文职制服的同源旧版**：深蓝 + 金，但褪色、洗旧、自己缝补过 |
| 体态 | 挺拔、主动 | 端正、有劲 | 站得直，但**肩是塌的** |
| 手里 | 硬皮登记册 | 钉头锤 | **记账本 + 一支笔**（没有武器） |

两个设计意图：

- **她与前台小姐同源**：同一套公会制服 → 玩家一眼知道"她也是公会的"。她属于装备科、外勤过，所以制服外罩了工装。
- **她与艾丽娅完全不同源**：艾丽娅是暖红 + 绿，梅莉莎就全走冷灰 + 蓝，**发色是全项目唯一的亚麻灰**，0.3 秒就能分清。

一句话概括这张图的意图：**同一套制服下的另一种结局。**

### 2.3 外观设定（可直接照做）

**头部**

- 脸型偏窄，颧骨略明显；眼下有淡青（长期没睡好，不是黑眼圈）
- 额前右侧有一道 2 ~ 3 cm 的旧疤，颜色偏白，**不夸张、不血腥**（她"装死"留下的）
- 左耳后别着一支短铅笔，或夹着一叠折过的小纸片（记录员的工具从不离手）
- 头发剪短或低束，**没有任何装饰**；额前一缕散下来，没空打理
- 常态表情：**不笑**。嘴唇自然闭合，视线落在人身上**偏下**的位置

**服装**

- 基础：公会文职制服 —— 深蓝主色 + 金色滚边，**饱和度比前台小姐降 30 ~ 40%**
- 外罩：**装备科的深色皮革工装短褂**，前襟两个大口袋，口袋口磨白
- 左胸：一枚**褪色的公会徽章**，磨损明显重于前台小姐那枚（时间对照）
- 袖口挽到肘上，小臂有捆扎带；领口不整齐，有一处自己缝的针脚

**随身道具（至少露出两件）**

1. **记账本**——一手拿着，皮面磨得发亮，里面夹着纸条。这是她的核心道具
2. 腰侧挂一串**旧钥匙 + 铜制小铭牌**
3. （可选）脚边一只**半开的补给木箱**，箱内衬纸露出一角——这张图能直接点题

**环境痕迹（她在裂隙里住了十一年）**

- 衣摆、鞋面有干泥和**暗色结晶粉末**
- 手指关节有旧伤，指甲短、缝里有洗不掉的深色
- 制服下摆有歪斜的针脚（她自己缝的）

### 2.4 姿态（别画成"欢迎你"）

**推荐**：站姿，重心压在一只脚上；**左手托着记账本，右手垂在身侧**。
视线**不要正对镜头**，略偏下或偏向画面外——她在看你的装备编号，不在看你。

**不要**：张开双臂、伸手指路、微笑招手、任何女主角光环式的构图。

### 2.5 差分需求（3 张，按优先级）

| 差分 | 用在哪一句 | 表情要点 |
|---|---|---|
| **A 常态** ★必备 | N3 相遇整段 | 疲惫但清醒，不笑，视线略下 |
| **B 交代真相** ★必备 | 「其实那只是……装箱的人。」 | 眼睛**不看人**，嘴微张后闭上——像说完就不打算再解释 |
| **C 松开** ★强烈建议 | 「我装箱装了十一年。今天开始，我不用装了。」 | **第一次抬头直看镜头**，肩线放下，眼里有水光但**不许掉下来** |

差分 B、C 只需要改**头部 + 肩部区域**，不必重画全身。
差分 C 是她整部戏**唯一的情绪释放点**，也是真结局的情绪锚，值得单独投入。

**当前进度**：已交付的是 **差分 A（常态）**。B / C 还没做，目前三处台词共用同一张 A，
不影响功能，但真结局那一句会少一点劲——**C 是性价比最高的一张补充**。

### 2.6 明确禁止

- ❌ 画成第二个艾丽娅（同发色 / 同发型 / 同精神头）
- ❌ 画成老妇人 —— 她三十出头，是**操劳**，不是**衰老**
- ❌ 画成圣母或圣女 —— 她不是来宽恕的，她是来认账的
- ❌ 画成破布流浪汉 —— 衣服旧，但**有条理**（她是记录员）
- ❌ 画成战斗单位 —— 她**没有武器**，一支笔就是她的道具
- ❌ 加翅膀、加魔法光效、加漂浮符文 —— 她是个普通人

## 3. 裂缝意志（Rift Will）立绘　★ P1

### 3.1 它到底是什么（这一条决定它长什么样）

- **它不是灾兽。它是封印机制本身长出来的东西。**
- 它是**看守 / 交易方**：诸神放逐"空洞之喉"时留下**沉座**压住它，裂缝意志替诸神看门——**看久了，它想换班。**
- 它的诉求只有一个：**要一个足够强的灵魂坐上沉座，替它坐，它才能走出去。**

它只有**一句台词**（第 8 章 · HAPPY 结局）：

> 「……你们以为砸了它，就结束了？」

### 3.2 已定案：不出正式立绘，用占位图顶着

| 方案 | 成本 | 做法 |
|---|---|---|
| **A. 占位图**（已定案） | **0** | `riftwill` 保持缺图状态，运行时由 `PlaceholderArt` 自动顶上一张写着 `RIFTWILL` 的占位图。台词照常出，玩家能看出"这里有个东西在说话" |
| **B. 出独立立绘** | 1 张 | 按下面 3.3 走。以后想让它多出场再做，**现在不用做** |

> 代码已经处理好了：`riftwill` 留在 `StoryPortraits.AwaitingArt` 里，缺图时不再返回 null，
> 而是返回占位图。哪天真的出图了，把图放进 §1.3 的两个路径就会自动替换，不用改代码。

### 3.3 若将来要出独立立绘（方案 B）

**设计核心一句话：形态接近人，材质完全不是人。**

因为它想做的正是"像人一样从门里走出去"，所以它**在模仿人形，但模仿得不对**——这句是这张图的全部。

- **轮廓**：直立人形，肩宽，**无性别特征**；比例比真人拉长约 15%，显得"高得不太对"
- **材质**：主体是**黑曜石般的深色晶体**；体内有**自主游走的裂隙纹**，纹路会亮，像地脉在流动
- **头部**：**没有清晰五官**。面部中央只有一道纵向裂隙，裂隙深处有微弱的光——这就是它"看"的地方。**绝对不要画眼睛、鼻子、嘴**
- **下身**：腰部以下**不散开成触手**，而是像晶体一样**收束、悬空**——它是从沉座里长出来的，所以**下方收窄、有根**
- **手**：可以有一到两只"过于对称、过于安静"的手垂在身侧（它在学着像人一样站）。**手里什么都不拿**
- **配色**：黑曜 / 深紫为体，冷青白为光。**不要红色**（红是灾兽与炼狱的语汇，会串味）
- **背景**：透明

**姿态**：静止。**它不做任何威胁动作**——它只是站在那里，说一句话。
威胁感来自"**它太安静了**"和"**它在等你**"，不来自尖牙利爪。

### 3.4 明确禁止

- ❌ 画成恶魔 / 魔王（角、蝠翼、獠牙、王座）
- ❌ 画成触手怪、眼球怪、血盆大口
- ❌ 画成骷髅或亡灵
- ❌ 红色系、地狱火
- ❌ 让它拿任何武器
- ❌ 画成"可爱"或"威武" —— 它是**制度**，不是角色

## 6. 通用负面提示词与参数建议

**负面提示词（每次都要带上）**

```
text, watermark, signature, logo, multiple characters, background scenery,
blurry, lowres, jpeg artifacts, extra limbs, extra fingers, deformed hands,
3d render, photorealistic photo, chibi, super deformed, pixel art (立绘用),
thick black outline, drop shadow, white outline
```

> 注意最后两条是矛盾的：**画立绘时**加 `pixel art`；**画图标时**就删掉 `pixel art` 和 `thick black outline`，改加 `photorealistic, oil painting` 的反向。

**参数建议**

| 项 | 立绘 | 图标 | 背景 |
|---|---|---|---|
| 比例 | 1171 : 1345 ≈ **0.87 : 1**（近 7:8） | 1 : 1 | 9 : 16 |
| 生成后处理 | 抠底 → 缩放到 1171×1345 → 检查头顶留白 60~90 px | 缩到 128×128，**最近邻重采样**保像素锐利 | 缩到 576×1024 |
| 输出 | PNG-24 + Alpha | PNG-24 + Alpha | JPG 或 PNG 均可 |

**最后一步别忘了**：所有立绘放进工程后，用编辑器里的
`Assets/Editor/StoryPortraitCheckTool.cs`（菜单里搜 Story Portrait）跑一遍检查，确认路径与尺寸都对。
