## 4. 验收标准

- 点升阶（普通金币路径 + 传奇钻石确认路径都测）：成功瞬间「进阶成功」大图从 0 猛的弹出（过冲约 1.3 再落定 1.0，总约 0.4s），effect 的 4 组粒子 + 音效同帧齐播（约 2s 放完即停，不循环）。
- 关窗再开：成功节点默认收起，不残留、不自动播。
- 不满星连续升阶两次：每次成功都重新弹出、特效重新播（不卡在第一次的状态）。
- 满星：按钮置灰无反应，不播动效（现有逻辑不变）。
- 竖屏/更瘦屏：Panel 整体 _fitK 缩放不影响弹出观感。
- 编译零 `error CS`；`git status` 除 MercAscendUI.cs 与本文档外无其他改动。
- 若粒子看不见：只报告（查 ParticleSystemRenderer renderMode/sortingOrder 与画布相机匹配），不自行改预制体。
