# 功能解锁维度规范（项目约定）

> 来源：主人 2026-09-19 要求 —— "背包扩容可以增加什么数据，是看广告还是在线时长，**以后增加的功能都要考虑这些因素**"。
> 用途：**今后任何新功能 / 新解锁项，评审时必须对照本表选维度**，并在设计文档里写明所选维度与理由。
> 本规范是项目约定，不是代码。

---

## 一、维度总表

| 维度 | 适合的功能 | 优点 | 风险 / 禁忌 |
|---|---|---|---|
| **A. 推进里程碑**<br>（首次通关 N 关 / 章节 / 击败某 Boss） | **核心功能、永久解锁**（背包扩容、技能槽） | 最健康；鼓励推进；**天然防刷** | 卡关玩家会等得久 → 必须配保底通道 |
| **B. 资源消耗**<br>（天赋石 / 金币） | 数值型天赋、消耗品、一次性服务 | 玩家熟悉，可控 | **会被刷** → 必须配递减 + 每日上限 |
| **C. 看广告** | **永久功能解锁**（背包、槽位、洗点、改名） | 变现点；永久解锁的接受度最高 | 反感度中等；**本期只埋点不接 SDK** |
| **D. 在线时长** | **仅小额日常奖励**（在线 10 分钟领 5 石） | 提升日活留存 | ❌ **禁止用于永久功能门槛** —— 强制挂机反感度高，且卡刚需 = 卡体验 |
| **E. 累计行为**<br>（击杀 N 只精英 / 通关 X 次 / 强化 Y 次装备） | 成就型、收集型功能 | 引导玩家体验各系统 | 需额外统计与埋点 |
| **F. 成就 / 图鉴收集度** | 收藏向（图鉴页、称号、头像框、外观） | 硬核玩家的长期追求 | 轻度玩家拿不到 |
| **G. 周目数 / 二周目** | **终极功能**（双修、高级专精） | 长线追求，支撑二周目 | 一周目玩家看不到 → 不能放刚需 |
| **H. 钻石** | 主人已明确**不作为天赋付费点**；仅限稀有外观 / 便利性 | — | 天赋系统禁用 |

---

## 二、选型规则（硬性）

1. **永久功能解锁** → 优先 **A 推进里程碑**，配 **C 广告** 作付费替代，**B 天赋石** 作第三通道。**三通道并存**，玩家任选其一。
2. **在线时长 D** → 只用于**小额日常资源**（每日在线奖励、挂机收益），**永不用于永久功能门槛**。
3. **任何可重复刷的产出** → 必须配 **边际递减 + 每日上限**（模式见 §四）。
4. **刚需功能**（背包格子、技能槽）→ **绝不能**只给单一维度，必须有推进 / 资源 / 广告三选一。
5. **纯数值天赋** → 走 B（天赋石），并受"分批开放 + 等级上限"约束。

## 三、评审清单（新增功能时必须回答）

```
[ ] 1. 这个功能是「永久解锁」还是「一次性 / 数值增益」？
[ ] 2. 选了哪几个维度？（永久解锁必须 ≥2 个通道）
[ ] 3. 会不会被玩家反复刷？若有，递减与每日上限是多少？
[ ] 4. 会不会卡住正在卡关的玩家？保底通道是什么？
[ ] 5. 是否用到「在线时长」？若是 —— 违反规则 2，必须改成小额日常奖励
[ ] 6. 是否需要埋点？（广告类必须埋，见 §五）
[ ] 7. 数值是否走表？（硬编码一律禁止，进 combat_tuning.csv 或专属表）
```

## 四、防刷模板（可复用）

任何"打怪 / 通关掉落"的产出，统一套这个结构：

| 层 | 规则 | 示例（天赋石） |
|---|---|---|
| **第 1 层 · 推进（主）** | **首次**达成给全额，与天数无关 → 产出可控 | 每关首次 2 石 / Boss 25 石 / 章节 10 石 |
| **第 2 层 · 重复（辅）** | 重复达成只给 **5%**，且**每日每关上限** | 刷第一关 1 次 = 0.1 石 |
| **第 3 层 · 保底** | 每日登录 + 每日任务，防卡关死局 | 3 + 5 石/天 |
| **第 4 层 · 技术出口** | 高难度倍率，奖励技术而非刷量 | 困难 ×1.5 / 噩梦 ×2.0 |
| **禁止** | 通用资源（金币）直接兑换核心产出 | 金币 ⇄ 天赋石 已取消 |

**校验问题**：`刷最低关 1 次` 的收益 必须 << `推进 1 个新关卡` 的收益。
（当前：0.1 石 vs 2 石 = 相差 20 倍 ✅）

## 五、广告埋点规范

本期（2026-09-19）**只埋点，不接 SDK**。

- 统一入口：`AdTrack.Log(eventName, params)` 静态类 —— 将来接 SDK 只改这一处
- 事件命名：`<模块>_<动作>_<click|show|result>`，如 `talent_feature_unlock_click`
- 已规划埋点（天赋模块 6 处）：见 `Docs/天赋右列重制方案_2026-09-19.md §五`
