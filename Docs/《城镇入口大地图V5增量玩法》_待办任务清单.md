## 1. 任务清单（本轮只做 T-A；T-B/T-C 占位）

### T-A · 游荡点（限时随机点位）✅ 本轮做
**目标**：每天按日期确定性刷 1~2 个限时点，位置/类型随机、奖励高于固定点；复用现有选兵→行军→战斗→结算全链路；**不新增存档字段**。

**设计口径（建议值，可调）**
- 数量：每日 **1 个**（保守起步；想 1~2 可改常量）。
- 位置：在地图内容区内随机（**安全区 x∈[-1300,1300]、y∈[-2100,2100]** 留边距、避开底图边缘），**距城堡 ≤ 600（近档不越界）**，且**与现有 6 点最小间距 ≥ 400**（避免图标重叠）。
- 类型：矿 / 野怪 / 城 三选一（随机），名字从 `SlgDefs.CityNames` 或专用名池取。
- 奖励：固定点同类型 ×1.5（向下取整）；守军战力同类型 ×1.2（不能白拿）。
- 存在期：当天有效（按 `TodayKey()`），跨天自动换；打完进现有 `slgPointCd` 冷却。
- **确定性种子**：`System.Random(TodayKey().GetHashCode())`，保证同一天进出地图位置/类型完全一致（不能每次刷新都变）。

**改造点（对着真代码）**
1. `Config/SlgDefs.cs`
   - 加常量：`WanderDailyCount=1`、`WanderRewardMul=1.5f`、`WanderGuardMul=1.2f`、`WanderSafeX=1300f`、`WanderSafeY=2100f`、`WanderMinGapFromCastle=600f`、`WanderMinGapFromPoints=400f`。
   - 加 `public static PointDef BuildWanderPoint(string dayKey)`：用确定性 Random 生成 1 个 `PointDef`（`Id="wander_"+dayKey`、Type/Name/IconPath/Pos 按上面规则；IconPath 复用现有 `MineBigPath/MonsterPath/CityPath`）。
   - 加 `public static readonly string[] WanderNames = {...}`（专用名池，或复用 `CityNames`）。
2. `Systems/SlgSystem.cs`
   - `ActivePoints()` L36：固定点之后 `if (WanderDailyCount>0) list.Add(SlgDefs.BuildWanderPoint(DayKeyUtil.TodayKey()));`
   - 其余（`CanDispatch`/`Dispatch`/`SettleMarch`/冷却）**零改**——游荡点走同一套。
3. `UI/SlgMapUI.cs` `BuildPoint()` L207
   - 游荡点名牌前加标记（如「★」前缀或独立小角标），提示是限时点。
   - 可选：游荡点图标加轻微高亮描边（不新建图，用 `Image.color` 微调）。

**为什么风险低**：点位按当日种子确定性生成、**不需要存点位数**；走现成链路；只动 `ActivePoints()` 和名牌渲染。**不碰存档、不碰结算、不碰主线。**

**验收**
1. 同一天反复进出大地图，游荡点位置/类型/名字**完全不变**。
2. 改系统日期到次日，游荡点**自动换新**（位置或类型变化）。
3. 游荡点避开城堡和 6 个固定点、不重叠、不出画面。
4. 点游荡点 → 正常选兵出征 → 行军 → 战斗 → 占领 → 入账；奖励约为同类型固定点 ×1.5。
5. 打完游荡点进冷却（`slgPointCd`），冷却中灰显 + 显示剩余分钟。
6. 不足 3 闲兵/粮草金币不足时，与固定点同样的置灰提示。
7. 清档后无残留（游荡点本就无存档字段）。
8. 存档兼容：老档加载不报错、`slgPointCd` 多一条 `wander_YYYYMMDD` 也无害。

**依赖 / 风险**
- 依赖 `Core/DayKeyUtil.cs` L17 `TodayKey()`（**禁止**另写 `DateTime.Now.ToString`）。
- ⚠ 游荡点 `Id` 带日期 → `slgPointCd` 会随天数累积条目（每天最多 1 条、int 值，可忽略；如要洁癖可在 `EnsureDailyTaskKeys` 类的位置清理过期项，非必须）。
- ⚠ 图标：游荡点复用现有 3 种场景图（**不新建美术**）；若要专属图标，报主人（见 §3）。
