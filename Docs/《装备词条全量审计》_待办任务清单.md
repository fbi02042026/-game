## 三、发现 B（新 bug，同类）：模板件路径 isPercent 错配
### 现象
`WeaponAffixSystem.IsPercentAttr`（:172-179）与 `ArmorAffixSystem.IsPercent`（:119-125）把以下词条标成 **乘算 (isPercent=true)**：
- `CritRate`、`Dodge`、`LifeSteal`、`CooldownReduce`（外加 ExpBonus/GoldBonus 经济类，战斗无关）

但消费端是 **加算扁平分数**：
- **CritRate**：基础 `BASE_CRIT_RATE = 0.05`（`GameConfig.Combat.cs:241`），消费 `Random.value < critRate + bonus`（`DamageFormula.cs:62`）= 扁平概率；天赋也走加算（`AttrSystem.cs:473` 用 `false`）。
- **Dodge**：`dodgeChance = target.attr.GetAttr(Dodge)`（`UnitBase.Attack.cs:368`）= 扁平概率。
- **LifeSteal**：`LIFESTEAL_RATIO + GetAttr(LifeSteal)`（`UnitBase.Combat.cs:129`）= 扁平比例。
- **CooldownReduce**：`baseCooldown × (1 - reduce)`（`SkillSystem.cs:486`），`reduce` 为加算分数；天赋也走加算（`AttrSystem.cs:514` 用 `false`）。基础未写 → 默认 0。

### 后果（同 DMG_RED 那一类「面板虚标 / 数值不生效」）
- **CritRate**：模板件标 "+5%"（面板 `RoundToInt(0.05*100)`），实际 `0.05 × 1.05 = 0.0525` ≈ 仅 +0.25%（应为加算后的 +5%）。面板与实际差 ~20 倍。
- **Dodge / LifeSteal / CooldownReduce**：基础为 0，`0 × (1+v) = 0` → **词条完全失效**（不是虚标，是直接死）。

掉落路径（`RiftEquipGenerator.TryMapAttr`）此前已把这些强制改加算（注释里讲的就是 `0×(1+v)=0` 这个坑），但 **模板件路径漏改**。

### 修复方案（✅ 已落地，2026-10-21）
- `WeaponAffixSystem.IsPercentAttr`：从 `true` 分支移除 `CritRate / Dodge / LifeSteal / CooldownReduce`（保留 `AttackSpeed` 乘算、`ExpBonus / GoldBonus`）。
- `ArmorAffixSystem.IsPercent`：从 `true` 分支移除 `Dodge / LifeSteal / CooldownReduce`（保留 `MoveSpeed` 乘算、`PhyPower / MagicPower` 原样不碰，因它们不在防具池）。
- 改后口径与掉落路径（TryMapAttr 强制加算）、天赋、消费点三方一致；数值量级与掉落路径对齐（CritRate 加算 +2%~6% 等）。
- ⚠️ 注意：模板件随机数本身已是小数（如 0.02~0.06），改加算后直接 `+0.05` 即「+5%」，无需再动 `RollAttrValue`。
- 附带确认：`EquipInstance.cs:268` 旧版 `GetRollableAttrs` / `RandomAttrValue` 全仓库无调用方（dead code），不涉本次修改。
- 未编译，待主人引擎验证。

### 验收
- 模板武器/防具出现「暴击率/闪避/吸血/冷却缩减」词条时，实战增益 = 面板显示值。
- 回归：AttackSpeed / MoveSpeed 仍是乘算（不受影响）。

## 五、发现 D（小问题，非战斗 bug）
1. **CSV 表头被当数据行**：`RiftEquipTables.LoadRanges` 从 `i=1` 开始且不跳过 `#`/表头，会把第 12 行表头 `属性ID,属性名称,...` 读成一条 `_ranges["属性ID"]`（全 0）。无任何调用方引用该 key，故无害，但属脏数据。可顺手在 `LoadRanges` 跳过首行非数据（低优先）。
2. **ELE_DMG 只接 FireDamage**：`IceDamage` 是独立属性且无任何装备来源，冰系出装的玩家无法通过装备提升冰伤。属 2026-10-19 统一口径的设计选择，非 bug，但冰系 coverage 缺口可记一笔。
