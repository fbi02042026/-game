## 四、SPUM 专项（主人点名）

SPUM 是**生产工具**，不是被引用的素材库，所以「直接引用率 0.2%」是假象。真实使用情况：

| 项 | 内容 |
|---|---|
| 安装版本 | SPUM 1.8.6（`Assets/SPUM/`，483 文件 / 19.5 MB） |
| 部件库 | `SPUM/Resources/Addons`（Legacy / Ver121 / Ver300，596 文件）+ `Units`（23 个角色 prefab） |
| 已拼角色 | `SPUM/Resources/Units/`：dunbing（盾兵）101/102/201/202、fashi（法师）101/102、gongshou（弓手）101/201、kuangzhan（狂战）101/102 … |
| 产出落地 | 导出 PNG → 存 `Art/UI/Icons` → 复制进 `Resources/Icons/MercStand`（31 张立绘，20.4 MB）+ `MercHead`（26 张头像） |
| 运行时是否依赖 SPUM 目录 | ❌ **不依赖**。成品图已落在 Resources，SPUM 目录可以整体移出工程（建议先备份） |

> 立绘 MD5 溯源结果：`MercStand` 31 张中 28 张原图在 `Art/UI/Icons`、3 张在 `Art/UI/Story` —— 即 SPUM 导出后又被放进定制美术目录，SPUM 原始部件图未被运行时直接引用。

## 六、包体结论

1. **素材占包体 99%**，代码只有 4.6 MB。
2. **727 MB 特效里 96% 没用上**，是头号肥胖源。
3. 最省事的瘦身三步（合计约 213 MB，零引用）：删 Hyperbit 整包 → 删 UIShaderEffects 整包 → 清各特效包 Demo 目录。
4. `Art/城镇` 600 张只用了 1 张（4.2 MB，量小但比例触目）。
5. `opening_intro.mp4` 在 `StreamingAssets` 和 `Art/Video` 各存一份（各 14.5 MB），重复。
