# 开发日志：打包这点事（2026-10-09）

现在 Release 包打出来 124 MB，咱们目标是微信小游戏，这体量肯定不行。
打包上踩了两个坑，记一下免得再撞。

## 命令行打包在这台机器上就是跑不动

9-27 那天想偷懒用命令行打包，连着试了三次，三次全卡死。卡的地方一个是资源库刷新刚开头，
一个是包管理器设日志级别那步。当时专门确认过，CPU 时间不动了、日志也不再变长——
是真死，不是慢。网络、临时目录、磁盘都查过，都没问题，最后也没找出为啥。

所以现在老实了，直接在编辑器里点：File → Build Settings → Build。
要打 Spotlight 版就走 Tools / Build / Spotlight Android APK。
那个 bat 脚本没删，就在开头写了句「本机没验过，别指望它」，换台机器说不定能跑。

对了，构建日志里那堆红字——授权校验失败啦、shader 兜底找不到啦、CS0162 啦——
看着吓人，其实一个都不影响出包。以后就看最后一行，写着成功退出、返回码 0，就没事。

## 叫 Resources 的文件夹，会被整个打进包

这条挺坑的。引擎的规矩是：甭管你用没用到，只要文件夹叫这个名字，里头的东西全给你塞进包里。
很多买的素材包自带这么个文件夹，咱压根没碰它，它也跟着进包，白白占地方。

现在还剩俩：SPUM 的部件库 11 MB（运行时真不读它，角色图早就存别处了），
还有怪物包自带的那套字体资源 2 MB。

办法特别简单，文件夹改个名就行，前面加个下划线，引擎就不认了。
8-20 的时候给一个特效包的演示目录这么改过，一下省了 47 MB。
剩下这俩照做，又能省 13 MB，想改回来随时改，没风险。

唯一要注意的：动手前一定先把团结编辑器彻底关掉。
动资源会触发重导入，以前重导入把一批 meta 的 guid 改坏过，预制体引用直接断链，够喝一壶的。

## 就这么点事

打包别碰命令行，走编辑器；再把那俩白给的 Resources 文件夹改个名，白捡 13 MB。
